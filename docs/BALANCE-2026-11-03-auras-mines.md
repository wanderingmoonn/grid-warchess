## 二、光环的"范围"是怎么加的

光环半径原先写死在两处判断里：

```ts
// auraBonus（友军光环）
if (distance(ally, unit) !== 1) continue;       // ← 在能力循环**外面**
for (const a of aurasOf(...)) { ... }
```

这个位置很关键：距离判断放在**能力循环外面**，意味着"改一个光环的范围"必然
把所有光环一起放大。威吓、咒域（都是 1 格）会跟着变成 2 格，那不是需求。

所以改成每个 aura 自带 `radius`（默认 1）：

```ts
for (const ally of s.units) {
  const gap = distance(ally, unit);
  for (const a of aurasOf(utype(s, ally.type))) {
    if (gap > (a.radius ?? 1)) continue;   // ← 每个光环自己说了算
    if (a.allyAtk) atk += a.allyAtk;
    ...
```

`radius` 这个字段上一批（虚咒）已经加进 `AuraSpec` 了，这次只是让**友军侧**
也读它——之前只有 `fearPenalty`（敌军侧）读。没写 `radius` 的光环一律仍是 1 格，
威吓、咒域、治疗光环的行为一字未变。

## 三、布雷：从"贴脸扣血"到"真的埋一枚雷"

原来的 `trap` 其实是这么写的：**自己回合开始时，对距离 ≤1 的敌人扣 6 血 + 减速**。
它跟"埋雷"差得很远：

- 它跟着人走——陷阱师移动，效果也跟着移动；
- 它没有"留在格子上"这件事，敌人绕开也没用，站旁边就掉血；
- 它每回合都能生效，本质是一个隐形的贴身光环。

仓库里早就有一套**留痕（Mark）**层（`core/marks.ts`）：水雷 `nv-mine` 就是用它做的，
接口是"注册一个 `MarkKindDef`，挂到扩展的 `marks` 数组里，引擎负责触发与扣次数"。
这次就是照着这条预留接口重写的：

```ts
const LAND_MINE: MarkKindDef = {
  id: 'gb-mine', name: '地雷', tags: ['mine', 'land'],
  hidden: true, trigger: 'enemy', detect: 1,
  on: ['plain', 'forest', 'hill', 'mountain', 'plateau', 'valley', 'marsh', 'dune'],
  onEnter: (c) => { hurt(c.unit, 10); slow 1 回合; },
};
// 注册在荒兽包：marks: [LAND_MINE]
```

布雷动作改成：**自己回合开始时，在相邻一圈里挑一格陆地埋一枚**（一轮最多一枚），
**全场上限 6 枚**、一格只放一件、城里不埋、跳过自己人站着的格子。

四个数值/规则选择都说一下：

| 选择 | 理由 |
|---|---|
| 伤害 10、无视护甲、不触发反击 | 雷不跟你讲武德；4 代前一个兵 24~40 血，一枚约三成血，踩两枚就得回城 |
| `trigger: 'enemy'` | 自己的雷区自己人走过去天经地义（水雷同理） |
| `detect: 1` + `hidden` | 贴脸才发现。这是雷唯一的破法：先拿一个兵趟一遍 |
| 只认陆地 | 桥面是最想埋的地方，但那会让"过桥"变成掷骰子，而且桥本身会被踩塌——两件事叠一起太吵 |

## 四、顺手修掉的三条旧用例

半径一改，三条会跟着变，都不是 bug 而是**用例里藏着旧假设**：

1. `指挥光环：相邻友军攻击 +2` → 改成 `2 格内 +4`，并把"挪远"从 1 格改到 3 格
   （原来挪到 (5,8) 仍然是 2 格，光环照样生效——那一步其实一直没测到"失效"）。
2. `effectiveStats：指挥光环来自相邻友军` → 站位从 1 格改到 2 格，期望值 +2 → +4。
3. `魔法攻击不吃护甲，只被魔法抗性挡` → 它复用了一个**已经被换下场的**
   `heavy` 对象做"8 甲目标"，而新换上场的圣骑士带着守护光环（现在半径 2），
   于是那个幽灵对象平白多了 2 甲（14 → 12）。改成重新摆一个重骑回去。
   这一条说明旧写法有多脆：`place2` 会清格但不改手里那个对象。

新增 4 条：

| 用例 | 守的是什么 |
|---|---|
| 指挥光环 2 格内 +4、3 格外没有 | 半径与数值 |
| 守护光环 2 格内 +2、3 格外没有 | 半径（同地形对比，扣掉地形差） |
| 布雷：回合开始埋一枚、敌人踩上掉 10 血 + 减速、雷消失 | 留痕真的挂上了、真的触发 |
| 布雷：自己人踩不到、上限 6 枚 | 阵营与上限 |
