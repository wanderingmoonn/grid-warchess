# v4 回放：把 AI 的想法录下来，拖进游戏里看

## 一句话

```bash
node --experimental-strip-types scripts/make-replay.ts --exam S-013
# 产出 exams/S-013/replay.json —— 拖到游戏窗口里，自动进入「复盘」
```

## 面板上看什么

右下角会出现「AI 想法 · t=N · 回放」：

```
决定 press · c2                 ← 这一手的决定层结论（press/defend/expand）
编队[进攻] main-c1 走 3人 散0 advance · 要2人 集火u7 3路
编队[进攻] main-c2 走 5人 散0 advance · 要5人 3路
```

| 字段 | 含义 |
|---|---|
| 决定 `press/defend/expand` | 决定层：这一手要推进、守、还是攒 |
| 编队 `main-c1` | 约束层的队：`main-<城>` = 为这座城组的队 |
| `走/组` | `march`（推进）/ `assemble`（集结） |
| `N人` | 这一手还剩几个 |
| `要N人` | 编队需求（按守军身价算的配额） |
| `集火u7` | 这一手全队打谁 |
| `N路` | 分了几条走廊（地形宽度决定） |

## 两个必须知道的细节

**① 只记"变化点"。** 签名（队 id + 状态 + 人数）没变就不重复记，
所以时间轴上看到的是**结论变化的那些手**，不是逐手快照。想逐手看得改 `logSquads`。

**② 手摆局面必须带开局快照。** 回放原来是"config + seed 重开一局"，
对手摆的题库/关卡重建出来是另一张图，第 1 步就走不下去
（S-013 第一次生成时就是这样）。所以报告里现在带 `initial`（见 `replay-file.ts`）。

## v3 与 v4 的差别

面板还会显示 v3 的「计划」「决战」两行——那是 v3 的概念（一张大分数表）。
v4 没有这两样，所以只有「决定」和「编队」。这不是缺数据，是**两套架构本来就不一样**。
