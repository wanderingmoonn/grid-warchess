# 太空时代 · 装甲五项 · 水陆过渡

**v0.8.1（2026-11-13）**

这一版跨度有点大：合并了另一条开发线的「太空」两包，顺手把装甲扩展的五个问题修了，
再给水加了一道坡。

## 1. 新扩展：太空时代 / 太空战争

两条都默认不勾，在新对局面板里自己开。

- **太空时代**：开局在地球之外多一张**月球图**（约地球的 3/4 边长，只有月壤与环形山）。
  第五代可以修**火箭发射井**（2×2），装一个单位、加注 3 回合、点火上轨道，
  再 2 回合落到月面。把工程队送上去能展开成**月球基地**，采样结果送回地球就赢。
- **太空战争**：在地月之间加一层「轨道」。发射井能把**核心舱**直接射入轨，
  展开成可扩建的**空间站**——花资源铺甲板、加舱段（战斗舱、研究室、接驳站），
  站上建设不需要工程队。还加了**降落到星球**、废墟与接管。

左下角的地图列表可以在地球 / 月球 / 星图之间切换，每张图各记各的相机。

## 2. 扩展之间多了「冲突」和「联动」

有些包不能同时开（会在面板上直接说清原因），有些包一起开有额外效果。
两个方向都认：只在一边写了，另一边也算数。

## 3. 装甲扩展：五个问题

- 规则书的兵种表补上**插槽**（主1 副1 甲2 …）、耗电，电站补「供电 +N」；
- **电量常驻**：建了电站，侧栏顶部一直有电力条，不用先点一台装甲；一座电站都没有时整块不出现；
- 装备后槽位角标不再变成「拆」，**拆卸单独一组**（写着「主 · 速射炮」和退款额）；
- **装配不再限「每轮一次」**：装满一件这台本回合就不能动了，但同回合可以接着装；
- 装甲**战斗数值整体 +30%**（攻/血/甲/武器伤害），造价与耗电没动。

## 4. 深水与浅水之间不再是刀切边

两档水色差得远（#4a7fa6 / #a8cadf），以前拼在一起是一条硬线。现在挨着的那两侧
各铺半格宽的渐变，边界线上的颜色正好是两档中点，接上了——看起来像一道缓坡。

（**深水只在开了「海军」时有**：离岸两格以外的水才是深水。）

## 5. 状态徽章两侧都能看

以前只有敌方单位点开能看到「中毒 / 灼烧」，自己的**产兵建筑**（军营、宗门大殿…）
点开是空的。现在自己的营地也有状态行，棋子悬停的提示里也带上了。
