# 10 月 30 日更新（二）：选卡屏不再一进来就判超时

这一版只动选卡模式，三件事：**一进禁用就被判超时**、**池子顺序是花的**、
**卡片看不到完整数据**。

---

## 一、一进选卡就"双方禁用已超时"

现象：联机开局，刚点开选卡，禁用阶段还没看清，流水里已经写着双方各"放弃"了一次禁用。
两个人的禁用名额就这么白丢了，而且是被一条谁都没看见的超时判定吃掉的。

两个原因叠在一起：

**① 规则层把"没有计时"当成了"早就到点"。**
超时的判据是一句 `action.at < draft.deadline`。lobby 阶段 `deadline` 是 `0`
（那一屏要等人，本来就不该计时），而 `0` 这个缺省值在这句话里永远不会成立——
于是任何一次超时请求都会被放行。只要有一个客户端在禁用阶段带着 `deadline = 0` 的状态
跑一拍定时器，就会替**双方**各补一次"放弃"。
现在：`deadline` 不是正数（0、NaN）时一律回一句「这一阶段还没开始计时」，不动状态。
顺带把入口也堵了——`DRAFT_START` 少了时间戳会被拒，`action.at + 25秒` 算不出 `NaN`
才是这个坑的源头。

**② 界面把别人的钟当成了自己的。**
`deadline` 是**另一台机器**的 `Date.now()` 写进房间的。你入座时对面可能已经在禁用屏上
坐了一会儿，甚至那份 deadline 早就过期了；拿它直接减本机的 `Date.now()`，倒计时一进来
就是 `0s`，紧跟着就是上面那一枪。
现在界面自己记一个锚点：**我看到这一轮的时刻**。超时要同时满足两条才发起——
本机盯着这一轮走完了整个时长，**并且**房间那份 deadline 也到点。倒计时显示取两者的小值。
于是：

- 刚进禁用就是满格 25 秒，不会一进来 `0s`
- 别人的钟比你快也不会替你抢答；比你慢也不会把整局拖死
- 超时本身照样会触发（房间那份到了就过），只是不再"提前"

## 二、池子按"时代 → 扩展"排

以前池子的顺序是**抽样时的顺序**：为了每个时代都抽得到，抽样是"一层一张"轮着来的，
铺出来就是 1 代、3 代、2 代、5 代混着，同一个时代的原版兵和扩展兵也掺在一起。
20 张卡还能忍，开着扩展时池子到 30+ 张，扫一遍得靠眼睛来回跳。

现在排序是两级：

1. **时代**（低 → 高）：先回答"这一代有什么"，因为时代决定它什么时候能用
2. **扩展包**（原版最前，其余按扩展的声明顺序）：同一代里再回答"这是哪个包带的"
3. 同一代同一个包里，战斗单位在前、建筑在后；再按名字排，保证顺序稳定

## 三、悬停看完整数据（点不动的卡也能看）

卡片上只有"时代 · 造价 · 攻/血"——那是用来**扫**的，不是用来**算**的。
要判断"这一手禁它值不值"，得知道护甲、射程、视野、溅射、连击、能力和来源包。

现在鼠标停在任何一张卡上都会浮出一块详情：

```
长弓手                    IV 代 · 战斗
攻 14 · 甲 1 · 血 24 · 移 3 · 射 4 · 视 5
40 金 · 来自「奇想·骑士团」
能力：远程 · 破甲
────────────────────────────
现在点不了：你已经提交过禁用了，等对面
```

三个细节是刻意的：

- **点不动的卡也有详情**。"我已经交完禁用、对面在选"和"轮到对面选人"这两段时间里，
  正是最想研究池子的时候。所以"为什么点不了"是详情里的一行，而不是干脆不给看。
- **禁用状态改用 `aria-disabled`，不再用 `disabled`**。`disabled` 的按钮在部分浏览器里
  连 `mouseover` 都不派发，那样详情永远出不来——点不动的原因反而被藏住了。
  点击仍然拦得住（会弹一句原因）。
- **浮层挂在 `body` 上**，不在卡片里。池子是 `overflow:auto` 的滚动容器，
  卡片内部的绝对定位浮层会被裁掉，最上面一排的详情会直接看不见。
  浮层按卡片的视口矩形定位，顶上放不下就翻到下面，指针事件全部穿透。

## 四、验证

- `npm test` 全绿：规则 **433** / 界面 **147** / 静态服务器 **11**
- 新增用例：
  - 规则：`deadline` 为 `0` 或 `NaN` 时 `DRAFT_TIMEOUT` 必须被拒，且不替双方补"放弃"；
    缺时间戳的 `DRAFT_START` 也要被拒
  - 界面：刚进禁用时倒计时**是正数**、流水里**一条都没有**（不会一进来就超时）；
    卡片按时代非降序；同一代里扩展包按声明顺序、原版在最前（用「奇想·骑士团」+
    「古典会战」两个包验的，同一代里确实混着两家的兵）；悬停浮层会出现、有数值与造价、
    移开就收起

## 五、回滚

界面层为主，`src/core` 只动了 `draft.ts` 里的两处守卫（不改存档结构）：

```bash
git revert <本批 commit>
npm run build:static && node scripts/serve-static.mjs
```

回滚后旧行为会回来：`deadline` 为 0 时仍可能被误判超时——如果只是想撤销排序和悬停，
保留 `draft.ts` 那两处守卫、其余照旧即可。
