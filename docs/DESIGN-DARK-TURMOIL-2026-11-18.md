# 「黑暗动乱」· 设计草案与最小实现

> 2026-11-18。依赖修真包（`requires: ['cultivation']`）的剧情扩展。
> 这一版只做到**最小可跑**：衰老 → 寿元见底 → 吞同伴续命 → 还是老死。
> 仆从、诡异、攻城、波次、数值全未做。

---

## 1. 设计草案（作者口述，原样记录）

- **尸骸仙帝**：实力凌驾于九级修士之上（修真包最高 9 级），但**和九级修士不同，它还会老**。
- 平时在**沉眠地**休整，年龄增长缓慢；寿元濒临耗尽时出来发动「黑暗动乱」，
  清洗天地间所有生物换取寿元，然后回去接着睡。
- 单位分两类：
  - **仆从**：帮仙帝压制玩家成长；
  - **诡异**：增生的怪物，按自己的逻辑行事，不听指挥。
- 仙帝缺"食物"（敌人不够吃）时，会**清理同阵营单位，从低级往上**。
- 所有单位 / 建筑**都不能造**，只能由关卡模式生成。
- 「不迎战」的代价：仙帝隔一段时间来把玩家基建打爆；诡异可能直接攻破城市；
  仆从会定点清理高威胁单位。
- 寿元对玩家只给**模糊描述**，不给数字。

---

## 2. 三个机制决策（已落地）

### 2.1 不走修真的境界系统

`MAX_RANK = 9`，且 9 级的寿元是 `Infinity`。往修真包里塞"第 10 级"会牵动属性公式、
经验墙、面板、规则书和整套平衡，而本包只是**借**修真那套语义。

所以：尸骸仙帝不是修士兵种，`isCultivatorUnit` 不认识它；属性直接给一组
高于九级修士的固定值（九级大约：攻 +257 / 甲 +119 / 真伤 66 / 每回合 5 段攻击）。

**好处**：修真包一行没改；将来修真包调数值，这个 boss 不会跟着漂。

### 2.2 年龄用引擎的 `u.age`，不去拦核心

核心在回合开始时给**所有**单位 `age += 1`（`rules.ts` 的回合开始）。
我们的钩子在这之后跑，所以：

- 不在沉眠地 → 再 `+1`（合计 **+2**/回合）；
- 在沉眠地（2 格内）→ 不加（合计 **+1**/回合）。

这就是"沉眠地延缓衰老"。核心的年龄规则一个字没动，也没去"倒扣年龄"。

### 2.3 寿元存在 `custom.lifespan`（自己读写）

修真包的 `getLifespan` 优先读这个字段、且要求是有限数——所以给 9 级兵写一个
有限寿元它也会认。但**修真包的 `isDoomed` 只对修士生效**，我们的 boss 不在其列，
所以判死得自己做（我们在钩子里比 `age > lifespan`）。

顺带：寿元不落"Infinity"，所以序列化没坑。

## 3. 最小实现（这一版有什么）

| 东西 | 说明 |
|---|---|
| `corpse-emperor` 尸骸仙帝 | `summonedOnly`（产线硬拦，玩家也造不出）；1600 血 / 300 攻 / 130 甲 / 射程 5 |
| `slumber-site` 沉眠地 | 建筑，不会动；站它 2 格内衰老减半 |
| 技能 `devour`（吞噬） | 无冷却、`multiCast`（一回合能吃多个）；**只能吞自己人**，+10 年寿元 |
| 技能 AI 提示 | 剩余寿元 ≤ 8 **且** 8 格内敌人 < 2 才吃；挑**境界最低**的同伴 |
| 面板 | 只说"将熄 / 将尽 / 尚可 / 绵长"，不给数字 |
| 关卡 `level:dark-turmoil` | 16×16，B 席 `cityless`，目标：杀掉仙帝（**老死也算**） |

数值全是占位（`LIFESPAN 200` / `START_AGE 178` / 吞噬 +10），调的时候改
`dark-turmoil-packs.ts` 顶部那几个常量。

## 5. 实跑发现（重要，别当结论丢了）

关体实跑 40 个行动的结果：

```
仙帝年龄 194 / 寿元 210 · 吞噬 1 次 · 场上同伴 3 个 · 胜者 B
```

两件事：

1. **"吃自己人"这条循环在真关里确实会触发**（吃了 1 次，寿元 200 → 210）。
   不是只在探针里成立。
2. **40 个行动内玩家被清场**。300 攻 / 130 甲 / 1600 血 对 2 代修士是碾压。
   这不是 bug，是"占位数值 + 没做关卡节奏"的必然结果。

**所以这个关现在不能当难度关看**，它只是"循环跑得通"的证据。

## 6. 下一步（按依赖顺序）

1. **数值与关卡节奏一起调**：现在没法单独调某一项——boss 多强、玩家需要多少兵、
   沉眠地给多少喘息时间，三者是同一个方程。
2. **仆从**：帮仙帝压制玩家成长。技术上就是 `unitAi` profile（优先打经济单位 / 高威胁单位）。
3. **诡异**：自主行动、不听指挥。同样是 `unitAi`，但行为要"不讲道理"（
   比如只追最近的目标、不看队形）。
4. **"不迎战"的代价**：定时攻城 / 拆基建。适合放关卡事件（`turn` 触发 + `spawn`），
   不需要新机制。
5. **波次与"清洗"**：现在只有单体 boss，还没有"黑暗动乱"的场面。

## 7. 已知的坑 / 待确认

- **老死有一回合延迟**：`killUnit` 发生在回合开始钩子里，而胜负判定在它之前跑过一次。
  表现是"它已经化成白骨了，但游戏要等下一次交棒才结束"。要修得给 `checkWinner`
  加一次调用——先记着，别现在动。
- **吞噬没有手动入口**：`targeting: 'point'` 但没注册可点格子，所以真人操作仙帝时
  点不出这个技能。现在它只由 AI 使用（关卡里 B 是电脑），等真要做"玩家操控仙帝"
  再补 `registerSkillTargetCells`。
- **`START_AGE` 的初始化只认"年龄 ≤ 1"**：如果以后有别的路径给 boss 设了年龄，
  这条会不生效。写在 `tickEmperor` 里，改的时候看清楚。
