# 10 月 30 日更新：指挥官模式能"空过"，联机选卡不再卡住

这一版是两个尾巴：指挥官模式的**排产少一种意思**（想攒钱却没处表达），
和联机选卡的**四个把两个人一起卡死的洞**。

---

## 一、指挥官模式：能排「空过一回合」了

以前序列里的每一格只有三种：一个兵种、「升级时代」、空的。
"空的"在这里被两件事共用：**我还没排到这一格**，和**我这一回合故意什么都不造**。
两者在数据上是同一个值（空串），于是后者根本表达不出来——你把格子留空，
AI 看到队首是空串，会当成"你还没排计划"，自己替你排一条，顺手把钱花掉。

现在参谋部多了一颗「空过一回合」：

- 点一下，序列末尾加一格 **空过**：这一回合不造兵、也不升级，钱留着
- 队列条上它长得和"还没排"的虚线空格**不一样**（实线、写着「空过」），
  一眼分得清"我还剩 3 格没想"和"我明确要求这 3 回合不花钱"
- 排满 5 格时按钮置灰；每一格照样带 `≈ N 金`，可以对着余额决定哪几回合该攒

什么时候用：想升时代但差一口气、等对面先撞上来、或者前线已经站满不想再塞人。

## 二、「结束行动」和「交给 AI」都改成"打完一批再交还"

以前指挥官模式里有三个入口能推进游戏，节奏还不一样：

- 参谋部的「执行 5 回合」——一批 5 个回合，打完交还
- 底栏的「结束行动，交给对方」——只推进**一个**回合
- 顶栏的「交给 AI」——把某一方托管给 AI，回合会自己往前跑

后两个都是误触重灾区：顺手点一下"结束行动"，就变成"我走了半批、对面还没走"，
批处理的回合计数、对面看到的局面、联机提交的回合号全都对不齐。

现在这三条**做的是同一件事**：

- 底栏那颗按钮变成「执行 5 回合，然后交还」（联机是「执行本回合」），执行中置灰
- 顶栏那颗在指挥官模式里叫「交给参谋部」，点下去也是执行一批，
  不会再出现"把对面也丢给 AI、然后两边跑到天荒地老"
- 队列空着也能执行：这一批就只有走位，不产兵（想攒钱就直接点，不必先排满）

## 三、联机选卡：四个洞

双人 BP 的毛病看着五花八门，其实只有两个根：

**根一：超时那一步只改了本地，没写进房间。**
你的钟先到点，本机替你补了一手，房间里没有；对面的钟后到点，也补了一手。
两份名单从此分叉，进度号各自往前跑，谁也追不上谁——于是「超时补选完还得再选一次」，
而且之后点哪张卡都没用。

- 现在超时和别的动作一样**提交进房间**，谁先到点谁写，另一边拉下来即可。
  超时的结果是确定的（禁用＝放弃；选人＝按种子在剩余池里取一个），不会打架。
- 同一格只尝试一次，不会每 400ms 弹一句提示。

**根二：本地进度号跑到房间前面时，程序只会干等。**
提交失败（断网、切后台、对面抢先四次）之后，本机停在一份"房间里并不存在"的名单上，
轮询看到"我这边的进度号更大"就直接放过了——两边各拿一份对方没有的名单互相等，
界面表现就是**禁不动、选不动**。

- 现在这种情况按**房间是权威**处理：自动退回房间那一份，并明说"刚才那一步没交上去，请再点一次"。
- 选卡屏右上角多了一颗 **「刷新房间状态」**：卡住时点一下立刻按房间对齐，
  不用关页面重进。

另外两处顺手修的：

- **席位以房间为准**。以前点击用的是缓存下来的座位，一旦和房间不一致，
  点下去会被判"这是对面的席位"然后没反应——这也是"选不动卡"的一条来源。
- **提交期间的点击不再被吞**。以前正在提交时点下一张卡是静默丢弃的（手感像卡了），
  现在会记住这一下，等上一步交完接着办。

## 四、验证

- `npm test` 全绿：规则 **432** 项 / 界面 **146** 项 / 静态服务器 **11** 项
- `npm run test:room` 打真实云端房间跑通：抢座、提交、过期回合号被拒，
  以及一整轮联机 BP（进度号走到 18，收尾把锁交还 `turn = 1`）
- 新增用例专门盯着这次的坑：
  - 「空过」落成 `@idle` 哨兵，和空串分开；AI 不会把它当成"没计划"去造兵（还带一条反证：
    队首点真兵种时它确实会造）
  - 指挥官模式里**不存在** `data-act="end-turn"`，底栏换成"执行一批"
  - 联机 BP 的合并协议：两边同时禁用时，后交的一方合并重交、两份名单都留在房间里；
    超时是一步动作；同一手补不进新局面上时判失败让调用方退回房间那份

## 五、回滚

界面层为主的改动，`src/core` 只动了三处（`ORDER_IDLE` 哨兵、`SET_ORDERS` 认它、
`mergeDraftStep` 抽成纯函数），无存档字段变更：

```bash
git revert <本批 commit>
npm run build:static && node scripts/serve-static.mjs
```

旧存档里的序列读出来照旧（`@idle` 是新增值，旧版本读到它只会当成"没有这个兵种"，
不会崩；真要回滚到不支持它的版本，先在队列里把那几格删掉即可）。
