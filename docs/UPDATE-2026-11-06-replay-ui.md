# 复盘时界面不该跟着演

**v0.3.40（2026-11-06）** · 复盘只读化

## 一句话

拖一份对局数据进来看复盘时，界面原来还当这是"你正在打的那一局"：
侧栏顶着「轮到你行动」、城里有生产按钮、选中单位有强制移动 / 拆除 / 结束行动，
顶栏还摆着「暂停 AI」「交给 AI」「导出对局」。**每一颗都点不动**（闸门挡着），
但每一颗看起来都能点——这局棋和这套 UI 在互相否定。

现在复盘是真正的只读：**能改局的东西全部收起来**，留下的只有"看"。

## 具体收了什么

| 位置 | 原来 | 现在 |
|---|---|---|
| 侧栏抬头 | 「轮到你行动」 | 「复盘 · 全图视角」 |
| 席位栏 | 红方标「（你）」 | 两边都不标——复盘里没有"你" |
| 城市面板 | 生产区 + 产兵按钮 | 城市卡（时代 / 耐久 / 护甲 / 驻军），只读 |
| 单位面板 | 强制移动 / 强制攻击 / 拆除 | 只属性卡 |
| 侧栏底栏 | 结束行动（禁用）/ 撤回 / 认输 | 只留一颗禁用的「复盘 · 只能看」 |
| 顶栏 | 暂停 AI / 速度 / 交给 AI / 联机 / 迷雾 / 导出对局 | 全部收起，只留规则书 / 反馈 / 首页 |
| 参谋部横条 | 指挥官局照样弹出来 | 不出现 |
| 选卡遮罩 | 选卡局的报告会盖住棋盘 | 不出现 |
| 结算卡 | 终局帧会问"要不要捐出这局的数据" | 不出现 |

最后两条不是"看着别扭"，是会真出事：

- **导出对局**按下去导的是当前 `state`，而复盘期间 `state` 是别人的棋——
  玩家以为在导出自己那一局，发出去的却是别人的。
- **结算卡**自带"上传这一局"的按钮，按下去等于替一个不知情的人签了同意书。

两处都在入口处加了闸（顶栏那颗按钮藏起来 + `case 'export'` / `reportPanel()` 里再拦一道）。

## 还有一个更隐蔽的冲突：AI 会接着下

`enterReplay` 换掉的是全局 `state`，而 AI 走子那两条循环（`runAiTurn`、
`runCommanderBatch`）只认自己的 `token`。不按停的话，它们会接着在**回放**上下子：
拖到自己想看的那一帧，过一会儿棋又变了，回合数还和进度条对不上。

现在进复盘先 `aiToken += 1` 把两条循环叫停，退出复盘时 `kickAiIfNeeded()` 重新点起来。
热座交接遮罩也顺手关掉——那层同样是 window 级拖放能触发的。

## 顺手补的一件事

复盘里原来点城**打不开城市卡**：城不是单位，不在 `stackAt` 那条道上，而复盘分支只认单位。
现在点城里没站兵的那一格会选中城——复盘时"这一步它为什么不敢压上去"，
答案往往就在城的耐久和时代上（攻城伤害 = 攻击 − 护甲）。

## 钉住的用例

`npm run test:ui` 加了两条：

1. **界面只读**：摆一局、造一份带 `winner` 的报告拖进去，点城之后断言 ——
   侧栏没有任何一颗可用的改局按钮、抬头写「复盘」且没有「轮到你行动」「（你）」、
   顶栏六个会改局的按钮全 `hidden`、结算卡不存在；退出后顶栏复原。
2. **AI 不会接着下**：开一局双 AI 让它打起来，中途把文件拖进来，跳到最后一帧，
   盯 500ms —— 回合数和进度条位置都不许变。

把 `spectator: watching() || replay !== null` 改回 `watching()`，第一条会红（185 通过 / 1 失败），验证过。
