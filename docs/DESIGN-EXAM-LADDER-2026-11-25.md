## 一、问题：三处能数的证据

用户的原话是"考题设计得有点散乱，没有按照从简单到复杂，上来就考复杂问题；想让它在这上面超越 v1 和 v3，步子迈得太大"。
这不是感觉问题，三处都能拿数说话。

### 1.1 题是从病历上撕下来的，不是从课表上排的

题库的原料是 v3 的三局失败回放。`GUIDE-V4-EXAM` 第十四节自己写了：真实局面切出来多半是"综合判断"，
单机制题要另摆。也就是说这套题的来源是**"v3 在哪儿疼"**，不是**"要学会这个得先会什么"**。

病历本来就不该有序——它就是哪儿疼记哪儿。问题是我们后来把它当成了课表，还按同一个刻度打分。

### 1.2 v4 相对 v1 的净领先，只有一道题

用 2026-11-25 09:30 的矩阵（13 道题 × 4 个答题者，对手 `core/ai.ts`）：

| 答题者 | 绿 | 是哪几道 |
|---|---|---|
| 空壳 | 0 | — |
| v1 | 7 | S-000 S-001 S-006 S-009 S-012 S-016 S-017 |
| v3 | 6 | S-000 S-001 S-009 S-013 S-016 S-017 |
| v4 | 8 | S-000 S-001 S-005 S-006 S-009 S-015 S-016 S-017 |

- **只有 v4 绿的：S-005（桥头让位）、S-015（经济选型）**，两道。
- v4 绿而 v1 也绿：六道。这些只能算"没退步"，不能算领先。
- v1 绿而 v4 红：**S-012（采购 + 收尾）**。

所以 v4 相对 v1 的净账是 **+2 −1 = 净多一道**。而 13 道里有 5 道是"把兵变成战果"的题
（S-002 / S-004 / S-011 / S-012 / S-013），四家一起红；v4 唯一的领先项全在"摆位置、选岗位"这种不打仗的事上。

**结论：v4 已经会摆阵，还没学会打。** 在这个位置上要求它同时超过 v1 和 v3 拿下那五道，
等于让它一跳越过整整一层。用户感觉"步子大"，是因为中间确实空了一层。

> 顺带修一处旧读数：`V4-CODE-MAP` 第 0 节原来写"三道只有 v4 绿"，把 S-006 算了进去。
> 矩阵里 v1 在 S-006 已经是绿的（11-24 的评审记的是 v1 = 39 < 45 红，之后 v1 变强了）。
> 已在第 0 节改正为两道。

### 1.3 分布是"两头空、中间挤"

| 级 | 现有题 | 状态 |
|---|---|---|
| 1 会挪一格 | 无 | 缺 |
| 2 不做无用功 | 无（原意被并进别的题了） | 缺 |
| 3 一件事做对 | S-005 S-006 S-015 S-016 S-017 | 5 道挤一层 |
| 4 两件事排序 | S-001 S-009 | 一对，够用 |
| 5 分得开 | S-013 | 只有一道，且红 |
| 6 打得过 | S-002 S-004 S-011 S-012 | 4 道，全红 |
| 7 收得掉 | 无（Y-002 废了） | 缺 |
| 8 整局 | 无题，只有长局跑批 | 缺 |

13 道题的题号看起来是连着的，但它们压在第 3~6 级上，两头是空的。
"东考一个西考一个"不是错觉，是这个分布的直接后果：四道挤在同一层，另外四层没有题。

另外还有两个数字要记住：**第 1、2 级空着**，是"v4 一红就分不清是不会走还是走不好"的直接原因；
**第 7 级空着**，而那是 v3 最大的洞（100 个兵打不动一座城）。

> 三处"四家全红"的题（S-002 / S-004 / S-011）不是"不可能的题"。
> S-002 有人的 52（线 45）、S-004 有后撤机器人的 8（线 8）、S-011 有 **v4 自己在 11-24 跑出的 8/8/8/7**——
> S-011 从 8 掉到 4，是撤回"军队走位"那几轮（8.28~8.35）的代价，不是判据写错了。
> 这正是"判据必须先被人/某个答题者跑绿过"这条规矩的价值：它把"不可能"和"退步了"区分开。

## 二、八级阶梯

每级四栏：考什么 / 过关长什么样 / 为什么必须排在上一级之后 / 现在有没有题。

| 级 | 名字 | 考什么 | 过关长什么样 | 为什么在上一级之后 | 现有题 |
|---|---|---|---|---|---|
| **1** | 会挪一格 | 一个兵能不能走到指定格子（有绕水、绕山两种情况） | N 回合内那个兵站在那儿 | — | **无** |
| **2** | 不做无用功 | 不做明显赔本或没意义的事（死水不造船、不修多余的桥、不空手挨炮） | 做了那件不该做的 = 红 | 得先会动，才谈得上"动错" | **无** |
| **3** | 一件事做对 | 有唯一正确目标的一件事：让开桥、站对格子、空城直接砸 | 状态或数量达标，且没有副作用 | 只考"选得对不对"，不考"打得赢" | S-005 S-006 S-015 S-016 S-017 |
| **4** | 两件事排序 | 先后有意义：先清场再砸城、先造兵再迎敌 | 两段的判据都达标 | 每一段单独拿出来都是第 3 级的一道题 | S-001 S-009 |
| **5** | 分得开 | 同时守两个地方 / 两路推进 | 两个目标都保住 | 每一路单独拿出来都是第 4 级的一道题 | S-013（缺第二道） |
| **6** | 打得过 | 兵力优势下的对抗、交换、伤亡控制 | 战果达线且伤亡不超线 | 得先会分兵，才谈得上在一个方向上集中 | S-002 S-004 S-011 S-012 |
| **7** | 收得掉 | 兵很多、敌很少，能不能把最后一座城拿下 | 时间窗内城被拿下 | 前六级都对了，这里只考"敢不敢投够、敢不敢不管家里的安全" | **无**（Y-002 废了） |
| **8** | 整局 | 从开局到结束的过程指标 | 经济产出 / 升代时间，不看胜负 | — | 无题，只有长局跑批 |

### 排序只认一条检验

> **这一级的题，能不能拿上一级的解法当第一步？**

能，才算相邻；不能，中间就是缺了一级。这条检验有两个作用：
它把"难度"从一种感觉变成一个可以当面对质的问题；它也自动否掉"跳级"——现在 S-002 落在第 6 级没人反对，
但它一直是按第 3 级的用法在用（"城伤 39 < 45，去修"），所以红得莫名其妙。

### 一处分歧要写清楚

现在被叫"地板"的 S-000 是"12 个三代兵，30 手内推下一座城"，按这张表落在第 4~6 级。
它不是地板，它是"能不能完整打一场占优的仗"。**地板的名字要还给第 1 级。**
名字错了的代价是：v4 全红时你会先去看 S-000，而 S-000 红只说明"哪儿都坏了"，不指向任何一处。

## 三、五条机制

### 3.1 病历和阶梯分开，别共用一张分数表

| | 病历 | 阶梯 |
|---|---|---|
| 顺序 | 无序，按症状索引 | 有序，按依赖排 |
| 装什么 | 真实失败局切出来的综合局面、够不着的难题 | 一级一级能过的题 |
| 作用 | **证据**：这个病真发生过、亏了多少 | **刻度**：现在到第几级 |
| 打分 | 不参与日常红绿 | 日常只看这张 |

现在的问题就是两者共用一张 13 道的表：既看不出进度（8/13 里 5 个是地板），也看不出病灶（红的都是一个数）。
拆开以后，"这题红了"在病历里说的是"敌人还存在"，在阶梯里说的是"这一级没学会"，两种话不会混。

### 3.2 每级配两道题，一主一换

一道红了，你分不清是"机制没有"还是"这条线画低了"。两道一起红才是机制问题；
只有一道红、另一道绿，高度怀疑是凑着分数线做的。

"一换"指第二道不改考的东西，只换一个条件：换个地形、换个兵种、数量加一、金币少 100。
它的作用不是考新能力，是**证明这道题考的是机制而不是地形**。

第 3 级是唯一已经够两道以上的（5 道），第 4 级刚好一对。第 5、6 级要补/拆（见第五节）。

### 3.3 加一法：新题 = 最近一道绿题 + 改一处

这是把"步子大小"从感觉变成数字的那一条。

**做法**：拿你最近一道已经绿的题，只改一处，变成新题。改一处（加一个守军 / 把一座桥改成两座 / 少给 100 金 / 把敌人挪近两格）：

- **红了** → 就是这个改动代表的那项能力缺。红在哪，答案就是哪。
- **绿了** → 这个改动没考到东西。它从"考题"降级成"护栏题"（防退化，不计成绩）。
- **改两处以上** → 红了也归因不了。**不许**这样做。

这条已经无意中验证过一次：S-016（空城、城下没人、直接砸）绿了之后，加 4 个守军，长成 S-017（先清场再砸）。
一道改动，一次就抓出了真 bug——打分层把"按计划走一格"排在"攻城"前面，兵贴着城墙被派去走位。
那就是标准做法，只是当时当成了一次性的运气。

**"步子"= 新题与最近一道绿题差几处，目标是 1。**

拿这个尺子量现在的题：

| 题 | 相对最近一道绿题差几处 | 判断 |
|---|---|---|
| S-017 | S-016 + 加 4 个守军 | 1 处，标准做法 |
| S-013 | 要从"一对"跨到"两路同时"，中间缺一整级 | 远超 1 处 |
| S-002 | 推进、队形、清场、攻城、兵种交换、伤亡 | **6 处** |

六处的题出现在第三级的位置上，红成"城伤 39"就完全正常——没有人能从这一个数里推出该改哪。

### 3.4 三段观测：红的时候要能看出断在哪一环

现在一道红题只给一个数（城伤 39 < 45）。这个数说"没做到"，不说"断在第几步"。
而"散乱"的一半感受来自这里：题和题之间没有关系，每题红了都是一个新的谜。

做法：每道题除了最终判据，再记两三个**中途观测点**，按三段：

1. **开动了吗**：第 3 手，有几个兵朝目标方向动了；
2. **到位了吗**：第 5 手，有几个站到了能打的格子上；
3. **达成目的了吗**：第 N 手，战果多少——**这才是判据**。

前两段只记录、不判红绿。这样一道红题会自己说出"我是第二段断的"，
而第二段断通常意味着**上一级的题该红**——于是人被送回该修的那一级，而不是在这道难题上瞎调。

三段观测还有个副作用：它们顺带就成了"这道题能不能用"的体检。
如果第一段永远是 0，这题根本进不了"考了什么"，得退回病历。

### 3.5 读数口径

三句话，都是冲着"步子太大"来的：

1. **地板绿不是成绩，是入场券。** 现在 8/13 里 5 个是地板题（v1 也绿），把它当成绩会误判进度。
   阶梯的进度只看"最高一级全绿的是第几级"。
2. **"超过 v1/v3"只对第 6 级往上成立。** 第 1~3 级 v1 本来就是对的，要求"超越"没有意义，只会逼你把题写难。
   现在老觉得红得莫名其妙，就是因为拿第 6 级的题当第 3 级的验收。
3. **降步子靠拆题，不靠降分数线。** 把 45 改成 35 让它变绿，就是 v3 那个病（拿分数表达"必须"）。

## 四、和现有规矩冲突的地方，要改哪几条

阶梯不是推翻旧规矩，是给几条规矩加前提。逐条对：

| 旧规矩（出处） | 现在的问题 | 改成 |
|---|---|---|
| 新题必须先红（PLAN 5.5 第 1 条） | 地板题、护栏题天生就是绿的 | 分两类：**探路题**（必须先红，用来开发）/ **护栏题**（允许绿，用来防退化）。两类在题卡上明写 |
| 只动一道题 = 高度怀疑补丁（PLAN 5.5 第 10 条） | 一级只有一道题时，"只动一道"是正常的 | 先问"这一级有几道题"再判断。所以 3.2 那条"每级两道"是这条前提 |
| 一道题 = 六个文件（GUIDE 第五节） | 有效 | 不变；题卡头部加三行：**第几级 / 上一级是哪道 / 这一级多了什么** |
| 判据只能用四种形态（README 第七节） | 有效（数量、次数、状态、累计量） | 不变 |
| 判据必须先被跑绿（PLAN 5.5 第 7 条） | 有效 | 不变，另外三段观测的第一、二段也要有观测样本 |
| 题库会腐烂，定期体检（GUIDE 第十二节） | 有效 | 不变；失效报告里多一列"属于第几级" |
| 种子卫生（README 第十节） | 有效 | 不变 |

## 六、补题顺序

按"补了之后能立刻判断什么"排，不按难度排：

1. **第 1 级 2 道**（半小时的事：一个兵、无敌人、走到指定格；一个兵、中间隔一格水要绕）
   —— 补完立刻能回答"v4 全红时，是连走路都不会，还是只是走得不好"。这是现在最缺的一句话。
2. **第 2 级 2 道**（重做"死水不造船""不修多余的桥"这类"不该做"的题）
   —— 这一级的题天生容易写（判据是"没做某事"），成本最低。
3. **第 7 级 2 道**（兵多敌少、限时拿下；一道空城版、一道有少量守军版）
   —— v3 最大的洞，也是 S-012 收尾半的落点。
4. **第 5 级补 1 道**（S-013 的简化版：两座城、每路只有 2 个敌人、没有地形障碍）
   —— 让第 5 级有"一主一换"，否则 S-013 一红就整级废掉。
5. **第 6 级先不补**，等 3~5 级全绿。四级都红着的时候补第六级的题，等于又回到"跳级"。

## 七、代价与风险

| 风险 | 说明 | 预案 |
|---|---|---|
| 阶梯训练出"每级都会、合起来不会" | 每一级都单独验，可能出现只会做一格的题 | 每三级放一道**故意混着**的题，判据只和上一道混合题比；整局体检照旧跑 |
| 补底下两级短期看不到 v4 变强 | 这几天全是写题，不碰大脑 | 事先接受。换来的是"每次红都知道红在哪"；现在 19 个题目目录里 4 道废题、1 道冻结、1 道半废，就是没这一步的代价 |
| 8 级分法本身拍脑袋 | "会挪一格"和"不做无用功"可能该合成一级 | 见第八节待拍板；分法错了只影响标签，不影响任何一道题的写法 |
| 每级两道让题量翻倍 | 从 13 到 18 左右 | 护栏题可以很便宜（小局面、几行判据）；真贵的只有第 6、7 级 |
| 又滑回"看题数当进度" | 18 道绿 12 道听起来比 8/13 好，但可能都是底下几级 | 进度只看**最高一级全绿的是第几级**，不看总数 |

| 4 | S-000 要不要改名 | 改。名字错了会让人往错的方向看第一眼 |

## 附：这份文档的维护规矩

- 阶梯的级数只增不减；要合并某两级，必须说明"合并后哪一类红不再可区分"。
- 新题进库必须在题卡头部写三行：第几级 / 上一级是哪道 / 这一级多了什么。
- 负结论（哪种排法试过不行）进第七节，别删。
- 每次阶段性改动，`.workbuddy/memory/` 当日日志留一行指针。
