# 奇想扩展全兵种总表

> 由 `npm run fantasy:table` 生成，不是手抄。**数值**来自当前代码，**出场/战斗**来自
> 400 局双 AI 跑批（`results/bf-modern*`，200 局火药开局 + 200 局信息化开局，20×20）。

## 口径

```
输出 = 物理 max(0, 攻 − 靶子护甲) + 魔法 max(0, 魔攻 − 靶子魔抗)，按三档靶子加权；
       带破甲的兵，靶子护甲砍半
生存 = 血 × Π(名义攻击 / 实受伤害)^w，威胁谱 = 轻 20(0.32) / 中 45(0.26) /
       重 80+破甲(0.20) / 法师 10 物 + 28 魔(0.22)
战力     = (输出 × 生存)^0.55 × 射程 × 移速 × 视野 × (1 + 能力)
性价比新 = 战力 / 价格^0.55              ← 报表 / 审计口径（unit-value.ts）
性价比旧 = 攻×√血×射程 / 价格^0.8        ← **AI 采购默认用的这一把**（ai.ts 的 oldEfficiency）
采购分   = min(26, 性价比旧 × 3)          ← AI 采购打分里"划不划算"那一段的实数
建造     = 400 局里被招募/建造的次数，`火药批/信息化批` 各 200 局（不含召唤、分裂、孵化）
交换比   = 累计输出伤害 / 累计承受伤害，> 1 表示换血换得赚
```

**两把尺子必须分清**，否则整张表会被读错：
AI 买不买看的是"性价比旧"，它完全不看移速、视野、能力，价格指数还更陡（0.8 对 0.55）。
"性价比新"只在报表和审计里出现。同一行里两个数差得远，本身就是一条信息：
差得越多，说明这个兵的价值越集中在"AI 算不出来的部分"（机动、射程外的东西、光环）。

> · **战力**：均势口径（`tempo = 0`）。**压上/龟缩**：同一兵在 `push` / `turtle` 姿态下的战力，
>   两者之差就是"这个兵多依赖主动进攻"——移速、飞行、冲锋、掠空在压上时更贵，
>   盾墙、回血、护甲光环在龟缩时更贵。
> · **名次**：按性价比新排，只在本表这 64 个奇想战斗兵内部比，不是全兵种表的名次。
> · 只说"贵不贵"，不说"该不该买"：治疗光环、召唤、破城这些价值按权重近似计入 `能力` 一列，
>   但它们的真正价值取决于阵容，表里看不出来。
> · **0 建造有两种意思**：真的一次没被造过，或者这一档在两批开局里都摸不到。
>   后者看"只能召唤"那一列——召唤物本来就不进兵营，建造恒为 0。
