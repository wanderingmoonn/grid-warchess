# 奇想扩展全兵种评分表

> 由 `npm run fantasy:table` 从 `src/core/unit-value.ts` 直接算出，不是手抄。
>
> 口径：
>
> ```
> 输出 = 物理 max(0, 攻 − 靶子护甲) + 魔法 max(0, 魔攻 − 靶子魔抗)，按三档靶子加权；
>        带破甲的兵，靶子护甲砍半
> 生存 = 血 × Π(名义攻击 / 实受伤害)^w，威胁谱 = 轻 20(0.32) / 中 45(0.26) /
>        重 80+破甲(0.20) / 法师 10 物 + 28 魔(0.22)
> 战力 = (输出 × 生存)^0.55 × 射程 × 移速 × 视野 × (1 + 能力)
> 性价比 = 战力 / 价格^0.55
> ```
>
> · **战力**：均势口径（`tempo = 0`）。**压上/龟缩**：同一兵在 `push` / `turtle` 姿态下的战力，
>   两者之差就是"这个兵多依赖主动进攻"——移速、飞行、冲锋、掠空在压上时更贵，
>   盾墙、回血、护甲光环在龟缩时更贵。
> · **采购分**：AI 采购打分里"性价比"那一段的实数，`min(26, 性价比 × 3)`；
>   带 ★ 的是撞了封顶的——它们之间的性价比差异在 AI 眼里已经**不存在**了。
> · **名次**：只在本表这 64 个奇想战斗兵内部排序，不是全兵种表的名次。
> · 只说"贵不贵"，不说"该不该买"：治疗光环、召唤、破城这些价值按权重近似计入 `能力` 一列，
>   但它们的真正价值取决于阵容，表里看不出来。
