## 一、先说清一件被我写错的事：桥**不是**"人一走就塌"

上一份文档我写了"桥是单位，人一走桥就塌"，错了：

- 桥是 `category: 'building'`、**`move: 0`** 的建筑（木桥 45 / 石桥 85 / 钢桥 140 金），
  它占一格水面、把脚下地形改成"桥"；
- **它不会自己走开**；只有**建筑被拆掉**时，`syncBridges` 才把地形还原成桥下的样子。
- 所以一条 5 格宽的河要造 **5 座桥建筑**（+ 工人的建造动作），不是"吃掉 5 个战斗单位"。
  v3 也没有编制上限，不存在"桥占编制"这回事（那两处 v1 遗留注释已删）。

同理，`docs/ANALYSIS-BIGMAP` 里"19 座桥 ≈ 19 个单位的编制"已经改成"19 座桥按石桥算约 1600 金建材"。

## 二、修了什么

三处都要求"**抢下来守得住**"，判据不新拍数字：

```
安全 = 视野里没有任何敌兵「下回合就能打到这座废墟」
     = enemyThreatAt(废墟格).n === 0     // 判据是敌人的「移动力 + 射程」，和"城下有人"同一把尺子
```

1. **朝向废墟的坡度**（走位）：不安全时按"掏不起钱"那一档走（而不是 35/格），
   别让整支部队被一座抢不住的废墟拴住；
2. **踩进去的接管分**：不安全 → 不给 +220，改成 −90（等于"别进去"）；
3. **攒重建费**：`savingFor='rebuild'` 只在安全时启用——不安全的废墟不给它冻结采购；
4. **反复易手降权**：接管分和坡度都乘 `1/(1+n)`，n = 这座城被接管过几次。

### 易手次数怎么数（这里有个坑）

不能用"归属变没变":**废墟被打空不改归属**，同一方可以反复接管自己那座被打空的城，
按归属计会漏掉一大半（实测一座城 22 次接管里，绝大多数是同一方回头再进）。
所以用 `capturedTurn`（每次接管都会重写）来数，存在 `AiFocus.ruinFlips` 里（跨回合记忆）。

降权用 `1/(1+n)` 而不是"5 回合内几次"：不需要时间窗口，也不会过期——
抢过三次的地方，抢第四次只会更亏。

## 四、四组对照（对手固定 `baselines/ai-9efb961.ts`，每组 24 局）

| 组 | Q1/Q2（小图） | Q3/Q4（24×24） | 对基线配对 | 均回合 |
|---|---|---|---|---|
| 基线 | 10-2-0 | 11-1-0 | — | 71 / 101 |
| **只开废墟闸** | 10-2-0 | 11-1-0 | **0↑0↓ / 0↑0↓** | 69 / 101 |
| 三件套 | 11-1-0 | 4-3-5 | 2↑1↓ / 0↑7↓ | 60 / 192 |
| **三件套 + 废墟闸** | 11-1-0 | **4-1-7** | 2↑1↓ / 1↑7↓ | 60 / 196 |

**废墟闸叠在三件套上：配对 2↑0↓**（其余 10 局逐局相同）：

```
Q3|31|A   三件套 负 250 → +废墟闸 平 261   ↑
Q3|32|A   三件套 负 224 → +废墟闸 平 261   ↑
其余 10 局：胜/负/平与回合数一字不差
```

**两个结论**：

1. **对基线是 no-op（0↑0↓）**。基线本来就不去抢废墟——那个病要等三件套把兵推到城下
   才出现。所以这一条**不是"修了一个所有局都受益的 bug"，是"给三件套配套"**。
   这一点必须记清楚，别以后拿它去解释基线的胜率变化。
2. 它把两局"负"拖成"平"，但**没把任何"平"变成"胜"**。大图剩下的 7 局平/负还是
   "打不动/打不完"，下一个该动手的是**渡口**（P0-6：19 座桥、240 回合"不通"），不是继续调废墟。
