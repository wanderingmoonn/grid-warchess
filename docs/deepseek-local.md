# DeepSeek 本地操控者

启动 `npm run dev`，访问 http://127.0.0.1:5178/，在顶栏点击「模型操控」。面板显示本机凭证读取状态；点击「执行本回合」才会调用 DeepSeek。模型只收到当前方的观察，一次返回一个动作，再由规则内核执行。

每批最多 12 次请求，结束回合后停止。达到上限、超时、服务故障或连续无效动作也会暂停，已经执行的合法动作照常保存。关闭面板或点击「暂停并接管」会取消等待，迟到回复不能修改局面。打开面板会暂停算法 AI；模型完成后由用户决定继续操控、恢复算法或手动走棋。模型接管不改写指挥官生产队列。

## 凭证配置

本机已按用户授权复用原项目的 Windows 加密凭证，只在被 Git 忽略的 `.env.local` 中记录文件位置。其他机器可参考 `.env.example`，任选：

```dotenv
DEEPSEEK_API_KEY=你的本机凭证
# 或者使用当前 Windows 用户加密的 SecureString 文件
DEEPSEEK_CREDENTIAL_FILE=加密文件绝对路径
DEEPSEEK_MODEL=deepseek-flash
```

修改配置后重新启动 Vite。代理优先读取环境变量中的密钥，其次读取加密文件；解密结果仅在代理内存中使用。Windows PowerShell 子进程固定使用自己的模块路径，兼容从 PowerShell 7 启动开发服务器的情况。不要给凭证变量添加 `VITE_` 前缀。

## 调用边界

| 项目 | 当前值 |
| --- | --- |
| 模型 | 默认 `deepseek-flash`，可配置 `deepseek-v4-pro` |
| 输出 | JSON 对象，关闭 thinking，最多 512 个输出 token |
| 单次截止 | 代理 30 秒，页面执行器 35 秒 |
| 输入大小 | 128 KiB UTF-8 JSON |
| 并发/预算 | 单个请求，每个代理进程每小时最多 120 次上游尝试 |
| 自动重试 | 无；错误后暂停 |
| 联机 | 模型入口禁用；仅本地对局 |
| 发布部署 | `PORT` 发布模式禁用代理；静态 `dist/` 本身不提供模型接口 |

代理限制回环连接与本机同源 POST，固定上游地址，不接受浏览器指定密钥、模型或远程端点。响应、日志和游戏存档不携带凭证。此功能不改变原联机架构的服务端防作弊边界。

模型与 JSON 请求格式参考 [DeepSeek 官方模型文档](https://api-docs.deepseek.com/quick_start/pricing/) 和 [JSON 输出文档](https://api-docs.deepseek.com/guides/json_mode/)。服务商模型可能更新，代理模型白名单需随官方变更维护。

## 验证记录（2026-10-25）

`npm run test:model` 使用内存上游，验证代理约束、协议解析、界面和换局取消，不产生 API 用量。

全量离线验证共 435 项通过，其中新增代理测试 16 项、面板与客户端测试 6 项、页面生命周期测试 3 项。类型检查、生产构建、规则书同步及 Git 空白检查通过；实际浏览器已确认本机凭证状态和执行入口。浏览器构建中不包含代理凭证变量及 DeepSeek 上游地址。

显式执行 `npm run test:model:live` 会访问已启动的本机代理，最多发出 3 次真实模型请求。测试只操作固定种子的内存局面，不读取或覆盖用户存档。本轮结果：`RECRUIT → RECRUIT → END_TURN`，3 条动作均通过规则校验，0 次拒绝，约 3 秒，正常交接回合。该结果证明接口可用，尚不能判断长局棋力、成本或稳定性。
