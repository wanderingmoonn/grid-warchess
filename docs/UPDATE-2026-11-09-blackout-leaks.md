# 浓雾两处信息泄漏（2026-11-09）

> **2026-11-10 修订：点击那条改口径了。**
> 同一天另一条线把遮蔽做到了面板层（`PlayerView.terrainHidden` + 「未探明」/
> 「记忆里的地形（可能有变）」），比这里"toast 一句就吞掉点击"信息量更大。
> 于是撤掉了 `refuseLook` 硬拦：**浓雾里也能点开，但只写「未探明」，不写数值**。
> 城市卡原本没走那条闸门（它走 `selectedCityId` 这个入口），当天补齐了——
> 黑掉的城市现在也只写「未探明 + 上次看到谁在占、什么时代」。
> 染色那条（`onlyVisibleCells`）保留，且合并时被对方扩成"有雾就裁"（不只浓雾）。

「浓雾蔽野」（`blackout`）的规则是**连地形和城一起遮掉**：视野外只剩一片黑，
城市要侦察到才画得出来（`board.ts` 的 `.tile.unknown`）。棋盘确实这么画了，
但"看一眼"和"给视图染色"这两条路上没人管，于是黑雾白送侦察。

## 一、点黑格能读到里面是什么

点击流程里"只看不操作"的入口有六处，原来一处都没拦：

| 入口 | 原来的后果 |
|---|---|
| 点敌方单位 → 属性卡 | 黑区里的兵能读到射程/血量 |
| 点城市格 → 城卡 | **黑区里的城能读到护甲和耐久**（最严重的一条） |
| 点空地 → 地形卡 | 黑地写着"森林 / 丘陵 / 平原" |
| 轮不到我 / AI 行动中 / 指挥官模式 | 走 `inspectAt`，同上 |
| 复盘 | 走另一条只读分支，同上 |
| 观战位 | 同上 |

修法：判据收成一个函数，六处调同一个。

```ts
// core/fog.ts
export function isBlackedOut(s, p, x, y): boolean   // 开雾 + 勾了 blackout + 不在视野
```

`main.ts` 里包一层 `refuseLook(coords)`：黑格就 `toast('浓雾里看不清那儿')` 并返回，
绝不落到任何属性卡。

**位置很讲究**：闸门放在"动作分支走完之后、查看分支之前"。
放在函数最上面会连下水点、施法落点、强制移动、过桥一起拦掉；
黑格本来也不可能出现在 `reach` / `targets` 里，所以拦在这一段不会误伤走子。

## 二、天气视图给黑区染了色

`computeBoardView()` 把扩展给的 `cells` 直接铺到棋盘上。天气是由**地形和位置算出来**的：

- 看到"这一片在下雨"就知道那边不是沙漠；
- 再配合「温和不画」（温度正常不染色），黑区的**边界**能反推出地形轮廓。

修法：闸门放在 `computeBoardView()` 一处，而不是各个扩展的 `cells` 里——
所有棋盘视图（天气、灵气、热度……）都走这条路，逐个扩展去记得"我该不该过滤"迟早漏一个。

```ts
// core/fog.ts
export function onlyVisibleCells(s, visible, cells): readonly T[]   // 没开雾时原样返回
```

**合并后收紧了**：原来只在「浓雾蔽野」下过滤，现在**有雾就过滤**。
理由是有雾的局里这张图不只是"天气"——灵气浓度里掺着对面灵田、灵泉的贡献，
整张铺开等于白送一张敌方建筑分布图。地形本身在基础雾里是公开的（棋盘一直画着），
但**由地形和建筑推出来的场**不是。第二个参数也从 `playerId` 换成了
"这一帧 `playerView` 已经算好的可见格列表"：观战与复盘拿到的本来就是全图，
不必再在函数里判断"是不是在观战"。

## 三、开/关行为对照（jsdom 跑真入口核验）

同一局 `16×16`、同种子，只改扩展列表：

| 场景 | 点黑格空地 | 点黑格城市 | 点看得见的格子 | 天气染色 |
|---|---|---|---|---|
| **勾了浓雾** | 面板没动 | **面板没动** | 正常弹出 | 36 格，**0 格落在黑区** |
| 只勾季节 | 弹出地形卡 | 弹出城卡 | 正常弹出 | 只染视野内（原来 144 格全图） |

未开浓雾时 `isBlackedOut` 恒 false，所以"能点开看看"这条路上，
不勾扩展和勾了扩展的交互一格都没变；但**染色**这条路口径统一成了"有雾就裁"，
只勾季节的局也会少了视野外那一片——这是有意的，见第二节。

## 五、边界

- 上帝模式、**观战位、复盘**都不拦：它们的棋盘是 `playerView(..., true)` 画的
  （满屏没有一格是黑的），拦了反而不一致。`blackedOutAt` 里显式放行后两者——
  这是合并时补的：复盘原来会被拦掉一半地图。
- 其他棋盘视图（灵气/热度）走同一个闸门，本次一并修好；`heat` 层本来就只画
  `visibleSet` 里的格子，不受影响。
- **侧栏还有第二道闸**（`ui/panel.ts`）：黑格点开会回一句"看不清"，但
  `selectedTile` 是会被留下的——你的侦察兵走开、这一格重新落回雾里时，
  面板会按"记忆里的地形"重画，没有记忆就写「未探明」，扩展行（灵气/天气）
  一律不下发。点击那道闸挡住了"主动去点"，这道闸挡的是"选中之后才变黑"。
- 已知的小别扭：浓雾里棋盘会画出**记忆中的**地形，但点它只回一句"看不清"。
  要放宽成"按记忆出地形卡"，得先给"点城""点单位"两个分支各加一道闸
  （城卡会报护甲和耐久），这次没做。
