# P1-3 回放（2026-11-23）

四份回放，都是 `bench-queue.ts` 的同一套配置复现出来的（导出脚本逐行复制 `playOne`，
开关也一起带上了，否则就不是同一局棋）。

> 回放文件**不进版本库**（`results/*` 在 `.gitignore` 里）。要复现同一局：
>
> ```bash
> node --experimental-strip-types scripts/export-bench-replay.ts \
>   --queue Q1 --seed 31 --new-side B --hub --out results/replays/p13/p13-q1-31-B-hub.json
> # 其余三份把 Q1/31/B 换成 Q3/31/A、Q3/30/A、Q4/30/A（都带 --hub）；
> # 第 2 份（base）去掉 --hub。
> ```
>
> **开关必须和跑批一致**，否则导出的不是同一局棋。

**怎么看**：游戏首页「复盘」→ 选文件（或直接把 json 拖进去）。
逐回合的城视角时间线用：

```bash
npm run replay:city -- results/replays/p13/<文件>.json --every 20 --side B
```

图例：`c3 e↑4 hp99 产8(musketeer,…)` = 这座城这 20 回合里**升到了第 4 代**、
血量 99、从它这儿造出 8 个兵（括号里是兵种）。

## 1. `p13-q1-31-B-hub.json` — **P1-3 起作用的样本**（新版胜 90）

Q1 / 12×12 / era2 / seed 31，新版坐 B，带 `--hub`。
基线同一局是 **负 79**（见第 2 份）。

```
T 11  c3 e↑3 hp81 产2(planter,engineer)      · c4 e2  hp63 产2(farmer,militia)
T 21  c3 e3  hp81 产6(planter×4,musketeer,…) · c4 e2  hp63 产4(herder,lumberjack,…)
T 31  c3 e↑4 hp99 产4(musketeer,planter,…)   · c4 e2  hp63 产3(longbow,longbow,spearman)
T 41  c3 e4  hp98 产8(rifleman×4,musketeer…) · c4 e2  hp55 产4(longbow…)
T 61  c3 e↑5 hp120 产10(…,tank,squad)        · c4 e↑3 hp80 产5(halberdier…)
T 81  c3 e5  hp120 产11(squad×5,artillery×3)  · c4 e3  hp52 产1(laborer)
终局 B（90）
```

**看这里**：升级从头到尾压在 **c3 一座**上（e3 → e4 → e5），产兵也跟着集中到 c3；
c4 一直到 T51 才被升到 e3，只负责补边角。**e5 的城在 T61~T81 连造新兵种**
（tank / artillery / squad），兵从 6 涨到 8 并赢下。

## 2. `p13-q1-31-B-base.json` — 同一局的**基线**（新版负 79）

```
T 11  c3 e2  hp63 产1(militia)              · c4 e↑3 hp81 产6(…)
T 21  c3 e↑3 hp81 产1(planter)              · c4 e3  hp81 产1(planter)
T 41  c3 e↑4 hp99 产3(halberdier×2,hussar)   · c4 e3  hp81 产2
T 51  c3 e4  hp85 产5(rifleman×4,militia)    · c4 e↑4 hp99
T 61  c3 e4  hp85 产9(agribusiness,farmer,…) · c4 e↑5 hp120 产1(squad)
T 71  c4 e5  hp111 产7(artillery,crossbow,…) · c3 没了
终局 A（79）
```

**看这里**：升级在 c3 / c4 之间**交替**（T11 c4 先升，T21 c3 追，T41 c3 反超，
T51 c4 追）——两座城始终只差一代，谁也没到顶。T61 c3 那一格产的 9 个兵里有
5 个是经济单位（agribusiness / farmer / planter / lumberjack×2）。
到 T71 c3 丢了，只剩一座 e5 的城在硬撑。

**两份对着看**：同样的钱，交替升 = 两座中等城；集中升 = 一座 e5 + 兵源稳定。

## 3. `p13-q3-31-A-hub.json` — **三局负之一**（新版负 118，基线负 84）

Q3 / 24×24 / era2 / seed 31，新版坐 A，带 `--hub`。

```
T 21  c1 e↑3 hp49 产9(herder,farmer,guboat…,musketeer)  · c2 e2 hp63 产11(lumberjack…archer)
T 41  c1 e↑4 hp99 产8(rifleman×4,musketeer…)            · c2 e↑3 hp81 产3
T 61  c1 e4  hp99 产4(rifleman,engineer…)               · c2 e↑4 hp69 产2
T 81  c1 e↑5 hp120 产5                                  · c2 没了
T101  c1 e5  hp120 产10(mg×5,rifleman×3,archer,musketeer)
终局 B（118）
```

**看这里**：枢纽城 c1 升得比基线快（T21 e3、T41 e4、T81 e5），
**但兵一直只有 5~13 个**，对面到 T101 是 17 个。T21 c1 血量只有 49（挨打中）。
这一局 P1-3 想要的效果达到了（升级压在需要出兵的那座城），但**守不住**——
升级加的那点耐久扛不住 24×24 上的一波流。基线是 84 回合就被速推，这里是 118。

## 4. `p13-q3-30-A-hub.json` / `p13-q4-30-A-hub.json` — **"兵多但打不完"**

两份都是 261 回合平局（基线分别是胜 109 / 胜 101）。

```
Q4|30|A  T 61  c1 e4 产12 · c2 e↑5 产27(artillery,tank,squad,…)
         T121  c1 e4 产10 · c2 e5 产25
         T241  兵41 经12 金511
Q3|30|A  T 81  c1 e↑5 产15(squad×6,ironclad,tank,…)  · c2 e4 产5
         T241  兵29 经12 金389
```

**看这里**：`squad` / `tank` / `artillery` 一串串出来，兵堆到 29 / 41 个，
对面只剩一两座城，**261 回合没打下来**。这是 P1-3 最值钱的一条副产品：
现在卡的不是产兵，是**收尾**（进攻配额 P0-2、`commit` 门槛写死 8 兵 P2-3）。
