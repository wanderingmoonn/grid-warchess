# 上帝模式：看得清、找得到、少点几下

**v0.3.35（2026-11-05）** · 另外合并了 GitHub 上的光环引擎重构

这一版只动上帝模式（沙盒），四个地方：

## 1. 点一下就看到完整属性，不再只有一句血量

以前在沙盒里点一个兵，只弹一句「名字 24/24 血」。光环、规则加成、真实数值、
技能按钮——全都没有。而"这支兵站在那条光环里到底剩多少攻"恰恰是摆沙盒最想验证的事。

现在侧栏直接显示**和亲自指挥一模一样的那张属性卡**：生命、攻击、护甲、射程、
光环与规则加成之后的真实数值、英雄技能按钮、上下船入口。

做得上是"直接复用"而不是"照着重画一份"：两份卡片的数字必须同源，
否则迟早会出现"沙盒说 12、实战打出来 15"这种事。

## 2. 货架能按字搜了

高时代一屏四十多个兵种，找"长弓手"要翻半天。现在货架上有一个搜索框，
和产兵面板**同一套匹配规则**（名字 / 代号 / 职能 / 时代 / 包名，多词按"且"处理），
样式也一样。

输入法那条坑这次是共用一份代码解决的：中文组字期间**不重绘**，
组字结束再统一重画一次，重画之后把焦点和光标还回框里。
两个搜索框走同一个实现——把那段逻辑复制第二遍，等于把同一个 bug 复制第二遍。

## 3. 操控档简化：默认两边我都打

原来有三颗 chip（只摆放 / 我打某一边 / 两边我都打）。沙盒的用途就是自己演一遍，
那三颗 chip 反而让人以为"点了会换一种模式"。现在：

* **默认两边都由你走**，点棋盘就是走子 / 开火；
* 想歇手只剩两颗按钮：**「交给 AI · 一回合」**（两边各推一回合后交还）和
  **「接管 · 打到全灭」**（一直打到一方没兵，随时可以按停止）。

## 4. 快捷模式：空格结束回合

「结束回合」下面多了一个开关。打开之后**按空格**直接结束回合——
摆一场歼灭战要按十几次，鼠标每次横跨半个屏幕。

三个守卫都做了：正在打字时不抢空格；焦点在按钮上时不抢（那是"激活这个按钮"）；
按住不放只认第一下。开关记在本地，刷新之后手感不变。

## 一并合入：光环引擎重构

GitHub 上的 `447093b`（光环引擎瘦身、支持自定义半径、清理历史遗留 bug）
连同修真分支的两个修复一起合进来了。规则测试 564 项全过，其中新增的几条
（数组格式多光环共存、2×2 大单位按体积最近边算距离、动态效果型光环的半径传参）
就是这次重构的验收。
