# 《时代与回旋镖》v0.3.23 更新公告

**发布时间：2026 年 11 月 4 日**

## 更新概述

**六个时代改名了**，从"按年代分段"改成"按技术代分段"：青铜、铁器、火器、蒸汽、机械化、信息化。
跟着改名一起动的有两件事——几个年代错位的单位被挪回它们该在的那一代，
低时代补上了东方的军备（戈、弩、楼船，以及青铜会战包里的努比亚弓手、青铜剑士、旌旗车）。

## 更新内容

**时代改名**

| 旧 | 新 |
|---|---|
| 古典 | **青铜时代** |
| 中世 | **铁器时代** |
| 火药 | **火器时代** |
| 工业 | **蒸汽时代** |
| 二战 | **机械化时代** |
| 现代 | **信息化时代** |

开局面板的按钮用短标（青铜 / 铁器 / 火器 / 蒸汽 / 机械化 / 信息化），鼠标停一下能看到全名。
**只改显示名**：时代等级、存档、地图种子都没动，进行中的对局不受影响。

**单位换到它该在的那一代**（造价与数值同步上调）

- 重装步兵、弩炮、军团兵、战象：青铜 → **铁器**。它们是希腊方阵、罗马军团和希腊化战象，
  放在"青铜"里原本就早了几百年；四个也一起挪进了「铁器兵备」包。
- 卡拉克帆船、宝船：铁器 → **火器**。15 世纪的大帆船不该出现在铁器时代的海面上。
- 康格里夫火箭（1804）留在火器时代——它正好是这一代的尾巴；农业公司留在蒸汽时代
  （它原本在信息化时代，是因为"解锁太晚、回本窗口不存在"才挪下来的，挪回去等于撤销那个修复）。

**新增兵种：东方军备**

- 原版（人人都有）：**戈兵**（商周，破甲，专治甲片之间的缝）、
  **弩兵**（战国—汉，射 3 + 破甲，和长弓分成"破甲 / 射程"两条路）、
  **楼船**（汉，慢而厚的水上堡垒，补上"舢板 → 炮艇"之间空着的一代水战）。
- 「青铜会战」包：**努比亚弓手**（射程最远也最脆）、**青铜剑士**、
  **旌旗车**（光环指挥——第一代终于有了支援兵，以前编制里那 15% 支援份额是买不到东西的）。

**修复**

- **上传对局报告时的报错终于说人话了**。以前服务端拒收时，界面统一写"上传没成功：网络不通"，
  明明不是网的问题。现在"报告没过结构校验"和"网络不通"分开报，并提示把 `.json` 留着。

## 温馨提示

网页版**刷新一次**即可拿到新版；自行部署请更新代码后重新构建。

- 命名只影响显示，**老存档照常读**（存的是时代等级 1~6，不是名字）。
- 这一版动了兵种池，但**还没做平衡测量**：新兵种会不会让某一代突然变强，得跑一批
  同种子对局才知道。如果你觉得某一阵线突然好打/难打，把局面报上来（「反馈」按钮会带上
  版本号 0.3.23），那就是最直接的证据。
