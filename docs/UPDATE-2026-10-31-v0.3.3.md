# 版本 0.3.3 · 2026-10-31 · 奇想：五个单位调整与两条现代龙

这一批全在「奇想·英雄」包内：两项面板调整、三项新内容（两个英雄 + 一条孵化的龙），
外加为它们开的三条小机制。逐条写在下面。

---

## 一、暗夜死灵法师：降到火药、整体下调

| 项 | 旧 | 新 |
|---|---|---|
| 时代 | 4 工业 | **3 火药** |
| 造价 | 420 | **320**（解锁费 200 → 160） |
| 攻 / 血 / 甲 | 22 / 88 / 4 | **18 / 76 / 3** |
| 魔攻 / 魔抗 / 视野 | 18 / 4 / 5 | **14 / 3 / 4** |
| 移速 / 射程 | 3 / 3 | 3 / 3（不动） |

**为什么降时代**：招魂的价值等于"被拉回来的那个兵值多少钱"，而火药时代正好是
第一个"每个兵都值一笔钱"的时代。放在工业，它永远比战场节奏晚一步；放在中世又太早。

**复活范围 +1**：原来只能落在**相邻一格**，现在**两格以内**（由近及远挑第一个空位）。
混战里贴身四格几乎永远占满，"身边没地方站"会成为这个技能最常见的失败原因——
放宽到两格之后，它才真的能救回人。落点仍可预期（先近后远，不随机）。

**影响范围**：只改这一个英雄的数值与招魂落点。招魂的收费、一次性、英雄除外等规则不变。

## 二、神圣骑士长：护甲 12 → 14

它 2 速、150 血、职责是"站在最前面替全队吃伤害"，而 12 甲在工业时代挡不住主流破甲，
2 速的代价却没换来对应的硬度。+2 是对着这个定位补的，其余数值不动。

---

## 三、史莱姆牢大：生命上限 200 → 222

它是"用血换时间"的兵，而现在的集火能力比它上线时更强，200 血经常撑不过两轮。
+22（约 +11%）让它重新回到"想清掉它得专门安排一轮"的位置，别的数值不动。

## 四、圣剑勇者（新，仅「现代」同时开启时出现）

| 项 | 值 |
|---|---|
| 时代 / 属性 | 6 现代 / **光** |
| 造价（解锁） | 620（260） |
| 面板 | 46 攻 · 11 甲 · 140 血 · **4 速** · **射程 2** · 视野 6 |
| 攻击 | **直线形溅射**：只扫"自己 → 主目标"那条直线上的敌人 |
| 技能 | **圣剑觉醒**（冷却 3）：永久 +8 攻 / +2 甲 / +30 生命上限，并按新上限回 30% 血 |

**直线溅射怎么实现**：兵种表加了 `splashLine` 标记，`splashVictims` 在圈选之后
再过一遍共线判断（方向由"攻击者 → 主目标"决定，含对角线）。普通溅射是"周围一圈"，
它是"一条线穿过去"——所以站位从"贴一堆人"变成"对准一列人"。

**觉醒为什么是永久**：这个英雄没有位移、没有控场，全部价值压在"给它两三个回合"。
加成写在**单位**上（`atkBonus` / `armorBonus` / `maxHpBonus`），不写兵种表——
兵种表是这一局的公共表，动了它等于全场同名单位一起变强。

**为什么锁「现代」**：46 攻 / 11 甲 / 140 血在火药时代是碾压。没有现代那一套兵种做参照，
它只会变成"开了就能赢"的单件。

## 五、邪龙王（新，仅「现代」同时开启时出现）

| 项 | 值 |
|---|---|
| 时代 / 属性 | 6 现代 / **暗** |
| 造价（解锁） | 640（300） |
| 面板 | 40 攻 · 8 甲 · **190 血** · **2 速** · 射程 3 · **魔抗 12** |
| 属性 | 风 / 火 / 水 / 土 **减半**；光 **翻倍** |
| 技能 | **陨卵**（冷却 3）：6 格内落下魔龙卵，落点周围 1 格内的敌人各吃一发暗属性魔法 |

**属性表走的是既有结算**：`weak: { light: 2 }` 与 `resist: { fire/water/earth/wind: 0.5 }`，
没有为它新开一条伤害规则——所以它和"巨魔怕火"用的是同一套倍率，规则书里也只多两行。

**落点是自动挑的**：引擎的 `HERO_SKILL` 没有"目标格"字段（所有技能都不带目标），
所以按"这一发能打出最多伤害"选位置：把 6 格内每个可站的格子都算一遍覆盖到的敌人总伤害，
取最高的；同样多时取离自己近的。

**魔龙卵与魔龙**：

| | 魔龙卵 | 魔龙 |
|---|---|---|
| 面板 | 0 攻 · 1 甲 · 30 血 · 0 速 · 魔抗 6 | 44 攻 · 10 甲 · 150 血 · 5 速 · 射程 2 · 魔抗 8 |
| 特殊 | **2 回合后孵化** | 飞行（空中层）、同样风火水土减半 / 光翻倍 |
| 产出 | 邪龙王技能 | 卵孵化 |

卵给 30 血是**故意的**：它可以被对面拆掉——"先清卵还是先打龙"正是这个技能想问对手的问题。
孵化按**自己的回合**数（和充能技能一把尺子），换型保留血量比例：半血的卵不会孵出满血的龙。

## 六、为这一批新开的三条小机制

| 机制 | 位置 | 为什么必须新开 |
|---|---|---|
| `requiresPack`（单位级前置） | `types.ts` / `setup.ts` | 包级 `requires` 管"整包进场"，管不了"包里某一件"。条件不满足时这个 id **根本不进 `unitTypes`**，于是产线、选卡池、AI 报价、规则书全都自然看不到它 |
| `splashLine`（直线溅射） | `types.ts` / `rules.ts` | 圈形溅射表达不了"剑气穿过一排" |
| `hatch`（孵化） | `types.ts` / `rules.ts` | 卵→龙是延时换型，不是召唤（召唤会立刻多一个单位） |

配套还加了 `Unit.atkBonus / armorBonus`（永久增益）与 `SkillDef.atkUp / hpUp`，
接入点是 `attackPowerNow`、`effectiveStats`、`computeDamage`——**面板与实战读同一个字段**。

**AI**：两条新技能都进了判断（觉醒在六格内有人时开，越早越值；陨卵只要范围内有敌人就开）。
实测 AI 在这两种局面下都会选中对应技能。
