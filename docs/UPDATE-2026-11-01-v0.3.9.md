# 版本 0.3.9 · 2026-11-01 · 战况烈度

一句话：**轮到你的时候，上一回合被打得最狠的那几格在闪红——闪得越快，那儿打得越凶。**
看一眼就知道该往哪儿补人。规则数值一格没动。

---

## 一、它是什么

上一回合里，对面打过的每一格：

- **被攻击的单位脚下**（主目标）；
- **被溅射波及的每一格**（一发炮弹打到三个人，就是三格各记一笔）。

每格记一个次数 x，轮到你时按 x 闪红：x 越大，闪得越快。

| 次数 | 闪烁周期 |
|---|---|
| 1 | 1.5s |
| 2 | 1.15s |
| 3 | 0.9s |
| 4 | 0.7s |
| 5 及以上 | 0.5s（封顶） |

五档封顶是有意的：再快人眼也分不出来，只会变成一片乱闪。

## 二、什么时候出现、什么时候消失

| 时机 | 表现 |
|---|---|
| 对方回合结束、轮到你 | 红格浮出（不依赖你有没有选中单位） |
| 你走出**第一步**（移动/攻击/产兵/建造…） | 红格整体收起，让位给可达格与可攻击目标 |
| 结束回合 | 不算出手，红格不收——但回合一换，你也就看不到了 |
| 观战 / 不是你的回合 | 不显示 |

## 三、什么算、什么不算

| 事件 | 计不计 | 理由 |
|---|---|---|
| 攻击命中主目标 | ✅ | 对面打出去的 |
| 溅射波及的格 | ✅ 逐格各一次 | 同上 |
| 反击（你打过去被还手） | ❌ | 是对方还手，不是你这一方被"主动攻击" |
| 建筑自动开火 | ❌ | 那是守方在你回合开火，不属于"对方回合的攻击" |
| 中毒 / 灼烧 / 天气扣血 | ❌ | 环境，不是对面打的 |

去掉后两类是关键：混进来，"哪里被打得最狠"就对不上了。

## 四、几条硬约束

1. **视野外的格子不显示**——而且不是"画的时候遮住"，是算的时候就不下发。
   看不见的地方不该告诉你"那边刚打过仗"。
2. **对手的账本不下发**。`heat` 存在对局状态里，`playerView` 会把对手那一份整本删掉：
   他挨打的格子等于他的部队位置，泄漏出去就是白送视野。
3. **每回合自动换一批**。账本按 `回合` 分键，只留最近两回合；新一轮敌方回合打完，
   表自然换成新的；对面没打你，它就是空的。
4. **旧存档照样能打**。`heat` 是可选字段，读不到就是"还没打过仗"。

## 五、实现

| 文件 | 内容 |
|---|---|
| `src/core/heat.ts`（新增） | `noteHeat`（记账 + 只留两回合）、`heatCells`（读上一回合）、`heatStep`（1~5 档）、`visibleHeat`（三条显示规则一起判） |
| `src/core/rules.ts` | 攻击结算的两处记账：主目标、溅射逐个。反击与建筑自动开火**不记** |
| `src/core/types.ts` | `GameState.heat` 可选字段 |
| `src/core/fog.ts` | `playerView` 裁掉对手的账本 |
| `src/main.ts` | 每帧算一遍可见烈度；`heatDismissTurn` 记录"这一回合已出手" |
| `src/ui/board.ts` + `src/style.css` | 格子挂 `heat dN`，内层 `<i class="fx-heat">` 红色呼吸动画 |
| `scripts/build-manual.ts` | 规则书「战斗」章新增「战况烈度」一节 |

闪烁层用独立元素而不是伪元素：`.tile::after` 是可攻击/可达高亮，`::before` 是地形纹理，
两个都占满了，挤进去会互相盖掉。关掉动效的人（`prefers-reduced-motion`）看到的是静态红罩。
