## 二、虚咒是怎么实现的

需求：3 格内敌军攻击力 −25%。

现有的光环（威吓 `foeAtk: -2`、咒域 `foeArmor: -2`）是**减法 + 相邻 1 格**，
两个都不够用：减法对高攻单位近乎无效（−2 打 40 攻等于没削），而且贴脸才好使，
女巫却是全场最脆的法师。

所以给 `AuraSpec` 加了两个字段（`src/core/ability-hooks.ts`）：

```ts
/** 给范围内敌军的攻击力百分比降低（0.25 = −25%） */
foeAtkPct?: number;
/** 上面几条"给敌军"的作用半径（格）。默认 1 = 相邻 */
radius?: number;
```

规则层新增 `hexWeakPct(s, unit)`（`src/core/rules.ts`）：

- **取强不叠乘**：两个女巫贴身仍是 −25%，不会变成 −50%
  （光环类一律按"取最强的一条"处理，和威吓/咒域的层数上限是同一个思路）；
- **上限 0.9**：数据里写错一个 1.5 也不会打出负伤害；
- 生效点两处，和威吓同一处口径：
  - `effectiveStats()`（面板"我的攻击力"）：`atk × (1 − pct)`，并在明细里标一行「虚咒」；
  - `computeDamage()`（真实结算）：在威吓之后、乘算类修正之前按比例削底子。

顺带把 `fearPenalty()` 的判据从 `distance !== 1` 改成 `distance > (a.radius ?? 1)`，
让"半径"对所有 foe-* 光环统一生效。威吓、咒域没写 `radius`，行为一字未变。

## 三、一处需要你确认的语义

「掠空」在本仓库里是一条**已存在**的特性（`fly-over`），它的机制是：

> 飞行，而且**可以和地面单位站在同一格**——它在你头顶，不在你身边。
> 可以掠水、森林丘陵按 1 步算。

也就是说女巫现在是**空中层**单位：地形不再挡她，**地面近战够不着她**，
只有远程、魔法和空中单位能打她。这比"只掠水、仍在地面"（那是 `leap` / `fly`）
强得多。

按你写的"掠空"二字，我实现了 `fly-over`。如果你要的是后者（能过水但按地面兵算），
告诉我一句，换成 `leap` 就行——一行数据。

```

伤害      3格内 16 | 4格外 22      ← 18 − 2（女巫护甲）= 16；24 − 2 = 22
```
