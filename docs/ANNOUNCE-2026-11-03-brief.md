# 《时代与回旋镖》v0.3.21 更新公告

**发布时间：2026 年 11 月 3 日**

## 更新概述

三人和四人局终于有了**自己的地图**：以前这两档其实不画地貌，抽到"随机"永远是同一张空
棋盘；现在地貌从和两人局同一份池子里抽，"随机"是真随机，扩展地貌（高原 / 峡谷 / 沼泽 /
群岛 / 大川）也能用。这一版还带上了**双城市开局**，其中四人局改成了"田字四区"。

顺手修了两个会让人以为游戏坏了的毛病：一是地图放大之后点不动、拖不动；二是一方认输之后，
接手的那一家有一半单位"已经行动过"。

## 更新内容

**新增：多人局的双城市开局**

- 开局面板三 / 四人局上多了**「双城市开局」**开关。每家开局两座城，**丢一座不算出局，两座都丢才出局**。
- **三家**：城摆在外圈八个格点上，每家取相邻两点，**中间那片是主战场**。
- **四家**：整张图切成**田字四区**，每家认领一个象限，两座基地在**自家那块地里随机生成**。
  基地不贴区域边界，两座城之间留出空档；抽出的一对总是"区内最分得开"的，于是
  **一城靠自家外角、一城靠近中央**——后方稳固，前方就是十字路口。四家的布局逐局都不同。
- 两座城**不保证陆路连通**，要连自己修桥。

**新增：三人 / 四人局的随机地貌**

- 地貌池和两人局是**同一份**，"随机"的抽取逻辑也只有一份（两格图那套被 1000 组参数逐字节
  比对过，一点没变）。
- 形状按人数来：四家图是**十字河**（每家守一个象限，去见谁都得过水），三家图是 **Y 形河**
  （沿三家分界线长）；山岭同理，中间山脊、隘口降成丘陵。
- 四人局的连通性**只保证"没有哪一家被山彻底封死"**：水挡路可以造桥、可以飞，
  所以四条河臂上有几处渡口就够了。三家局仍然保证陆路走得通。

**修复**

- **放大之后点不动、拖不动**。根因是拖动一开始就"捕获"了指针，于是放大后的每一次点击都被
  记在了滚动容器上——2 倍缩放下 100% 点不出棋子。现在要拖过 6 像素才算拖动、才接管指针；
  横向拖不动是另一条：样式表里的 `flex` 把内联宽度压回去了，横向只能拖 57 像素、纵向能拖 358。
- **地图右下角一块死区**。那是缩放条和聊天按钮的透明容器铺在上面，吃掉了点击。
- **认输之后接手的一家有单位"已经行动过"**。以前只把"当前行动方"改了个名字，
  上家留下的行动标记没清；现在换手时整轮重置。

## 温馨提示

网页版**刷新一次**即可拿到新版；自行部署请更新代码后重新构建。

- 三人局的双城开局要 16×16、四人局要 20×20，棋盘不够会自动抬上去（开局面板上会直接显示抬之后的尺寸）。
- 旧存档与进行中的对局不受影响：这次没有改任何兵种数值与规则判定。
