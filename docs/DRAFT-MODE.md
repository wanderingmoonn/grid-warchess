# 选卡模式（BP）：禁用、选人、然后开打

> 开局先打一轮 BP：系统抽一个兵种池，双方各禁 1 个、各选 6 个；
> 这一局双方只能造自己选到的，加上骨架（经济/建造/军营/桥）。
> 同时取消"产线只带当前时代和上一代"的下限。

## 一、它改的是什么，不改什么

改的只有一件事：**"这一局能造什么"由 BP 决定，而不是由开局面板的勾选决定**。

不改：伤害、寻路、视野、回合、经济、地形——一律照旧。所以选卡模式可以和
任何扩展、任何地图风格、双人热座或对战 AI 组合。它也不是一个新兵种包，
不进规则书的扩展分册（那本印的是兵种，这里印的是流程）。

## 二、流程

```
  ┌────────────┐  点"开始选卡"  ┌────────────┐  双方同时、互相看不见  ┌────────────┐  蛇形轮流  ┌────────┐
  │  等待开局  │ ─────────────→ │  禁用阶段  │ ─────────────────────→ │  选人阶段  │ ─────────→ │  对局  │
  └────────────┘                └────────────┘   各 25 秒              └────────────┘  各 30 秒/步 └────────┘
   建房 / 贴邀请链接 / 等对面入座
```

**0. 等待开局（lobby，不计时）**

选卡遮罩是整屏的，一盖上去顶栏的「联机」「新对局」就都点不到了——
于是"建房把链接发给朋友"这件事在 BP 期间根本做不到。所以开局先停在这一屏：

- 「联机 · 建房 / 加入」：打开联机面板，建房或进房；
- 有房间之后显示**房间码**与**邀请链接**（可一键复制），以及"等待对面入座 / 已入座"；
- 「开始选卡」：两边任一方点都行（这一步会同步给对面）；
- 右上角还有「跳过选卡」与「退出」（见第六节）。



**1. 禁用（同时、盲禁）**

双方各自挑一个禁掉，**互相看不到对方禁了什么**，两边都交完才一起揭晓。
参照的是 Dota/CS 那套：先交的人不该被后手针对。若某一方禁用位多于 1 个
（扩展全开时会涨到 3），一次交齐。

**2. 选人（蛇形轮流）**

顺序写在 `state.draft.order` 里，是"每轮交换首选权"的蛇形：

```
A B  B A  A B  B A  A B  B A
└─┬─┘  └─┬─┘  └─┬─┘  └─┬─┘  └─┬─┘  └─┬─┘
 第1轮  第2轮  第3轮  第4轮  第5轮  第6轮
```

每人 6 次、各 3 次"这一轮我先挑"。先手优势被摊成"先动一步"，而不是"先挑三个"。
被选走的兵**全局移出池子**——不能用"我也选一个一样的"来对冲。

**3. 超时**

| 情形 | 处理 | 为什么 |
|---|---|---|
| 禁用超时 | 视为**放弃**这次禁用 | 随机替他禁一个，有可能禁掉他自己最想要的兵，那是惩罚不是兜底 |
| 选人超时 | 系统从剩余池里**随机补一个** | 不补就凑不满名单，这一局直接废掉 |
| 没到点的"超时" | 一律拒绝 | 只有时间能决定谁超时，先后点击不能 |

超时的每一条都会进 `history` 和战报，界面上标「（超时）」「（超时代选）」，
赛后能看出这一局是不是有人掉线了。

## 三、规模：池子按"兵的数量"，名额按"兵种体系"

两条不同的尺子，故意分开：

**池子**跟着可进池的兵的数量长——每多 2 个兵，池子多 1 格（上限 60）。
池子太小会让扩展白开：加了 24 个兵却还是抽 20 个，新兵几乎见不到。

**名额**（禁位/选位）按**体系**长，规则是逐条定的：

| 在场的体系 | 禁用 | 选卡 |
|---|---|---|
| 无（原版） | 1 | 6 |
| 只有海军 | 1 | **+1** |
| 只有空军 | 1 | **+1** |
| 海军 + 空军 | **+1** | **+2** |
| 时代军备（`pack-*`） | **+1** | **+2** |

为什么名额按体系、不按兵数：一个体系带来的是**一整套互相制衡**的兵种关系
（船怕飞机、飞机怕防空、各时代的兵互相压制）。多一个体系才需要多一个名额去
"照顾"它；同一个体系里多二十个兵，只是池子更大，不需要更多名额。
这也让规则对玩家可预期：开海军就该多一个选位，而不是"开海军加了多少兵"。

系统按 id 前缀判断在场的是哪一类：`naval-` / `air-` / `pack-`。
按**实际生效的扩展**算（前置没满足的整包不生效，也就不该有任何加成）。

实测：

| 组合 | 池子 | 禁 | 选 |
|---|---|---|---|
| 原版 | 20 | 1 | 6 |
| 单海军（`naval-fleet`） | 28 | 1 | 7 |
| 单空军（`air-corps`） | 25 | 1 | 7 |
| 海军 + 空军 | 32 | 2 | 8 |
| 时代军备（`pack-antiquity`） | 27 | 2 | 8 |
| 「现代」+「现代海军」 | 27 | 2 | 9 |
| 海军 + 空军 + 时代军备 | 39 | 3 | 10 |
| 全扩展全开 | 60 | 3 | 10 |

最后一行要留意：**「现代海军」要带「现代」，而「现代」本身就是时代军备的一包**，
所以它同时点亮海军的 +1 与时代军备的 +2。规则按实际在场的体系算，
不按"你本来想开哪一类"算——这样联机两边看到的数字永远一致。

## 四、谁进池子，谁永远不受限

| 类别 | 进池？ | 说明 |
|---|---|---|
| 战斗单位（`category: 'combat'`） | ✅ | 池子的主体 |
| 非生产性建筑（塔、堡、工厂…） | ✅ | 建筑也是一种"这一局有什么解法"的选择 |
| 生产性建筑（军营 `camp*`） | ❌ 永远可用 | 没有它就没有前线补员 |
| 桥（`bridge*`） | ❌ 永远可用 | 选卡不该决定"这条河过不过得去" |
| 经济单位（农民、伐木工…） | ❌ 永远可用 | 没有它就没有收入 |
| 建造单位（劳工、工程兵…） | ❌ 永远可用 | 没有它连工地都起不来 |
| 召唤物（`summonedOnly`） | ❌ | 没有独立造价，选了也造不了 |

**判据只有一处**：`core/draft.ts` 的 `canUseType()`。规则层（`doRecruit`、`doBuild`）、
界面（城市与军营的产兵表）、AI（采购候选）都问它——这个仓库里"判据写两份"
栽过好几次（临水判定、迷雾可见性），所以宁可多绕一层函数。

## 五、取消"过时"下限，但不取消"未来"上限

原版规则：城市只能造当前时代和上一代的兵（`def.era >= era - 1`）。
它的本意是"现代了就别在产兵面板里翻十个早就没用的兵"。

选卡模式下这条会毁掉整个模式：你花了一个选位拿到古典投石车，城市升到工业之后
就再也造不出来——那等于"越往后期走，选卡越没有意义"。
所以下限放开（`eraWindowOk`），上限保留（造不了未来的兵）。

两条报错也分开写：「需要「工业」时代」是科技没到，去升城；
「已经过时了，产线不带它」是名单/时代窗口的取舍，去换兵种。玩家要做的决定不一样。

## 六、界面

一整块盖住棋盘的遮罩（选卡期间棋盘没有信息量，露一半只会让人误点）：

- **顶部**：阶段（禁用 / 选人 3/12）、倒计时（最后 5 秒变红闪）、这一句该干什么；
- **左侧**：兵种池，剩几个 / 共几个，每张卡是「图标 · 名字 · 时代 · 造价 · 攻/血」；
  禁用揭晓后有两条"禁用"标签；
- **右侧**：甲乙两栏，各列禁位与选位（空位是虚线占位、选过的是实心），
  以及这一方现在在干什么（「已提交禁用」/「轮到你选」/「已选 3 / 6」）；
- **底部**：最近六条流水（谁禁了谁、谁超时了）；
- **右上角两颗按钮**：「跳过选卡」与「退出」——遮罩盖住了顶栏，没有它们玩家就被关在里面了。

**退出与跳过**是两条不同的路，别混：

| 按钮 | 做什么 | 什么时候用 |
|---|---|---|
| 跳过选卡 | 这一轮 BP 作废，**这一局按原版用全部兵种接着打**（会同步给对面） | 不想纠结名单、或对面掉线选不下去 |
| 退出 | 放弃这一局，回到开局设置面板（房间里会顺带离房） | 想重新配一局 |

对方状态是明写的：禁用期只报"已提交/未提交"（不泄露内容），选人期报"轮到谁 +
已选几个"。热座换手时遮罩右上角会写「乙方操作中」，不需要额外的交接页。

## 七、联机：BP 是真的联机，不是"本地打完再建房"

联机 BP 的两个难点，各有一处对应设计。

### 7.1 锁：BP 期间把"进度号"写进 turn 列

房间是"一次提交一整局状态 + 乐观锁"的模型，锁用的是 `turn` 列。
但 BP 有十几个来回而回合数一直是 1——拿回合做锁等于没锁：
两边同时提交时谁都匹配得上，后写的直接盖掉前面那一步，玩家会看到
"我刚禁的兵没了"。

所以选卡状态里加了 `seq`（进度号，每走一步 +1），**BP 期间房间的 `turn` 列存的就是它**：

```
建房      turn = seq = 1
A 禁用    expected 1 → 写 turn 2
B 禁用    expected 2 → 写 turn 3     ← 拿到过期的 1 会被挡住
…选人…    expected n → 写 turn n+1
选完      expected n → 写 turn 1     ← 把锁干干净净交还给正常对局
```

最后一笔写回 1 是关键：之后 `END_TURN` 的提交仍然用"回合数"做锁，
两套语义在同一条流水线上无缝衔接，不需要加列、不需要改表。

### 7.2 冲突：禁用期本来就是"同时提交"，所以合并而不是拒绝

被锁挡回来不代表出错——禁用期双方就该同时交。标准动作是：

```
提交 → 被挡 → 拉最新 → 把自己的这一步补到最新状态上 → 用新进度号重交（最多 4 轮）
```

因为两边改的是不同字段（`bans.A` / `bans.B`），合并天然安全。
选人期是严格轮流，本来就不会撞；真撞了（比如有人用旧窗口连着点两下），
规则层会以"还没轮到你 / 这个兵已经被选走"拒掉，然后拉最新状态跟上。

超时也留了余量：`deadline` 是**写它的那台机器的钟**，两边差一两秒很正常，
所以联机时多等 1.5 秒才判超时——早判就等于替对面抢答。

### 7.3 轮询与界面

- 正常对局 15 秒轮询一次就够（回合以分钟计），BP 期间另开一条 **1.5 秒**的轮询，
  选完立刻关掉；
- 采纳条件也换了：BP 里回合和行动方都不变（一直是第 1 回合、一直是甲），
  套用"轮到我了吗"的判断会让两边都以为没自己的事。所以看**进度号**：
  云端的 `seq` 比我大就采纳；
- 两台机器各自只代表自己的席位（`draftSeat = room.seat`），观战位只能看不能选；
- 建房不再要求"先打完 BP"：BP 打到一半建房、对面进房接着打，都是正常路径。

## 八、兼容性

- **存档**：`state.draft` 随存档序列化，读档后接着选；`config.draftMode` 也存进去了，
  读档的界面才知道这一局有 BP。
- **旧存档**：没有 `draft` 字段 = 普通对局，所有判据原样返回 true。
- **扩展**：所有 `category`/`era`/`barracks`/`bridges` 字段都是既有的，
  扩展不需要为选卡改任何代码；新加的兵种自动进池，规模公式自动变大。
- **上帝模式**：沙盒不产兵，选卡没有意义，开局面板会把两者互斥（勾了沙盒就关选卡）。
- **开局部队**：开局送的那几个兵不参与 BP（它们是地图配置的一部分）。
  BP 决定的是**产能**——这一点在文档和界面提示里都写明了。

## 九、测试

`npm run test:rules` 新增 16 条（共 425 项）：

| 用例 | 守什么 |
|---|---|
| 原版池子 20 / 各禁 1 / 各选 6，只收战斗单位与非生产性建筑 | 规模与池子成分 |
| 按时代分层抽样，每个有货的时代都抽得到 | 不会抽出一池子全是第五时代 |
| 名额按体系加：单海军/单空军 +1 选，海空同开 +1 禁 +2 选 | 名额规则 |
| 时代军备 +1 禁 +2 选，且能和海空叠加 | 叠加与"按实际生效的扩展算" |
| 进度号每走一步 +1 | 联机乐观锁的语义 |
| 开局停在"等待开局"：不计时、不能禁用，点开始才进禁用 | lobby 阶段与它的边界 |
| 可以整轮跳过：这一局按原版用全部兵种 | 跳过的语义与它对判据的影响 |
| 盲禁：两边都交完才揭晓，禁掉的兵谁都拿不到 | 同时操作与全局移除 |
| 蛇形顺序，选完 12 步交接给对局 | 顺序与终局交接 |
| 没打完之前，走棋与产兵一律被拒 | BP 期间不许偷跑 |
| 名单外的兵造不出来，名单内的能造；骨架不受限 | `canUseType` |
| 取消"低于城市两个时代就不能造"的下限 | `eraWindowOk` |
| 建筑也要在名单里，工兵不能盖没选到的塔 | `doBuild` 也走同一判据 |
| 超时：禁用视为放弃，选人由系统补一个 | 超时语义 |
| AI 会禁用与选人，且只在池子里挑 | AI 不会选出池子外的兵 |

`scripts/smoke-room.ts` 打真实云端跑一遍联机 BP：建房时锁=进度号 → A 禁用 → B 拉最新禁用 →
用过期进度号再交必须被挡 → 合并后重交成功 → 走完 14 步 → **锁交还 turn=1**、两边名单数量正确。

`npm run test:ui` 新增 5 条（共 147 项），走的是真实界面：
打开开局面板 → 开启选卡 → 开始对局 → **先看到"等待开局"（有联机入口、没有兵种池）** →
点开始选卡 → 遮罩铺出 20+ 张卡 → 甲禁一个（仍停在禁用阶段）→ 乙禁一个（进入选人）→
一路点满 → 遮罩收起、棋盘可用；另有用例覆盖「跳过选卡」（遮罩收起、能结束回合）与
「退出」（弹出开局设置面板）。
