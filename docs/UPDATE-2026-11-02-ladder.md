# 决策梯子与时代让子：把"有多强"换成两把尺子

2026-11-02 · 自对弈胜率永远 50%，所以改量"优势值多少"；新增 `npm run ladder`

---

## 一、为什么不再看"AI 胜率"

此前所有改动都是拿 AI 和 AI 打（同一套判断，只是版本不同），
报出来的 50% / 46.9% / 38.8% 只能回答"这一版比上一版好还是差"，
**永远回答不了"它有多强"**。这也是上一轮"人类凭什么 100%"那个问题的死结：
分母是它自己，量不出绝对高度。

换个量法：**给一方一个确定的优势，看这个优势能换多少胜率。**

- 优势 = 决策质量高一档 → 量出"决策"这条轴值多少。
- 优势 = 开局白送 N 个时代 → 量出"抢时代"这个打法值多少。

两条都是同一个引擎里的对照，不涉及"人类有多强"这种测不出来的东西，
但它给出了**换算单位**：一件事值几个"档"。

---

## 二、梯子怎么搭

`scripts/probe-ladder.ts`，两种模式。

### 决策梯子（`--mode level`）

同一张图、同一颗种子、同一套规则，**只把一方的档位调低**。
运行中每回合开始前改 `s.config.aiLevel`（AI 每次决策都重读它），
所以 A 走的时候是高档、B 走的时候是低档，逐回合切换而不是开局一次。

三档实际差在哪（读代码）：

| 能力 | `basic`（初级） | `advanced`（高级） | `tactic`（中级） |
|---|---|---|---|
| 落点评估 | 只朝目标走 | 威胁圈、地形收益、脱险奖励 | 同高级 |
| 交换账 | 只看掉血**比例** | 按**谁更贵**算这笔换亏不亏 | 同高级 |
| 编队 | 无模板 | 职能配比模板 + 突击单位绕后 | 同高级 |
| 选点随机 | 在 ±25% 的近似候选里挑 | 收窄到 1.5% | 同高级 |
| 打法 | 无 | **压成均分**（rush/harass/boom 各 1/3，drive 清零，不弃城） | 按局势换档，可弃城 |

注意最后一行的方向：`tactic` 的档位 id 叫"中级"、`advanced` 叫"高级"，
但从能力叠加看是 `basic < advanced < tactic`——`tactic` 是**高级的评估 + 战术层**。
这也正是下面那个悬案的来源。

### 时代让子（`--mode era`）

双方都是 `tactic`，只把一方的城**在开局直接提到高 N 代，不花钱**。
`giveEra()` 照抄 `doUpgrade` 的那几步（`era` / `maxHp` / `armor` / `hp`），
封顶走 `eraCeilingOf(s)`——让子的本质是"这次升级白送"，别的地方不该有任何差别。

### 成对与对照

- 同一颗种子打**两局**：优势方先手一次、后手一次，抵消先手和地图不对称。
- 报的是**优势方胜率**，50% = 这个优势一文不值。
- 未决（160 回合封顶未分胜负）按半分计，同时单独列出。
- 另跑一组 `basic vs basic` 当**对照**：如果它也不是 50%，说明尺子本身有偏。

固定条件：种子 900–929 各两局（n=60）、era3（火药）、20×20、上限 160 回合。

## 三、结果

| 实验 | 优势方 胜/负/未决 | 计分胜率 | 95% 区间 | z | 均回合 |
|---|---:|---:|---:|---:|---:|
| **对照**：basic vs basic | 23 / 23 / 14 | **50.0%** | 38–62% | 0.00 | 108 |
| 决策：初级 → 高级 | 37 / 14 / 9 | **69.2%** | 57–79% | 2.97 | 93 |
| 决策：初级 → 中级 | 40 / 12 / 8 | **73.3%** | 61–83% | 3.61 | 91 |
| 决策：高级 → 中级 | 27 / 28 / 5 | **49.2%** | 37–61% | −0.13 | 89 |
| 时代：+1 代（火药→工业） | 46 / 13 / 1 | **77.5%** | 65–86% | 4.26 | 70 |
| 时代：+2 代（火药→二战） | 58 / 1 / 1 | **97.5%** | 90–99% | 7.36 | 42 |

换成"比 50% 多多少点"：

```
对照            50.0   ├──────────────────────────  基准线
初级 → 高级     69.2   ├──────────────────────────  +19.2
初级 → 中级     73.3   ├──────────────────────────  +23.3
高级 → 中级     49.2   ├─────────────────────────   −0.8  ← 等于没差
+1 代           77.5   ├───────────────────────────  +27.5
+2 代           97.5   ├────────────────────────────────  +47.5
```

## 四、怎么读

### 1. 尺子是准的

对照 `basic vs basic` 打出 **23 胜 23 负 14 未决 = 50.0%**，
逐种子看下去也是成对的（同种子换边后胜负相反）。
说明"成对镜像 + 优势方胜率"这套量法没有系统性偏移，
下面那些非 50% 不是量法造出来的。

### 2. 决策质量：一次性抬到头就停了

- 初级 → 高级：**+19.2 点**（z=2.97，显著）。威胁圈、交换比、编队、
  收窄随机——这些"算得更准"的东西是真的值钱。
- 高级 → 中级：**−0.8 点**（z=−0.13，CI 跨 0）。**打平。**

第二条顺手把 `UPDATE-2026-10-28-ai-tiers.md` 里留下的悬案结了。
那份文档里写着"中级 71.6% / 高级 65.4%，两档用的是不同种子，**不能**直接比"。
现在同种子成对打 n=60：**这两档没有可测出的强弱差**。
之前那个 6 个点的差是种子和样本造成的，不是档位造成的。

为什么会打平——目前只有假设，没有instrumentation，别当结论看：
`tactic` 多出来的只是"打法规摇摆"（速攻/骚扰/爆发三选一 + 可弃城），
走位和采购这些真正决定交换比的东西两档一样；
而三种打法在对称图上期望相近，换档带来的收益被换档的代价（兵种错配、
弃城损失）抵掉了。要证实这点得统计它一局里换了多少次档、每次换档前后
三回合的净收益——`buildPlan` 现在不对外暴露，需要先加个观测口。

### 3. 时代：一代 ≈ 一整条决策梯子

- +1 代 = **+27.5 点**，比"把对手从初级换成中级"（+23.3 点）还略高一点点；
  两者 CI 大幅重叠（65–86% vs 61–83%），**分不出高下**，
  只能说是同一量级。
- +2 代 = **+47.5 点**，接近不可逆：60 局里优势方只输过 1 局。
- 对局长度：108 → 70 → 42 回合。一代砍掉 35%，两代砍掉 61%——
  科技碾压不是"慢慢赢"，是"提前结束"。
- 边际收益递减但结论不变：第一代 +27.5，第二代只多 +20.0，
  可 77.5% 再往上加 20 点就是 97.5%，已经接近天花板。

**换算**：在这张图、这个起始时代上，**白送一个时代 ≈ 把决策水平整整提一级**。
这就是"抢时代"为什么是人类最稳的一手——它买到的东西，
和"把棋下得更准"是同一个量级的收益，而且不需要下得更准。

## 五、这些数字不是什么

三条限定，别越界引用：

1. **不是绝对强度。** 优势双方是同一个引擎，量的是"这条轴值多少"，
   不是"AI 有多强"。人类认真打出来的胜率不在这两张表里。
2. **+27.5 是上界，不是人类收益。** 让子是**开局白送、不花钱、不花回合**；
   人类抢时代要先攒钱、再花一个升级动作、还得守住城。
   真实收益一定低于这个数。把它当"抢时代最多能值多少"来读。
3. **样本 60 局，CI 宽 ±11 点。** 足以分开"有差别 / 没差别"，
   不足以分开"+19 点 和 +23 点"这种距离。要再细就加种子，别改系数去凑。

## 六、复现

```bash
npm run ladder -- --mode level --high tactic --low advanced --games 30   # 决策梯子
npm run ladder -- --mode era   --give 1 --games 30                       # 时代让子
npm run ladder -- --mode level --high basic  --low basic --games 30      # 对照
```

参数：`--mode level|era --high/--low basic|advanced|tactic --give N
--games N --seed 900 --era 3 --size 20 --cap 160 --exp a,b,c`。
stderr 逐局打印 `seed / 优势方 / 结果 / 回合数`，可逐局复核。

确定性：同参数重跑，`+1 代` 与 `+2 代` 两批结果与上一轮逐位相同
（46/13/1、58/1/1），所以这张表可以被别人原样重放。
