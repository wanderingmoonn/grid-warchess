# 新对局快捷键 · 新玩家默认材质

**v0.7.7（2026-11-12）**

两件小事，都不碰规则。

## 1. Alt + N：直接开新局

对局中按 `Alt + N`，直接弹出开局的设置面板——不用先点齿轮 → 「回首页」，
再从首页点「开始对局」。面板里点「开始对局」才会真的换局，点「取消」等于
什么都没发生，当前这一局还在。

设置 → 对局 里也补了一颗「新对局」按钮，旁边写着这个快捷键。

几条边界：

- 正在输入文字（搜索框、聊天、改名）时不抢键；
- 按住不放只认第一下，不会连开面板；
- **复盘里**先退出复盘再开面板——那时棋盘上是别人的棋，拿它的配置开局会串味；
- 首页、规则书、联机面板已经盖着的时候不叠第二层。

## 2. 第一次进来就是材质

以前「美术贴图」默认是原版（纯色块 + 汉字），要玩家自己进设置里找。可材质
现在就是这游戏的脸面——新玩家第一眼看到的却是一张草稿。

现在**没存过偏好的人默认「材质」**。明确关过的人（设置里点过「原版」）仍然
关着，`?terrain=off` 也照旧能压住，老玩家的选择不会被改掉。

材质模式下棋子仍是汉字（棋盘上是淡彩平面，像素小人和它打架），这一点没变。
