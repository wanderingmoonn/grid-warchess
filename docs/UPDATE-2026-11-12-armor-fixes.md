# 装甲五处修正（2026-11-12）

**v0.7.8** · 只动「装甲时代 / 聚变时代」这一套，前六代与其它扩展不受影响。

## 1. 规则书的兵种表补上插槽

`scripts/build-manual.ts` 的 `traitsOf` 以前对装甲素体几乎是空的：攻/血在表头，
而"能装几个主槽"这个决定战力的数字整张表都查不到。现在照 `主2 · 副1 · 甲2` 印出来，
素体再带一行「耗电 N」，电站带「供电 +N」。插槽与供电在词条表里各有一条解释。

## 2. 电量默认可见

电力条以前挂在**装甲面板**里——想看电，先得选一台装甲。现在它在侧栏顶部
（席位卡下面），**名下有电站在发电就一直在**；一座电站都没有时整块不出现。
观战/复盘不画（那是别人名下的电）。

同时，装甲属性卡上的「耗电 N（本方余量 X）」在没电站时**不再带括号那半句**：
那时余量是负数，写出来只会让人以为哪里坏了。

## 3. 槽位角标不再是"拆"

已装模块的列表以前每一行都是「拆」按钮，五件排下来主炮和装甲板长得一样。
现在改成两组：

- **已装**：只读行，角标是槽位单字（主/副/甲/统/设），右边写"已装"；
- **拆卸（退还一半）**：单独一组按钮，角标才是"拆"，文字写「主 · 速射炮」+ 退款额。

一眼能看出这台车的槽位构成，也不会在"装"和"拆"之间点错。

## 4. 装配不再限次数

`canMount` 去掉了"每座坞每回合 1 单 / 装配总厂 2 单"的检查，`doMount` 不再占名额。
新的节流是**这台单位这一回合的行动**：装上一件就置 `acted / moved`（本回合不能走、
不能打），但同回合可以接着装，槽位、电、钱够就行。

坞的名额**没有删**，只是现在只剩「整备」在用（`doRecharge` 仍是 1 次 / 总厂 2 次）。

## 5. 战斗数值 +30%

| 上调 | 不动 |
|---|---|
| 素体与无人机的 **攻击 / 撞击 / 生命 / 护甲** | 造价、耗电、供电 |
| 模块的 **武器伤害 / 装甲板护甲 / 额外生命 / 近防 / 矢量** | 射程、连发段数、移动、视野、插槽 |
| 地雷 40→52、轨道打击 120→156、护盾投影 30→39、整备臂 40→52 | 充能次数、经济产出、建筑血量 |

举例（第 7 代）：砧 175→228 血、22→29 攻、17→22 甲；速射炮 38→49 ×2；
反装甲炮 74→96；链锯臂 138→179。第 8 代：塔 330→429 血、34→44 攻、24→31 甲。

口径是"**同样的钱、更硬的数值**"——造价没动，所以这次是纯增强；如果下一轮还想加，
改的是同一批字段，不要顺手把造价一起乘。

测试里写死的数字（175 血、120 伤、8 点近防、60 额外生命）都换成读表了，
以后再调数值不会连带把测试弄红；装配坞那两条"每回合只接一单"的断言按新规则重写。
