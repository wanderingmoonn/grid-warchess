# 肉鸽 2.0（if 线，L1–L3）实现说明

> 一句话：**主游戏原封不动，标题页多了一个「肉鸽 2.0」。**
> 两个入口：标题页的「肉鸽 2.0」按钮，或 `npm run dev` 后打开 `http://127.0.0.1:5178/?rogue=1`。
> 设计依据见 `ROGUELIKE-FLOW.md`（结构）与 `ROGUELIKE-STORY.md`（叙事）；本文件只讲**做了什么、怎么跑、差在哪**。

## 〇、它和标题页那个「肉鸽」是什么关系

**两套东西，并存、互不影响。**

| | 原版肉鸽（另一位合作者） | 肉鸽 2.0（本目录） |
|---|---|---|
| 定位 | **原版规则的线性切片**，DLC 随时可加，纯粹原版也能跑 | **if 线**：把整个游戏几乎所有的部分都揉进肉鸽 |
| 结构 | 三幕 × 三场 = 9 关（每幕第 3 场是 boss），节点只有 battle / rest | 每层 **10 步 × 2 门 = 20 房**，三层，房型含事件 / 商店 / 营地 |
| 战斗 | 沿用原版的城与经济 | **玩家前三层没有城**；遭遇/精英**双方都没城**（兵打光算输），攻坚/层末才攻城 |
| 代码 | `src/core/roguelike/*` + `src/ui/roguelike/run-screen.ts`，接在 `main.ts` 里 | `src/roguelike/*`，**不引用对方任何模块** |
| 存档 | 有自己的 run 存档 | 不落盘（刷新即重开） |

**约定（对方原话）**："不要覆盖，留着""你自己搞个肉鸽 2.0""搞好就让它在你原版肉鸽旁边再加个接口"。
所以本实现唯一动到的共享文件是**标题页加了并排的一个按钮**，原版肉鸽的代码一个字节都没改。

## 二、怎么跑

```bash
cd grid-warchess
npm run dev
#   标题页 →「肉鸽 2.0」（在「肉鸽」右边）
#   或直接开 /?rogue=1
#   内容预览：/?rogue=1&rogueAuto=win —— 所有战斗直接判胜，一层层看事件/商店/结算
```

界面上「← 返回标题」在开局页右上角、层地图顶栏右侧、结算页；它走的是整页重载回不带参数的地址，
所以退出后主程序是干净的（不会留下被隐藏的棋盘或半截状态）。

生产构建也通（已验）：`npx vite build`，肉鸽被拆成独立 chunk（`app` 18 KB、`battle-screen` 9 KB、`ai` 63 KB），
只有真的进战斗才会去拉 AI。

自动验证：

```bash
node --experimental-strip-types scripts/rogue-smoke.ts      # 逻辑：房间图 / 流程 / 真打一场
node --experimental-strip-types scripts/rogue-ui-smoke.ts   # 界面：开局 → 战斗 → 结算 → 三层走完
npm run test:boot                                           # 确认本体没被影响
```

两条冒烟脚本不进 `npm test`（那是本体自己的回归），也不改任何既有脚本。

| 层末 boss | 不走房间图，走完 10 步后单独一场（L1/L2 从三家名字里随机，L3 固定钟楼） |
| 时代钟 | 本层已进房数，越高敌人预算越大、越可能上高代兵 |
| 跨层保留 | 军队、金币、藏品跨层带走；阵亡的单位不回队（随军医官除外） |
| 五种战斗的区分 | 遭遇（双方无城，平地遭遇）／**精英（无城，但有一座「塔 + 兵」的据点）**／攻坚（敌 1 城 + 塔）／**守城（三席：友军有城、玩家支援，守 N 轮）**／层末（L1–L2 敌 1 城 + 塔 + 墙，L3 两城 + 两塔）；尺寸 8→22，每深一层 +2 |
| 地图 | 自己写的固定图：**平原 ≈80%、森林 ≈14%、丘陵 ≈6%，没有水/山**（不绕路）；尺寸随层与房型 8→16，**人多时自动放大到 22**（20 个人站 8×8 会堵成一团） |
| 时代 | **L1 = 第 1–2 代 / L2 = 第 3–4 代 / L3 = 第 5–6 代**（城随低代：1/3/5，层末敌人用高代），第 6 代由「信息化」扩展解锁 |
| 跨层换代 | **不自动换装**。旧兵原样带走，换代靠玩家自己：战利品、商店、层末奖励。层末必给**一个下一层的初级兵**当落脚点 |
| 敌人换代节奏 | 每层按时代钟分三段：**钟 0–2 用上一代**（L2 是 e2、L3 是 e4）/ 钟 3–5 本层低代 / 钟 6 以后与层末用高代（2 份高代 + 2 份低代混编，池子里留旧兵当填线的） |
| 第二层 | **四种世界**：正史 / 时代军备 / 奇想 / 修真。第一层末四选一，第二层的兵池、扩展、层末 boss、第三层的溢出全跟着换（见 §三·五） |
| 阵型 | 开局按**射程越远越靠后、移速 ≥3 的站两翼（左右交替）**自动排；只看谁站哪，不重挑格子（不会踩城/水/山）；部署时会多要 6 个格子当余量，阵型才铺得开 |
| 战斗上限 | 遭遇 16 / 精英 24 / 攻坚 32 / 层末 44 轮（人多再加），守城战 = 守住轮数 +3；超时判负 |
| 手感 | 选中一次即可"先走再打"；**撤回**按钮 + Ctrl+Z；无招募（玩家没城，只打这一支部队）；**鼠标悬停任意单位看属性**（和本体一样的攻/甲/血/移/射/视野） |
| 补员 | **没有后台补员**：兵只从战利品、商店、层末奖励来（上一版每胜一场白送 1 个兵，现在取消——战利品本身就是"兵 or 钱"）；敌人只在有城的关补，整场最多 1–2 个 |
| 方略 | 3 个（边军 / 射手 / 骑军），各带初始编成 + 一条规则级被动 |
| 事件 | **18 个**，2–4 个选项；效果＝金币 / 兵 / 藏品 / 整编 / **拿兵去换** / **赌一把**；**不再给"下一战 +攻/+甲/+血"** |
| 营地 | 从 5 个里抽 3 个：补员 / 募饷 / 征召 / **整编** / **犒军**（只管人、钱、编制） |
| 战斗奖励 | 普通/攻坚：**1 个本层兵**（攻坚 2 个）／**略高于 1 兵价的钱**／整训。精英：**3 个兵**／**3 兵价的钱**／**1 兵 + 1 藏品**。层末：**不给选择，全给**——1 藏品 + 1 本层高级兵 + 等价钱 + 1 个下一层的初级兵 |
| 奖励给什么兵 | 按时代钟抽：钟越靠后越可能给高代兵（p = 钟/10），但**低代抽最贵的、高代抽最便宜的**，所以钟到一半时两边拿到的战力接近 |
| 结局 | 走完 L3 层末 → **常规结局「破钟」**；单位打光或城破 → 失败结算 |
| 失败判定 | 有城的席位按"城全空"判；**没城的席位（玩家，遭遇战里的双方）按"兵打光"判** —— 引擎自带的 `seats.cityless` |
| 城与工事 | 攻坚/层末敌人才有城（整场最多补 1–2 个兵）；**精英没有城，改成一座防御塔 + 围着它的兵**；**攻坚/层末的城边有塔（L3 两座）**，所以"杀完兵再把城当沙包"不成立——你得顶着塔拆城。工事按造价的一半计入敌方预算，最多吃 35% |
| 临战决议 | 层末 boss 前**固定出现**，从 **8 个**里抽 3 个：夜袭 / 强攻 / 买通 / 就地征召 / 工兵破墙 / 火攻 / 迂回 / 掘壕。**全部只影响这一场**，且大多带代价（拿一样换一样） |
| 商店 | **三行货架**（兵种 3 / 藏品 2 / 补给 1），买完不关店可以接着买，40 金刷新；有「行军图」时全场 8 折 |

### 三·五、第二层的四种世界

第一层打完，选一条路：**正史 / 时代军备（→ 技术史）** 或 **奇想 / 修真（→ 神话史）**。
第二层随之变成那个样子——不是换名字，是**兵池、扩展开关、层末 boss、第三层溢出**全换。

| 世界 | 第二层 | 兵池（低代 / 高代） | 扩展 | 第三层 |
|---|---|---|---|---|
| 正史 | 商道 | 火枪 / 戟兵 / 骠骑 / 臼炮；步枪 / 机枪 / 装甲车 | — | 科技层（原样） |
| 时代军备 | 军械库 | 线列步兵 / 猎兵 / 胸甲骑兵 / 攻城加农炮…；堑壕突击队 / 马克 I 坦克 / 列车炮… | `era-arms` | 科技层 + 军备 e5（伞兵 / 重型坦克 / 火箭炮…） |
| 奇想 | 异境 | 狂战士 / 幽灵 / 刺客 / 法师 / 精灵弓手 / 树人 / 圣骑士…；皇家守卫 / 狼人 / 元素召唤师 / 双头巨人… | `fantasy` | 科技层 + 至尊法师 / 精灵女王 |
| 修真 | 山门 | 炼气士 / 剑修 / 体修 / 青木剑 / 玄石印；魔修 / 魂修 / 寒水镜 / 赤炎珠 | `cultivation` | **末法之世**（没有 e5 兵，是设定不是缺内容） |

**完整兵池**（数字是造价；`低代` = 钟 3 以前的主力，`高代` = 钟 6 以后 / 层末）：

| 世界 | 低代兵池 | 高代兵池 |
|---|---|---|
| 正史 | 火枪兵 130、戟兵 100、骠骑兵 150、臼炮 140 | 步枪兵 200、机枪队 175、装甲车 250 |
| 时代军备 | 线列步兵 150、猎兵 140、胸甲骑兵 185、龙骑兵 155、掷弹兵 165、攻城加农炮 160、康格里夫火箭 150、长管炮 170、工兵 130 | 堑壕突击队 195、战壕迫击炮 200、火焰喷射器 215、毒气兵 230、榴弹炮 225、列车炮 265、马克 I 坦克 330、装甲列车 340、扫雷兵 110 |
| 奇想 | 狂战士 120、幽灵 130、刺客 135、法师 150、精灵弓手 175、树人 175、死灵法师 175、圣骑士 215、皇家骑兵 235、超级重骑 205 | 皇家守卫 255、狼人 235、元素召唤师 280、双头巨人 300、机关傀儡 245、神圣骑士长 470、国王 330、炼金术士 240 |
| 修真 | 炼气士 110、剑修 180、体修 180、青木剑 150、玄石印 180 | 魔修 270、魂修 270、寒水镜 190、赤炎珠 260 |

第三层溢出：军备 = 伞兵/突击队/反坦克炮/火箭炮/重型坦克/自行火炮/高射炮/重型迫击炮；奇想 = 至尊法师/精灵女王；正史无；修真无（末法之世）。

三条实现上的取舍：

1. **奇想的池子里不放飞行单位**。空中层是"和地面同格但不在同一层"，地面单位打不到它；
   一局里只要对面有一只会飞的、玩家又没带对空，这仗就打不完（实测 10 个兵围着 3 个敌人
   打了 39 轮，城一点血没掉）。奇想的味道靠魔法、亡灵、巨兽给。
2. **修真不跑完整的修炼循环**，改成"按时代钟给境界加成"：钟 0–2 算筑基（攻 +6 / 血 +16）、
   3–5 金丹、6–8 元婴、9+ 化神（攻 +15 / 血 +40）。双方同享，只加人不加法器。
3. **奇想 / 修真各有自己的 `power` 系数**（决定"加钱"那一笔，不动人数）：同样的预算下
   它们的兵"每块钱买到的战力"更高（魔法、境界），所以要单独配——现在奇想 1.8、修真 2.2、原版与军备 1。

### 三·六、守城战（特殊战，三席）

一层一场，帮三家之一守城。**城不是你的**：友军（B 席）有城、有守军、有工事，玩家（A 席）只作为支援入场；攻方（C 席）从地图上沿分波压下来。

| 项 | 做法 |
|---|---|
| 剧情 | 东家是三家之一（守墙人 / 持秤者 / 守钟人），战后给**他家的兵**（本层最高档里的一只）+ 1 件藏品 + 60 金 |
| 席位 | `seats.count = 3`、`ai = ['B','C']`、`cityless = ['A','C']`、`teams = [['A','B'],['C']]`——A/B 同盟，C 单列。引擎的 `sameTeam` 已经把友军伤害、目标列表、胜负都接住了 |
| 场地 | 城在下沿（B 的，+80% 耐久），城前一座塔、一段墙；玩家从城前偏左入场，友军守正面 |
| 友军 | 自带 `2 + 层数` 个兵（本层池子里按预算抽）+ 一座塔一道墙；不招募、不刷兵 |
| 目标 | **守住 7 / 8 / 9 轮**（L1/L2/L3）。城破算输；**玩家支援打光也算输**（哪怕友军还在城上） |
| 敌人 | **四波**：开场 + 第 2 / 4 / 6 轮；总人数 ≈ 玩家 + 友军 + 层数 + 1，分 4:2:2:2；每波预算再 ×1.15（两家人守一座城，攻方不加强就只是来送死） |
| 胜负 | 建局时 `holdWinner: true` 关掉引擎的"一方全灭"判定（攻方分波来，第一波打光不等于结束），由 `outcomeOf` 判：守满 N 轮且 B 的城还在 = 赢；城破 = 输 |
| 波次怎么来 | 引擎的关卡 `deploy` 事件只能让"未登场席位"上一次场，做不出同一席位连来四波。所以由战斗屏在**敌方回合结束时**往 `state.units` 里追加（owner = C），规则层照常推进 |
| AI 轮转 | 战斗屏的 AI 循环改成"从当前席位一直跑到 A"：A 交棒后依次跑 B（友军守城）和 C（攻方），两席局的行为不变 |

为什么工事要削一刀：城里的碉堡是满配的（36 攻 / 86 血），战场上临时推上来的工事不是。统一按 **0.65 攻 / 0.85 血**折算，再叠世界的口味系数（奇想 ×3.2 攻、修真 ×1.7 攻，因为它们本来的建筑太弱）。

### 三·七、试验型方略：成长型（2026-11-26 重做）

开局页有两张**试验**卡，思路是"把后面的东西提前给你"——但不再给**完全体**。

上一版是满编的完全体下放：神圣骑士长护甲 14，第一层的兵打它每下 1 点血，
实测从第一层到第三层**一滴血没掉**。现在改成**成长型**：

| 方略 | 部队 | 开局金 | 成长 |
|---|---|---|---|
| 试验队 | 坦克（e5）×1 + 民兵×2 + 弓手×1 | 150 | 第 1 层 46% / 第 2 层 70% / 第 3 层 100% |
| 英雄 | 神圣骑士长（e4，英雄）×1 | 220 | 第 1 层 55% / **第 2 层就长满**（e4 的时代是第 2 层） |

- **完全体的定义**：就是它自己的数值（英雄 36 攻 / 170 血 / 14 甲，坦克 56 / 88 / 10）。
  成长只做乘法，不额外加强。
- **三个系数分开走**（`GROWTH_UNITS`）：攻、血大致同步，**护甲压得最狠**
  （减法公式里护甲是超线性的，第一层给到完全体的 0.4 就已经"打不动"了）。
- **英雄必须是近战**。这个引擎"打完还能走"，远程只要移动力不落下风就能一直退着打：
  实测圣剑勇者（射 3 移 4）从第一层到第三层**残血 100%**，等于无敌。
  所以英雄选了 range 1 的神圣骑士长。
- **不再有敌方补偿**：上一版为了对冲"完全体下放"，给过"敌方 +1 人 / 预算 ×1.35~1.6"，
  现在起手本来就弱，那笔补偿一并撤掉。
- **英雄开局只有一个人**（`army = [英雄×1]`）。敌军人数据 `enemyHeadcount` 会压到 2，
  所以是"一个人打两个"；金币给到 220，因为**钱是你唯一能添人的路子**（商店、外人）。
- **一个实测坑**：圣剑勇者虽然属于 `fantasy` 包，但它 `requiresPack: 'pack-contemporary'`。
  上一版只记了"第一个见到它的包"，于是英雄在部署时被当成"不存在的兵"直接跳过，
  场上一个人都没有（开局判负）。现在 `packsForUnit` 会把前置包一起开。

实测（AI 对 AI，每个房型 3 场，第一层）：

| 方略 | 遭遇 | 精英 | 攻坚 | 守城 | 打完全部后残血 |
|---|---|---|---|---|---|
| 英雄 | 3/3 | 3/3 | 1/3 | 3/3 | 72% |
| 试验队 | 3/3 | 3/3 | 3/3 | 3/3 | 93% |
| 边军（基准） | 3/3 | 3/3 | 2/3 | 3/3 | 8% |
| 射手（基准） | 3/3 | 3/3 | 3/3 | 3/3 | 93% |

英雄的弱点是**攻坚**（一个人拆不动城，还得顶着两个守军），这是刻意的：
一个人就是一支队伍，但一个人拆不了一座城。第二、三层它会明显吃力——
到那时候该靠你自己买的兵，而不是靠它一个人。

### 三·八、中立单位：两侧 + 场外交涉（实验）

约三分之一的普通/精英/攻坚关，**战场左右两侧各站一个**"不惹事"的东西
（L1 骑士 / L2 步枪兵 / L3 步兵班），坐标贴着 `x=1` 与 `x=w-2`：

- **不主动攻击**：它不占回合（藏在隐藏席位 C 里，引擎的 `nextSeat` 会跳过 hidden）；
- **AI 不打它**：把它编进 B 的队里（`teams = [['A'],['B','C']]`），AI 视它为友军；
  `attackableTargets` / `siegeTargets` 也补了"不列友军"的判据（这是核心修正）；
- **被打会反击**：反击是引擎自带的（`canCounter`），给它 `countersLeft = 99`
  补偿"没有自己回合、不会重置"；
- **不参与胜负**：隐藏席位不进 `playing`，打光 B 之后 A 直接赢，不用清它。

**场外交涉**（战斗屏右侧多了「外人」卡，2026-11-26 加）：

| 按钮 | 效果 |
|---|---|
| 招募（身价 ×1.8） | 它当场变成我方的兵，**战后留在队里**（走 `survivorsOf`）；贵三成，买的是"现在就能打" |
| 请走 | 从场上拿掉，不花钱。不想为它绕路、或嫌它占格时用 |

- 交涉**不占回合**，直接改 `state`，所以会压一次撤回栈（Ctrl+Z 连同金币一起退回来）。
- 花钱花的是战场里的 `players.A.gold`，而 `resultOf` 返回的就是它 → `finishBattle` 直接落账，
  不需要另开一条"战斗花费"的通道。
- 顶栏加了「金」，看得见余额。

## 四、和设计文档不一样的地方（都是刻意的，且都能改回去）

1. **无城关卡走的是引擎自带的 `seats.cityless`（关键改动）。**
   一关现在是一份 `LevelDef`（`core/level.ts`）：固定地图 + 席位 + 开局部署 + 开局时代，
   交给 `createMatch` 建局。`seats.cityless` 的语义就是"这一席没有城，兵打光即出局"——
   于是**玩家前三层没有城、遭遇战双方都没有城**这件事不用改规则层就成立了。
   （上一版是靠"给双方各发一座营城"绕过去的，方向是错的，已删。）

2. **敌人一律"抢攻"（`aiDoctrine: 'rush'`）。**
   手写 AI 默认会先算经济再推——那是完整对局的正确打法，但一关只有二三十轮，屯兵等于让玩家干等。
   `aiDoctrine` 是**现成的脚本接口**（产品界面不暴露），这里正好用上。

3. **只放地面战斗兵进场；地图是我们自己写的。**
   放开全表的话 AI 会把回合拿去做农民、修桥、盖房子（实测 30 轮 0 次交火）。
   地形也不再靠 `mapStyle` 抽——抽出来的图一半是水，陆军全得绕路。
   代价是**没有水战、没有野外建造**——这两条不在试玩范围。

4. **无城关卡关雾。**
   没有敌方城市当方向来源时，AI 只能靠"看见的敌人"推进；`setup.ts` 里那条实测写得很清楚：
   没城又开雾，两排兵能站到第 80 回合谁都不动。小图（8~18 格）全亮也更像短兵相接。
   有城的攻坚关同理关雾，免得玩家找不到城。

5. **两边都不许补员**：AI 那一侧用 `AiBudget.maxRecruit = 0` 关掉（玩家没城本来就不能造）。
   不关的话，敌人靠城市收入每两回合摸出一个兵，玩家再能打也磨不过。

6. **回合上限比设计值低**（16–30 轮，设计里是 120/300）。没有 L4 的 40×40 大会战，
   小图上十几轮就能分出结果；上限只是兜底，不是期望值。

7. **敌人强度按"层 + 房型"定，只按 25% 跟随我方部队**（`BALANCE.base / w / follow`）。
   不写成"完全镜像我方造价"是实测出来的：那样会滑向**兵越少越强**——小地图上
   同一时间只有三四个兵能交手，多出来的挤在后面挨打；而敌人预算跟着总造价涨，
   于是"拿兵"反而让对面也变强（纯选兵通关率一度比纯选钱低 10 个百分点）。
   现在层决定对面有多强，我方成长只带 25% 的回响，"变强"才是真的变强。

### 2026-11-25 第二轮：藏品与事件的平衡

起因：试玩反馈「+1 移速比 +1 攻防强得多」。量化之后这不是错觉：

| 加成 | 第一层（中位攻 14 / 甲 2 / 血 28） | 第三层（中位攻 55 / 甲 5 / 血 54） |
|---|---|---|
| +1 攻 | 每下 +7% | 每下 **+1.8%** |
| +1 甲 | 每下 −9% 承伤 | 每下 **−1.8%** |
| +6 血 | 有效生命 +21% | 有效生命 **+11%** |
| +1 移 | 2→3，接敌距离 **+50%** | 2→3 仍然 +50%；骑兵 4→5 是纯抢节奏 |

伤害是 `atk − armor` 的减法 → 攻/甲/血的价值随时代**指数式缩水**；移动是节奏收益，不缩。于是越到后面，移速藏品越一家独大。

处理（都是小改，可回滚）：

| 项 | 改法 | 理由 |
|---|---|---|
| 铁匠铺 / 铁甲 / 壁垒图 | 数值**按层成长**（1/2/3 攻、1/2/2 甲、6/9/12 血） | 让三件在每一层的相对价值都落在 5~20%，不再到第三层变成摆设 |
| 急行靴 | 移动 +1 **只给基础移速 ≤3 的兵**；方略/决议的 +移动仍然全军生效 | 砍掉"骑兵再快一档"的滚雪球；步兵/弓手 2→3 才是它该服务的人 |
| 随军医官 | 每层最多救 2 人（`reviveLeft`，进层重置） | 原来一局二十多场 = 白送二十多个人，把"兵力只减不增"抹平了 |
| 行军图 | −20% → −25% | 它只服务商店，出场次数少，原值几乎感觉不到 |
| 藏品标价 | 按强度分档 140~300（原来一律 200） | 价格要说真话：急行靴/医官 300，行军图 140 |
| 事件：旧战场「找那面旗」 | 加"损 1 个基础兵" | 白拿的藏品（≈5 个兵的价值）会让另外两个选项变成摆设 |
| 事件：三家的账房「抄账本」 | 加 −80 金 | 同上 |
| 事件：瘟疫「请医」 | 文案补"无人损失" | 它原本只写 −90 金，看不出买的是什么 |

### 2026-11-26 第三轮：按需求定调（事件红利 / 免费换兵 / 钱算兵力 / 工事编制）

| 议题 | 定调 | 落地 |
|---|---|---|
| 藏品是不是"事件红利" | **是**：事件收益必须高于一场战斗，否则玩家会绕开事件 | 上一轮给「旧战场·找旗」「三家账房·抄账本」加的代价**撤回**，恢复白拿；理由写进 `data.ts` 注释 |
| 免费换兵（整编 / 挑老兵 / 以旧换新） | **保持免费**，这是本作特色 | 不动 |
| 赌博 EV | 调高，且**押小要略高于"看场子"** | 押大 −100 → +320（EV +60）；押小 −50 → +140（EV +45）＞ 看场子 +40 |
| 敌方只跟我方"人数"走 | 不行：会滑向"开局不拿兵、纯屯钱买藏品、后期再补兵" | 新增 `BALANCE.goldFollow = 0.1`：**每 10 个最便宜兵的钱 = 1 个敌人**（`floor`，开局 180 金不触发）；钱只进编成，不进地图尺寸 |
| 工事吃守军预算 | 守方本来没先手，不能再"多塔少兵" | 工事占预算从 **1/2 降到 1/4**；并**倒过来换编制**：每两件工事 +1 守军（至少 +1）。a 兵 b 塔 → a+⌈b/2⌉ 兵 b 塔 |

实测（5 个兵、L1 遭遇战）：0/200 金 → 4 个敌人；800 金 → 7 个；2000 金 → 12 个。
L3 层末：2 塔 2 墙 → 守军 +2（5 → 7），工事不再从兵里扣钱。

## 七、调参入口（都在 `run.ts` / `battle.ts`，改一行就生效）

| 想改什么 | 在哪 |
|---|---|
| 一层几步、房型比例 | `run.ts` 的 `BAG` 与 `planLayer` 里的锚点 |
| 敌人上几个人 | `run.ts` 的 `BALANCE.countFollow`（现 0.7：我方 10 个 → 敌 7 个）与 `countBase`（每层下限） |
| 敌人有多硬 | `run.ts` 的 `BALANCE.quality`（每个敌人分到的钱 = 池内最低价 + 均价差价 × 系数）、`layerPower`（按层的整体难度） |
| 某个世界太难 / 太简单 | `data.ts` 里该世界的 `power`（只影响"加钱"，不动人数） |
| 回合上限 | `run.ts` 的 `roundLimit` |
| 地图尺寸 | `data.ts` 的 `LAYERS[].size`（遭遇 / 精英 / 攻坚 / 层末） |
| 地形比例 | `battle.ts` 的 `makeRows`（平原/森林/丘陵的百分比） |
| 开局金币 / 军队 | `run.ts` 的 `startRun`、`data.ts` 的 `STRATEGIES` |
| 事件/休整的钱 | `run.ts` 的 `PRICE_SCALE`（现 1 / 4 / 9）；买兵的负金上限在 `effectiveGold` 里（0.9 × 身价） |
| 每层的兵池与主题 | `data.ts` 的 `LAYERS`（`prevPool` 上一代 / `pool` 本层低代 / `poolHigh` 高代） |
| 奖励给什么兵 | `run.ts` 的 `rollLayerUnit` |
| 阵型规则 | `battle.ts` 的 `arrangeFormation` |
