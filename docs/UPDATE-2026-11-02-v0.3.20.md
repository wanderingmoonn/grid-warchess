## 一、飞行：地形对空中层不存在

三层问题叠在一起：

1. `terrainOk` 的豁免只写了"水面 + 深水"，高山是墙 → 飞机飞得进河、出不了外海、爬不过山。
2. `terrainOk`（能不能进）和 `tileStandsOk`（能不能停）各写一份，改一处漏一处。
3. **AI 借的是陆军的旱路图**：海岸线上 `advanceDistance` 前后都是 `Infinity`，
   推进分恒为 0——可达格列着 68 格深水，它一格都不飞。

现在：空中层无视一切地形（只有敌方城市挡得住），两处判据同源，空中步耗固定 1；
AI 有了自己的空中距离图（每格一步），走位评分按 `airLayer` 选图。

## 二、分类统一：会飞就是空中层

`flight: true` 并进 `airLayer()`。以前它只读 `layer` 和能力钩子，于是漏写 `layer`
的单位会变成"能飞过河的地面兵"（占地面格、被近战按普通单位打、面板却标飞行）。
想表达"过水但仍在地面"（蜘蛛骑士的跳跃）只能用能力，不能用 `flight` 字段。
守卫用例扫全部 280 个兵种，`flight ⇔ 空中层` 双向断言。

## 三、掉血动画只播一次

病根在浏览器：`paintUnits` 为了排序会 `insertBefore`，节点摘下再插回时**正在跑的
CSS 动画会从头再来**，而顺序变化最常发生在"这一下有单位死了"的那一帧。上一版只堵了
调用次数，管不了浏览器。现在残留血条改 Web Animations（重插入不重播）+ 绘制序号防重；
老环境退回 CSS 类。
