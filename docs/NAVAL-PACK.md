# 海军扩展 · 设计说明

> 两个包：**「海战」**（`naval-fleet`，第二~第五时代）+ **「现代海军」**（`naval-modern`，第六时代）。
> 十四个兵种、五条能力、两条海权规则、一道留给未来空军扩展的甲板接口。

---

## 一、放在哪里（以及"只在扩展区"这句话到底守住了没有）

| 文件 | 内容 | 性质 |
|---|---|---|
| `src/core/naval-packs.ts` | 五条能力、十四条船、封锁与抢修、两个 `Expansion` 定义 | 扩展区，**新文件** |
| `src/core/naval-carrier.ts` | 航母甲板接口（`DECK_SPECS` / `AirwingOps` / 收放容器） | 扩展区，**新文件** |
| `src/core/expansions.ts` | 两行：`import` + 展开进 `EXPANSIONS` | 注册处，**唯一的既有文件改动** |
| `scripts/build-manual.ts` | 书单加一项 `prefix: 'naval-'`（自动成册） | 文档生成器 |
| `src/ui/books.ts` | 规则书入口多一本「海战扩展」 | 文档入口 |
| `scripts/test-rules.ts` | 13 条用例 | 测试 |

**引擎里改了一处，而且必须改**：`src/core/rules.ts` 的 `reachableTiles()` / `threatTiles()`。

原来的 `reachableTiles` 开头是一句 `if (footprintOf(s, unit) > 1) return new Map();`
——占地 2 的单位**一律不会动**。这条在只有炮台、兵营的年代等于没写，但航母要是 2×2，
它就成了"航空母舰不能移动"的规则错误。所以这一版把多格移动做成了真的：

- 锚点走一步，n×n 四格跟着挪，**每一步要求四格地形全过**；
- 自己的四格豁免（不豁免的话它踩着自己的格子，一步都动不了）；
- 敌军只挡同一层，桥照旧能从下面过；
- 步耗按**锚点那一格**算（取最大或取和都会让"贴岸横挪一格"在玩家眼里莫名翻倍）；
- `threatTiles()` 的距离改成量到整个矩形，否则 2×2 的威胁圈会少画右边和下边。

单位是 1×1 时，这两处的新逻辑与旧逻辑逐字等价（`cellsAt` 返回单格）——396 项规则测试、
26 项 AI 优化测试、7 项评估、142 项界面冒烟全绿，冻结基线逐字节一致。

两条按定位刻意偏离公式的：

- **火船 0.87**（同代 0.5~0.7）：它只活一回合。价值模型算不出"活不过一轮"，
  所以给它更高的纸面比值，用 34 血和甲 2 把它拉回来。
- **航母 0.18**：光是船体不值这个价。它的价值在甲板（4 架飞机）、旗舰光环和
  "四格航道"上，这三样都不进公式。

## 三、航母甲板接口

### 3.1 谁负责什么

| | 海军包（`naval-packs.ts` / `naval-carrier.ts`） | 空军扩展（将来） |
|---|---|---|
| 船 | 数值、造价、`DECK_SPECS` 里的机位与起飞半径 | 不碰 |
| 飞机 | **不创建、不定义** | 兵种、属性、造价、燃油、整备、损失 |
| 起飞 | 提供甲板空格与"轮到你了"的时机 | `launch()` 里建单位、定落点、扣油 |
| 回收 | 提供容器 `carrier.custom.airwing` | `recover()` 判断能不能收（弹尽？受损？船在沉？） |
| 上舰资格 | 不判断 | `canBoard()` 说了算（垂直起降 ≠ 重型轰炸机） |
| 面板 | 画「甲板 2/4 · 舰载航空兵」这一行 | 不画 |

两条硬线：

1. **海军包永远不创建飞机。** 没有空军扩展时，航母就是"视野 9 + 旗舰光环 + 防空"的指挥舰，
   照常能打完一整局。
2. **空军扩展永远不直接改船的数值。** 要改只能走 `ExpansionHooks.modify*`（纯函数），
   否则航母会在两个包里各有一套算法。

### 3.2 怎么接（空军扩展侧）

```ts
import {
  registerAirwingOps, popPlane, stowPlane, deckFree, deckSpecOf,
} from '../core/naval-carrier.ts';

registerAirwingOps({
  id: 'air-core',
  name: '舰载航空兵',
  canBoard: ({ planeTypeId }) => !['heavy-bomber'].includes(planeTypeId),

  launch: ({ state, carrier, plane }) => {
    // 落点、燃油、回合限制全归空军：海军只负责叫你
    const spot = /* 在 deckSpecOf(carrier.type).launchRange 内找空格 */;
    if (!spot) return { ok: false, reason: '甲板上没有能起飞的空域' };
    state.units.push({ /* 新建飞机单位 */ });
    popPlane(carrier, 0);
    return { ok: true };
  },

  recover: ({ state, carrier, plane }) => {
    if (deckFree(carrier) <= 0) return { ok: false, reason: '甲板满了' };
    stowPlane(carrier, plane);
    state.units = state.units.filter((u) => u.id !== plane.id);
    return { ok: true };
  },

  onDeckTurnStart: ({ state, carrier }) => {
    // 整备：补燃油、修损伤、决定哪几架能起飞
  },
});
```

三个约定：

- `launch()` 返回 `ok: false` 时**不要把飞机从甲板取走**——调用方原样留着，下回合还能再试。
  "起飞失败不该损失一架飞机"是这道接口的保证。
- 只有**一份** `AirwingOps`（后注册的覆盖先注册的）。想并存只能由空军包内部按 `canBoard` 分派。
- 飞机停在甲板上时**不占棋盘格**（已经从 `state.units` 摘出去了）。
  一艘航母四架飞机把周边八格全堵死，在规则上无法解释。

### 3.3 已经为空军准备好的东西

- 防空巡洋舰 / 航母的 `nv-aa-cover`（对 `layer === 'air'` 的目标 +12 伤害）：空军一上线，
  这条能力立刻有对象；现在它是空转的，但"哪条船能防空"是海军的设计决定。
- `DECK_SPECS` 里已经登记了两条船：航母 4 机位 / 起飞半径 2，两栖攻击舰 2 机位 / 半径 1。

## 四、两条海权规则（不绑兵种）

| 规则 | 实现 | 数值 |
|---|---|---|
| **封锁** | `modifyIncome`：敌方水面单位贴着你的城，那座城收入 −8 | 每座 −8，最多 −24（三座封顶） |
| **港口抢修** | `onTurnStart`：水面单位贴着自家城，每回合 +4 血 | +4，同回合只算一次（两个包同开也是 4） |

> 封锁本来想掐**回血**，翻核心时发现 `cityRegenOf()` 里已经有一条"城外有敌人就不回血"
> （围城），任何单位贴着城都算——再写一遍就是同一条规则的两份实现，看着像新机制，
> 实际什么都不做。所以改成断**税收**：三座城被堵，一回合少 24 金，这才是海权该有的疼。

为什么不给海军加"浅水 / 深水"新地形：那会渗进 `navigable()`、寻路和城市生成三处核心，
扩展登记了新地形也**没法告诉引擎"这一格也算水面"**。这一版宁可少一种地形，也不开这个口子。

## 五、与现代扩展的兼容

- `naval-modern` 写了 `requires: ['pack-contemporary']`：第六时代是这个包开出来的（`unlockEra: 6`），
  单勾「现代海军」船一条都造不出来——在玩家眼里就是"包坏了"。开局面板会自动把「现代」补上。
- 第六时代的水面力量从 1 条（导弹驱逐舰）补到 8 条，覆盖航母 / 战列舰 / 防空 / 潜艇 /
  两栖 / 快艇 / 补给七个位置。
- 十四个兵的 `costRes` 都不写（只要金币）：多资源是「战争经济」的事，
  海军包不在资源层上加要求，免得"开了海军就造不起船"。

## 六、测试（`scripts/test-rules.ts` → 「海军扩展」）

```
海军：两个包都注册上，兵种全是水面单位
海军：现代海军依赖「现代」，单勾它一条船都造不出来
海战：封锁让被堵的城少收 8 金，三座封顶
海战：船贴着自家城每回合回 4 点，两个包同开也只回 4
潜航：迷雾局里贴脸才现形，不开迷雾一律可见
岸轰：同一条船带不带这条能力，攻城差 25%
大型单位：航母占 2×2，能移动，但进不了一格宽的水道
航母甲板：没接入空军时明说，接入之后收放计数正确
航母甲板：回合开始会把"整备"这个时机转告空军扩展
```

「大型单位」那条是这批最该看的：它同时钉住三件事——四格都占着、能移动
（防回归成"不会动"）、**任何可达锚点的四格都必须是水面**（一格宽的水道进不去）。

## 七、这批没做的

1. **AI 不会用航母**：AI 的推进打分按锚点算，2×2 的船在窄水域里会犹豫。
   能开、能打，但不是"会开"。
2. **潜航只在迷雾局生效**：`isHiddenFrom` 的第一句就是 `if (!s.fog) return false`，
   所以不开迷雾时潜艇是明牌。想让它在无雾局也藏，得改核心。
3. **没有新地形**（见第四节末）。
4. **空军扩展还没写**：接口与容器都在，`AirwingOps` 目前是空的。
