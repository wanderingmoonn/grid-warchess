# 海军扩展 · 设计说明

> 两个包：**「海战」**（`naval-fleet`，第二~第五时代，15 条船）+ **「现代海军」**（`naval-modern`，第六时代，7 条船 + 1 座平台）。
> 7 条能力、2 条海权规则、1 套补给链、1 道留给未来空军扩展的甲板接口、1 对新地形（浅水 / 深水）。

| `src/core/config.ts` | `terrainDef` / `terrainCost` / `terrainName` / `passable` / `navigable` 各加 `deep` | 同上 |

## 二、战列舰：历史定位与"现代为什么没有"

### 2.1 定位前移到第五时代

| | 上一版 | 这一版 |
|---|---|---|
| 战列舰 | 第六时代，1150 金，攻 100 | **第五时代（二战）**，780 金，攻 95，射 5，甲 18，溅射 2 |
| 第六时代的大舰 | —— | **超巡**（1050 金，攻 85，射 6，甲 17）接位 |

数值上是"降一代、降一档价"：第五时代的战列舰要跟同代的装甲巡洋舰（400 金）拉开距离，但不能贵到"一把梭"。攻 95 / 甲 18 / 血 180 意味着它能一炮打穿巡洋舰，同时挨得住三四个回合的集火。三项攻城加成（破甲 + 破城 + 岸轰）全在它身上——**大舰巨炮的终点就是登陆支援**。

### 2.2 现代没有国家建造战列舰（三条原因，各补一刀）

1. **反舰导弹让"钢多"变成负数**。1946 年比基尼环礁的靶舰试验已经证明：几万吨的装甲在核爆面前只是"更贵的靶子"；到 1967 年"埃拉特"号被 3 枚冥河导弹击沉，结论彻底坐实——**装甲挡不住掠海飞行的半吨战斗部**。此后加厚装甲是纯亏本买卖。
2. **制海权从炮口挪到了机群**。1940 年塔兰托、1941 年珍珠港、1944 年莱特湾：航母在战列舰射程之外把对手打残。战列舰剩下的唯一活是**对岸火力支援**，而这件事 5 英寸舰炮的驱逐舰和后来的精确制导弹药都能做，不必养一条 5 万吨的船。
3. **成本与编制**。衣阿华级一艘的造价与人力，够养一整支航母战斗群的一部分；而它唯一不可替代的东西（重炮岸轰）在 1991 年之后就再没上过场。

所以游戏里第六时代**没有战列舰**，位置交给**超巡**：导弹时代的大舰是巡洋舰体量（基洛夫级 2.4 万吨，比衣阿华小一半还多）。它不是"更强的战列舰"，而是"射程换溅射"——没有 2 级溅射，射程 6，靠破甲和齐射打单个硬目标。

数值口径：`V = 攻 + 0.45×血 + 5×甲 + 3×射程 + 2.5×移 + 1.5×视野（溅射每级 +4）`，只看同代。
同代 V/价大致：E2 0.68~0.76、E3 0.57~0.87、E4 0.40~0.51、E5 0.25~0.49、E6 0.16~0.37。
**越往后越"不值"是刻意的**——贵兵天然更不值，这是被编制上限压出来的设计，不是漏洞。

### 3.3 为什么这 8 个新舰种不是重复品

| 易混的一对 | 差别在哪 | 数字 |
|---|---|---|
| 潜艇 vs 攻击核潜艇 | 射程/耐久/价格各一档，一个能撒、一个能单挑 | 62 攻 3 射 / 92 攻 4 射，300 vs 900 金 |
| 维修舰 vs 潜母 | 修水面 / 修水下，互不兼职 | +4 通用 / +6 仅潜艇 |
| 维修舰 vs 补给舰 | 一个管血，一个管腿 | +4 血 / +1 移 |
| 轻母 vs 航母 | 数量 vs 质量 | 甲板 2 / 甲板 4，640 vs 1350 金 |
| 航战 vs 战列舰 | 混血必然两头不精 | 攻 70（对 95）、甲板 1、还贵 80 金 |
| 战巡 vs 战列舰 | 同炮径，快 2 格、薄 6 甲、便宜 120 | 660 vs 780 |
| 运输舰 vs 两栖 | 纯运 5 舱 vs 运 4 + 甲板 2 + 防空 | 300 vs 760 |
| 超巡 vs 战列舰 | 时代不同：导弹时代的"大舰"没有 2 级溅射 | 射 6 无溅射 / 射 5 溅射 2 |

**刻意留下的短板**：航空战列舰（两头不精）、火船（只活一回合）、导弹快艇（挨一发就沉）、航母（自己不打架）。一条船如果没有任何短板，它就会变成"唯一该造的东西"。

职责边界与接入方式未变：

- 海军包负责船、机位、把飞机从棋盘摘下来存进 `carrier.custom.airwing`、把"整备"时机转告空军；

- 没接空军时，面板写「甲板 0 / 4 · 空军扩展未接入」，航母退化成视野 9 的指挥舰。

## 五、海上经济单位：钻井平台

| 项 | 值 |
|---|---|
| 造价 / 血量 / 护甲 | 480 / 90 / 6 |
| 移动 | **0**（造出来就不动了） |
| 产出 | 深水 **50**、水域 **34**、浅流 **20** 金/回合 |
| 回本 | 深水 9.6 回合、水域 14 回合 |

**产出机制**：`incomeByTerrain` 读脚下那一格。越往外海越肥，但离本土越远、补给线越长——**收益和防守难度是同一条曲线**。

**与海军的互动**：

1. **敌舰贴着就停产**（`modifyYield` 归零）。所以平台天然要求制海权；反过来，敌方的平台是最好的袭扰目标——打掉一座 480 金的平台，比击沉一条 300 金的运输舰更伤经济。
2. **它自己不能动、不能打**，是整张图上最需要护航的单位；一条 300 金的潜艇就能让它停摆。
3. 平台站在深水上，而**航母也必须在深水上**——两者抢的是同一片海。

## 六、浅水与深水：机制、数值、兼容性

### 6.1 先说清现状

地图上原本就有三种"水"：`water`（水域）、`shallow`（浅流，陆军能涉水）、`bridge`（桥面）。
所以这一版**不是新增两种水**，而是：**补上真正缺的"深水"**，并给已有的"浅水"一条真正的规则分工（吃水）。

| 地形 | 陆军 | 小船（1×1） | 大舰（2×2） | 桥能否架 | 说明 |
|---|---|---|---|---|---|
| `shallow` 浅流 | 可过（2 步） | 可过（1 步） | **不可过（搁浅）** | 不能（只认 water） | 渡口、河滩 |
| `water` 水域 | 不可过 | 可过 | 可过 | 能 | 沿岸与内陆水域 |
| `deep` 深水 | **不可过** | 可过 | 可过 | **不能** | 离岸 ≥2 格的外海 |

`passable('deep') = false`、`navigable('deep') = true`、`terrainDef = 0`、`terrainCost = 99`（陆军）、`terrainName = 深水`。

### 6.2 深水怎么来的

不是地图生成器画的，而是扩展的 `afterTerrain` 在**地形画完之后**做一遍改写：

```
从所有陆地出发 BFS → 每个水格得到"离岸几步" → ≥2 的 water 改成 deep
```

为什么不在 mapgen 里画：那等于让地形生成器认识一种"扩展才有的格子"，把扩展规则缝进核心。「地形高差」补山脚用的是同一招。

**只改 `water`，不动 `shallow`**——把浅流深水化会凭空掐掉陆军的过河口。

### 6.3 与各地形 DLC 的适配（含明确的不适配处）

| DLC | 影响 | 处理 |
|---|---|---|
| **地形高差** | 三张 `Record<Terrain, number>` 必须齐全（`TERRAIN_HEIGHT` / `TERRAIN_RANGE_MOD` / `TERRAIN_VISION_MOD`） | 补 `deep = 0`。深水与水域同高，**海岸 0→2 的落差不变**，爬坡规则在海上不触发 |
| **季节与气候** | `terrainClass()` 只把 `'water'` 归入水面档，深水/浅流会落进"其他"（= 温和，不参与天气判定） | **已修**：深水/浅流一并归入 `water`。否则开了气候包的对局里，**外海反而成了最安全的地方** |
| **城郭与物料** | 城 3×3、建材、港口 | 不受影响。城永远在陆地上，而深水按定义离岸 ≥2 格，不会顶到城格；临水造船位照旧靠 `navigable()`，深水也算 |
| **时代兵备 / 奇幻五包** | 只带兵种与规则 | 不受影响。浅流、沙丘、沼泽原本就是这一批地形里的 |
| **联机 / 存档** | `Terrain` 是字符串 | 老存档没有 `deep` 格，读取行为不变。**双方必须开同样的扩展**：一边有深水、一边没有，会得到两张不同规则的地图（这是所有扩展的通用前提） |

**明确的不适配，以及为什么不改**：

1. **桥架不到深水上**（桥的 `buildOn` 只认 `water`）。这是**有意保留**的：桥墩下不去那么深。海上长距离投送只能靠船，不能靠桥——这条同时也是"海军为什么有必要"的一半理由。要跨海大桥，得给桥单独加地形并单独定价，不在这一版。
2. **没有"临深水的城"**。深水离岸 ≥2，所以沿海城临的一定是 `water`/`shallow`。这省掉了一整类边界情况（城能不能在深水边造兵、贸易加成算不算），也是我刻意把"沿岸那一圈"留成水域的原因。
3. **`adjacentToWater` 漏算浅流**（已修，顺手）：以前农民站在渡口边上拿不到河运 +3，和当年"桥面不算临水"是同一类错。现在浅流、深水、桥面一并算。
4. **AI 不会"用"深水**：它会沿着 `reachableTiles` 走，所以**不会把航母开进浅流**（判据在寻路里，自动成立），但它不会故意用水道卡住你的大舰。这是"能玩、不精"的那一档。
5. **一格宽的河永远不会变成深水**（离岸永远是 1 格），所以「无渡口河」那张图不会被这次改动破坏。

## 九、这批没做的

1. **AI 不会经营海军**：它会造船、会开火、会绕开浅流，但不会编队（护航、封锁、平台保护都要人来做）。
2. **空军扩展还没写**：甲板接口与容器都在，`AirwingOps` 目前是空的。
3. **没有跨海大桥**（见 6.3 第 1 条）。
4. **潜艇在无雾局是明牌**：`isHiddenFrom` 第一句就是 `if (!s.fog) return false`，要改得动核心。
