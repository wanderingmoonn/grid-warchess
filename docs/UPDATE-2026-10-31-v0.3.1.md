# 版本 0.3.1 · 2026-10-31

本次发版做两件事：**下架「非对称开局」扩展**，并把它带来的冗余一起清掉；
同时把今天上线的三批改动（奇想扩展、选卡时限、产兵筛选）一并打包上线。

---

## 一、下架「非对称开局」扩展

### 删了什么

| 位置 | 内容 |
|---|---|
| `src/core/expansions.ts` | 扩展定义 `asym-opening`（先手工兵 + 斥候、后手两农一牧一步兵一弓手） |
| `src/core/expansions.ts` | `ExpansionHooks.startRoster` 钩子声明（**只服务于这一个扩展**，一并删掉） |
| `src/core/setup.ts` | 开局编制重摆的整段逻辑（约 45 行：清空 units、按名单摆位、写战报） |
| `scripts/test-rules.ts` | 「非对称开局」用例 |
| `docs/EXTENSIONS.md` | 纯规则扩展的计数与举例（13 → 12，总数 26 → 34 的陈旧数字一并改正） |
| `public/manual*.html` | 规则书里的「非对称开局」小节与目录项（`npm run manual` 重新生成） |

### 为什么把钩子也删掉

`startRoster` 是"整批换掉开局部队"的专用接口，全仓库只有「非对称开局」一个使用者。
留着它等于在接口层留一个永远返回 `undefined` 的入口——下一个人读 `setup.ts` 会问
"这里为什么有一段没人用的重摆逻辑"，而答案是"曾经有一个扩展"。所以按删除任务的要求，
**接口与实现一起下架**，不留死代码。

### 影响

- 开局部队回到统一的默认编制（3 战斗 + 2 经济），两边完全对称；
- **老存档不受影响**：`expansionIds` 里就算还留着 `asym-opening`，也会被当成"不认识的名字"忽略，
  不会崩、不会少兵；
- 其它 34 个扩展、所有兵种与规则一行未动。
