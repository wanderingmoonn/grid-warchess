# 2026-10-30 · 修真扩展：合入分支、数值重排

分支 `The-Age-of-Cultivation` 上的修真扩展（第一个兵种「炼气士」）合进 `main` 并上线。

## 一、这次合的是什么

`main` 里原本就有一份 `src/core/cultivation-packs.ts`（10-30 合并上游时带进来的初版，
包名「修真·炼气」）。分支上那笔 `9d83842 修真的第一个兵种基本完成，可以投入测试` 把它整个重写了。

| 项 | 初版（main） | 分支版（本次上线） |
|---|---|---|
| 包名 | 修真·炼气 | **修真** |
| 造价 / 移速 / 视野 | 100 / 2 / 3 | 不变 |
| 攻击 / 生命 / 射程 | 1 / 2 / 2 | **10 / 20 / 1** |
| 升级门槛（exp） | 2^(r+1)：2/4/8/16/32/64/128/256/512 | floor(10+10r(r+1)+0.05·4^r)：**10/30/70/133/222/361/634/1389/4006** |
| 打坐经验 | 2r+2 | r+3 |
| 击杀经验 | 15 | 10 |
| 寿元 | 5+5r | 5+10r |
| 攻击修正 | 2r − 2·衰老 | floor(5r + 2^(r−0.5) − 2·衰老) |
| 护甲修正 | r − 衰老 | floor(−1 + r² + 1.5^r − 衰老) |
| 真实伤害 | floor(r/2) | floor(r²/2 + r·1.2^r) |
| 突破加血 | 固定 +5 | floor(8.5·Δr + 0.685·(r³·1.8^r − r′³·1.8^r′)) |
| 破碎提示 | 「突破至 N 层」 | 「突破至 炼气／筑基／金丹… 期」（`_REAMS` 那张表） |

射程 2→1 是配套的：射程改成随境界 `floor(r/2)` 成长，初始就给 2 会让 9 级修士拿到 6 格。
攻击次数 `floor((r+1)/2)`、溅射 `floor(r/4)`、移动 `2+floor(r/3)`、神识 `3+r−衰老` 没动。

**没合进来的**：`4834906 尝试自带规则书，但是没学会`——它只改了 `manual-small.html` 三行，
而规则书是 `scripts/build-manual.ts` 生成的产物，所以这里走重新生成，不保留手改。

## 二、补回被删掉的两条用例

分支重排经验曲线时，把「移动力随境界提升」和「神识随境界提升」两条用例直接删了
（阈值全错位，作者选择删而不是重算）。**功能都还在**，删掉的只是覆盖率，所以补回来并按新曲线重算：

- 移动力：0/2/3/5/6/8/9 级 → 经验 0/30/70/222/361/1389/4006 → 移动 2/2/3/3/4/4/5；
- 神识：基础 3，`3 + r − 衰老`，下限 1；8 级衰老 2 岁 → 9，面板明细的标签也改成新的包名「修真」。

顺带说明为什么门槛表从 `0/4/8/32/64/256/512` 变成上面那串：
`getRank` 是"从 0 级开始，每满足一道坎就 +1"，所以 **exp 70 是 3 级而不是 2 级**
（2→3 那道坎正好是 70）。第一次按"跨越值"算错了一格，测试当场抓住了。
