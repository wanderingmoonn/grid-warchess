# v0.3.28：十六个包并成四个

一句话：**开局面板从 34 个勾变成 23 个**——不是删内容，是把"同一套玩法的几个包"并成一个。

## 并了什么

| 原来的包 | 现在 |
|---|---|
| 青铜会战 / 铁器兵备 / 火器列国 / 蒸汽绞肉机 / 机械化合成兵 + 现代战争 | **时代军备** |
| 奇想·法则 / 骑士团 / 荒兽 / 秘法 / 英雄 | **奇想** |
| 海战 + 现代海军 | **海军** |
| 空军 + 现代空军 | **空军** |

兵种一个没少：扩展兵种仍是 241 个，`npm run manual` 的统计口径没变（53 个原版 + 241 个扩展）。

## 为什么并

不是"包太多了看着乱"，是**每多一个勾，就多一次判断题**：

- 时代军备拆成六个包时，玩家每开一局都要把它们找六遍；只勾一两个就以为"开完了"。
  而这六个包说的是同一件事——**这一代还有哪些兵可选**。
- 奇想那五个包更麻烦：后四个都 `requires` 第一个，勾一个兵种包，面板会顺手把「法则」补上。
  机制没错，但玩家看到的是"我明明勾了奇想，怎么没有龙"。这类问题在群里出现过不止一次。
- 海军/空军各拆两包，是为了表达"第六代要等「信息化」"。而这件事一个兵种级字段
  （`requiresPack`）就能说清，不需要一整包。

## 第六代怎么还留着门

时代军备里的 15 个专精兵、海军的 12 条现代船、空军的 9 架现代机，都打了
`requiresPack: 'pack-contemporary'`：

- 开了「信息化」→ 它们进本局兵种表；
- 没开 → 不进。既不占面板，也造不出来（造不出来的兵等于没有，这正是当年拆包的理由）。

判据在 `setup.ts` 的 `expansionUnitsFor`，**开局面板的兵种池用的是同一个函数**，
所以"面板上勾着、进局后造不出来"这种病不会出现。

「信息化」仍然是唯一能把科技线推到第六级的包（`unlockEra: 6`）——时代开关只有一处。

## 老存档、老报告、老链接怎么办

扩展 id 会进**存档、对局报告、联机快照、导出的对局文本**。直接改名等于让这些东西
在打开时变成"本机没有的规则"，玩家看到的是"我的存档坏了"。

所以留了一张别名表（`expansions.ts` 的 `MERGED_INTO`）：

```
pack-antiquity / pack-medieval / pack-gunpowder / pack-industry / pack-modern
pack-contemporary-war                                  → era-arms
fantasy-core / -knights / -beasts / -arcane / -heroes   → fantasy
naval-fleet / naval-modern                              → naval
air-corps / air-modern                                  → air
```

三个入口都做迁移：读档（`storage/save.ts`）、建局（`createMatch`）、导入对局。
迁移是**幂等**的，去重也在里面（老配置同时有 naval-fleet 和 naval-modern 时只留一个 naval）。

顺带守住的几处不是"顺手就能过"的地方：

- `enabledExpansionIds` 先迁移再判前置——`requires` 里写的是新 id，
  老配置不迁移会被判成"前置没满足"，整包被剔掉；
- `activeExpansions` 先迁移再取——否则读档之后所有扩展规则突然失效；
- 规则书书单（`ui/books.ts`）先迁移再比对——否则老存档会少掉整册，
  而玩家不知道"规则书去哪了"；
- 选卡的"体系加成"改成按 id 精确判断：原来用 `startsWith('naval-')` / `startsWith('pack-')`，
  合并之后一个都匹配不上，表现是"开了海军，选卡名额没涨"。

## 规则书

九册不变，但合册的成员从"按 id 前缀分组"改成**显式 id 列表**：前缀规则在合并后全部失效
（`fantasy` 不以 `fantasy-` 开头）。每册开头那段"这一册收了几个包"也按新结构重写了。

## 用例

规则 549 / 界面 174 / 静态服务 11 全绿，AI 那两套也过。改的地方分三类：

1. **结构断言换了口径**：原来查"七个包、每个包只属于一个时代"，现在查"时代军备里每一代的兵
   都多于原版同期"；奇想那几条从"包之间的搬运关系"改成"内容唯一性与数量"。
2. **id 换新**：`naval-fleet` → `naval`、`fantasy-beasts` → `fantasy`、`pack-antiquity` → `era-arms`；
   同时补了"旧 id 走别名、结果一致"的断言（迁移这件事本身要有测试盯着）。
3. **一条 AI 用例的窗口从 6 个回合放宽到 8 个**：奇想并包之后这个局面里的候选兵种从 14 个
   变成 72 个，"先铺经济、再谈英雄"的顺序没变，但第一次买英雄落到了第 7 个自己的回合。
   同时把"不许往弃城投钱"的判据从"开局那个 id 用到底"改成**每一步现算**——
   威胁半路解除时弃城决定会当场作废，钉死会误报。

## 怎么验

1. 开局面板：23 个勾，能一眼找到「时代军备 / 奇想 / 海军 / 空军」。
2. 只勾「时代军备」开局 → 兵种池里没有第六代兵；再勾「信息化」→ 多出 24 个（9 底座 + 15 专精）。
3. 只勾「海军」→ 没有航母；加「信息化」→ 航母、核潜艇都回来了。
4. 打开一份**旧存档**（或者用旧版本的"导出对局"文本导入）→ 兵种、规则、规则书分册都在。
