# 飞行：空中层不再有地形，AI 也不再"看不见对岸"

2026-11-02 · 只动移动规则与 AI 的距离图

## 症状

飞机还是飞不进深水。而规则层其实早就放行了——真正的问题有三层，一层压一层：

1. **放行的口径窄了一格。** `reachableTiles` 的 `terrainOk` 只给"水面 + 深水"开口子
   （更早的版本连深水都没有），高山和火山照旧是墙。飞机于是能飞过整条河、
   飞不出外海、也爬不过山——三件事看起来是三个 bug，其实是同一条判据写窄了。
2. **能过和能停是两套判据。** `terrainOk`（能不能进）和 `tileStandsOk`（能不能停）
   各写一遍，改一处漏一处，表现就是"飞得进去、停不下来"或者反过来。
3. **AI 根本没算出该往哪飞。** 这条最隐蔽：`tacticalMoveScore` 给飞行单位借的是
   **陆军的旱路图**（水是墙、山是墙）。站在海岸线上，`advanceDistance` 前后都是
   `Infinity`，推进分恒等于 0 —— 可达格明明白白列着 68 格深水，它一格都不去。
   玩家看到的仍是"飞机不能飞过深水"，但规则早就允许了。

## 改法

### 规则：空中层没有地形

一句话：**`layer: 'air'` 的单位无视一切地形，唯一挡得住它的是敌方城市**（那是防空，
不是地形）。`flight: true` 但不是空中层的单位（鹰、石像鬼）仍然只放行水面与深水——
它能贴水飞，但爬不了山。两件事从此分开写：

| | 水面 / 深水 | 高山 / 火山 | 敌方城市 |
|---|---|---|---|
| 空中层 `layer: 'air'` | 过 + 停 | 过 + 停 | 挡住 |
| 掠水 `flight` | 过 + 停 | 挡住 | 挡住 |
| 陆军 | 挡住 | 挡住 | 挡住 |
| 水军 | 过 + 停（浅滩看吃水） | 挡住 | 挡住 |

`terrainOk` 和 `tileStandsOk` 用**同一条**判据，不再各写一份。
另外空中层的步耗固定为 1（`flyer || air`）：既然能过高山，就不该按地形的 99 点收费。

### AI：给空中一张自己的距离图

`cityDistanceField` 新增 `mode: 'air'`——地形不存在，每格一步。
`Fields.air` 整回合算一次，`tacticalMoveScore` / 基础档的 `scoreMove` 都按
`airLayer(def)` 选图，不再借陆军的旱路图。

顺带把"集结"那条排除掉：空中的距离是每格一步，和地面的战线长度不是一个量纲，
拿它去比 `lineRef`，飞机几乎永远算"在战线前面"，推进分会被砍到 15%。

## 验证

- `npm run test:rules` 516 项（+2）：
  - **空中层无视地形**：深水、高山都能飞进去，也能停；掠水单位能过深水、爬不了山。
  - **AI 会飞过海**：14×14、中间一条 4 格宽深水、敌城只在对岸，飞机这一回合
    必须把落点推进深水带。改动前这条断言失败（AI 掉头去围同侧那座城/原地不动）。
- 冒烟：开「空军 + 现代空军 + 现代 + 地形高差」跑一局 AI 对局（33 回合），无异常。
- `tsc` 干净；`npm run test:ui` 166 项、AI 评估门槛 7 项照旧全绿。

| 文件 | 改动 |
