# 四个修复：聊天配色、三人局认输、状态不同步、掉血战报

2026-11-02 · 只动界面与联机同步，不改规则数值

---

## 一、聊天色条：红方说话顶着蓝条

**症状**：同一个房间里，有时红方说的话显示成蓝色。三人四人局里更乱。

根因有两处，叠在一起：

1. `net/chat.ts` 的 `toLine` 把席位写死成两种：

   ```ts
   row.seat === 'B' ? 'B' : row.seat === 'watch' ? 'watch' : 'A'
   ```

   C、D 座一律塌成 A 座。三人局里绿方说的话，被当成红方。

2. `chatLinesHtml` 只给 `mine` / `foe` 两个类，CSS 拿 `--team-a` / `--team-b` 上色，
   也就是"我永远红、对面永远蓝"。**蓝方玩家看红方说话，那条色条是蓝的**；
   观战位更彻底——`mine` 是 `watch`，于是所有人都变成"对方"，全蓝。

改法：颜色跟**说话人坐哪**，不跟"我方/对方"。

- 新增 `chatSeatOf(raw)`：A/B/C/D/watch 原样保留，认不出来的老数据退回 A 座。
- 行上多一个 `seat-a/b/c/d` 类，CSS 按席位取色；`mine/foe/watch` 只留文字标签和灰条。
- 四人份配色本来就有（`--team-c` / `--team-d`），只是聊天没接上去。

## 二、三人局认输：认输了，但房间不知道

**症状**：三人局里有人认输，剩下两家看不到，行动权卡在认输者身上，整局停住。
四人局是同一个 bug。

规则层 `doSurrender` 本来是对的（退出自己、交出行动权、不判胜负），问题在联机提交：

```ts
// main.ts dispatch()
if (room && !prevWinner && state.winner) { pushTurn(...); }
```

只有"这一下分出了胜负"才提交。两人局认输会直接判负，所以能触发；三人四人局
认输**不判胜负**（剩下的人接着打），`state.winner` 是空的 → 认输那一下从来没交上去过。
认输的人自己退出了，云端还是旧局面。

修法：退出名单变长也立刻提交。

```ts
const quitNow = (state.out ?? []).length > (before.out ?? []).length;
if (room && (quitNow || (!prevWinner && state.winner))) pushTurn(...);
```

配套两处：

- **对方怎么收到**：见第三节。认输既不推进回合、也不……以前连"行动方变了"都不看，
  所以就算提交了也收不到。
- **认输者自己的界面**：以前顶栏继续写"等待 XXX"、按钮写着"等待对方行动中"，
  看上去像在等一个永远不会轮到的回合。现在顶栏是"你已认输 · 观战中"，
  两颗按钮都禁用，按钮文字改成"已认输 / 只能看"。

## 三、只有轮到自己才更新棋盘和当前行动方

**症状**：交完回合之后，对面走完的那一整轮自己看不到——棋盘、顶栏的当前行动方、
战报全停在自己交回合那一刻，直到下次轮到自己才整块跳过去。三个人打时更是
B 和 C 的来回完全看不见。

根因是 `net/room.ts` 的 `adoptDecision`：

```ts
if (remote.current !== seat.seat) return { take: false, why: 'not-my-turn' };
if (remote.turn === local.turn) return { take: false, why: 'same' };
```

两条都在挡：不是我的回合不装、回合没变不装。第二条正好也是三人局认输收不到的原因
（认输只换行动方）。

改成：

```ts
if (seat.draft) return { take: false, why: 'draft' };          // 只有未提交的草稿还挡着
if (remote.turn !== local.turn || remote.current !== local.current) return { take: true, ... };
```

云端 state 只在**交回合**时写入（`submitTurn`），装进来的永远是走完的一轮，
不存在偷看对面半回合的问题。

顺带修了那句提示语：以前固定"对方已提交，轮到你"，现在按实际状态说
"轮到 XXX 了"或者"XXX 认输退出，还剩 N 家"。

## 四、掉血进场：中毒看不见、状态没有地方读

两件事一起补。

**(a) 战报**：中毒 / 灼烧在**挨打那一方的回合开始时**结算，日志挂在受害者名下，
而且没标 `open`（公开）——自己毒了对面，对面掉血那一条只有对面看得见，
施法者这边一笔都读不到。现在这两条标成公开（血条就摆在棋盘上，本来也不是秘密）。

另外 `decayUnits`（土墙、临时召唤物每回合自损）以前一声不响地扣血：
血条自己变短、战报一个字没有。现在写"自身损耗 N 点生命"。

**(b) 状态栏**：单位卡的血条下面多一行徽标，写清身上挂着什么、还剩几回合：

```
生命 34 / 70
[中毒 3 回合] [灼烧 2 层] [减速 1 回合]
```

口径：`burn` 的值是**层数**，其余是**剩余回合**——两者在数据里都是一个整数，
只能按 key 区分；写错单位比不写更糟（"中毒 3 层"会让人以为伤害要乘三）。
顺序沿用 `orderedStatuses` 的固定序（中毒 → 灼烧 → 减速 → 诅咒 → 咒缚），
和战报用同一套顺序，复盘时两边对得上。鼠标悬停显示状态说明。
