# 为什么这些路都没走通（截至 2026-11-06）

三次转向、四条技术路线、约 1.4 万局对局，棋力停在原地。这份文档只回答一个问题：
**每一条路具体死在哪，以及它们是不是同一个死法。**

---

## 一、先给结论：三条错配

| | 错配 | 一句话 |
|---|---|---|
| **A** | 作用域 | 所有改动都在"这一回合选哪一手"里，而胜负由"十回合里有没有坚持一件事"决定 |
| **B** | 量级 | 旋钮能搬动 5~9 分，场上的判决量级是 120 分（击杀） |
| **C** | 计量 | 用终局胜率去测局部改动，于是"没生效"和"没好处"被混成一个 50% |

这三条互相掩护：因为 C 分不清，A 的错误看起来像"参数没调好"，于是继续在 B 上找原因。

---

## 二、逐条路径的账

### 1. 手写启发式的参数调优（采购配比 / 战术权重 / 结构闸门）

| 干预 | n | 计分胜率 |
|---|---:|---:|
| 五条结构性改动 | 200 | 46.0% |
| 按战术平移采购配比 | 800 | **43.9%** |
| 速攻期加攻城器 | 800 | 50.3% |
| 三回合计划（浅） | 400 | 49.5% |
| 三回合计划（深） | 240 | 49.6% |
| 深计划 + 节奏判据 | 200 | 49.8% |
| 集结闸门（局部支援） | 800 | 48.2% |
| 收紧 harass | 800 | 49.1% |
| 高级档打开战术层 | 800 | **43.3%** |
| 战术层增益 ×4 | 400 | 46.5% |

**死因（A+B）**：打分函数是"局部项求和"，每一回合从零重算 argmax。参数改动只能把
候选动作重新排序，不能制造连续性——不能让 AI 连续八个回合造同一种兵，也不能让它
为了三回合后的总攻放弃眼前的交换。而后者才是这套游戏的胜负手：一个三十行的手写脚本
（无脑堆龙骑兵、只打经济）对同一个 AI 是 **87.5%（35:5）**。

### 2. 加深搜索（三回合推演 + 局面估值）

**死因（A）**：推演的叶子节点上用的还是同一个局部评估函数。把错误的目标函数算得更深，
只会更精确地算错。840 局合计 49.6%，与"搜索没有改变评估的语义"一致。

### 3. 战术层（rush / harass / boom 三套 doctrine）

- 自动选择：`drive = clamp01((weight − 1/3) × 3)`，平均权重 0.321/0.333/0.346 →
  平均 drive **0.00 / 0.00 / 0.04**；同局面动作一致率 **98.5%**（n=20775）。
  也就是说这一层在绝大多数回合**一声不响**。
- 补量级：把增益提到 ×4，动作变化 9.4%（是原样的 6.7 倍），400 局 **46.5%（z=−1.40）**。

**死因（A）**：战术层是"偏好"，不是"计划"。它能让某类动作加 90 分，但不能让 AI
承诺"接下来十回合都这么打"。反证：指挥官模式（玩家点名）有效——同样的三个权重，
但它是**把承诺写在 AI 之外**，AI 不再每回合重新投票，实测第一步动作 13% 不同。

### 4. 强化学习（V2 自对弈）

34 轮自对弈，对"不削弱的手写 AI"54.4%，但玩家视角完全不可用：只会堆弓兵、
不会造建筑、升不起时代、看不见地图尺寸。

**死因（另三条，见 `docs/RL-AI-POSTMORTEM-2026-11-06.md`）**：
- 观测里没有地图尺寸，兵种特征缺 hp / move / vision / 能力；
- 动作预筛挡掉 53.4% 的 RECRUIT 步数、87.6% 的 UPGRADE，导致 BUILD 从未成为合法动作；
- 奖励只有胜负，且自对弈是**同分布自嗨**——它学会的是"怎么打赢自己"，不是"怎么打赢人"。

### 5. 窄决策（上下文 bandit）

720 局强制战术采集：rush 49.6% / harass **34.8%** / boom 54.0%。
这组数是真的，但它量的是"**被迫**执行某套战术"的收益，而战术的真实收益取决于
执行是否一贯。用它去改"自动选择"的权重，等于假设战术可以逐回合独立挑选——
这与第 3 条的结论冲突：逐回合挑选本身就抹掉了战术。

## 三、"中性"有两种，我们混了三个月

| 表面数字 | 实际含义 | 该怎么处理 |
|---|---|---|
| 49~50% | 改动**没到动作层**（量级不够 / 被档位门清零） | 先量动作变化率，再谈胜率 |
| 49~50% | 改动到了动作层，但**不影响结果** | 换层，不要在同一旋钮上继续调 |
| 46~48%，z<−2 | 改动有害 | 立即回滚 |

前两类在旧流程里长得一模一样。这就是为什么"十二次中性"里有一半其实是第一类，
而我一直按第二类在解释。

---

## 四、可检验的预测

若 A 是主因，则应观察到：**任何继续调"每回合打分"的改动都会继续中性。**
十次干预、43.3~50.3%，与预测一致。

反过来，唯一还没被证伪的方向必须满足：**某一回合的决定依赖前几回合的承诺**——
即存在一个跨回合的状态（目标兵种 / 目标数量 / 发起回合），并且承诺期内不许改主意。
手写脚本之所以 87.5%，正是因为它天然有这个状态（写死在代码里）。

---

## 五、判据（以后任何 AI 改动都先过这四关）

1. **触发率**：新规则一局触发几次？< 1 次/局 → 无效，删。
2. **动作变化率**：同局面动作一致率降了多少？< 5% → 不跑胜率。
3. **量级对表**：改动的分值 vs 判决量级（击杀 120 / 威胁 25~100）。
4. **作用域**：这个改动能不能影响"连续多个回合的同一个决定"？不能 → 它最多只能做微调，
   不要期待它改变胜率。

## 六、补记（同日更晚）：为什么 AI「发现不了下一个龙骑兵」

这个问题有确定答案，而且不是能力问题，是**两把尺子**。

`src/core/ai.ts` 里 `combatPower` / `combatEfficiency` 默认用的是**旧尺子**
（`攻×√血×射程`），因为 2026-11-03 把采购切到新尺子（兰彻斯特 + 移速/视野/时序 +
特性计价）之后，**镜子对局从 50% 掉到 35%**，所以加了 `WB_RULER` 开关并默认退回。
原注释（`ai.ts:4181`）写得很清楚：*"贵兵需要一套 AI 还没有的战术"*。

于是同一张卡在两张表上是两个位置：

| 兵种 | 旧尺子（**实际用于采购**） | 新尺子（**只用于报表**） |
|---|---:|---:|
| 龙骑兵 | **79 / 99**（性价比 2.28） | **16 / 99**（7.10） |
| 皇家骑兵 | 26 / 99（4.72） | 11 / 99（8.38） |
| 民兵 | 19 / 99（5.24） | 49 / 99（4.36） |

旧尺子只读攻/血/射程，**不读移速、视野、溅射、能力**——恰好把"某种强卡"最贵的那部分
当成了零。后果不止是采用率：**任何用这个 AI 跑出来的平衡报表都会系统性低估这类兵种**，
报表说强、采购不买，两边打架。

当日实测（400 局，era 3 / advanced，新尺子 vs 钉死旧尺子的冻结副本）：
**45.1%（z=−1.95）**——方向与 11-03 一致（那次 35%），中间几次尺子校准把差距从 15 点
收到 5 点，但没有关上。

**结论**："看见强卡"（尺子）和"用出强卡"（战术）是两件事，现在是二选一：
- 开新尺子 → 报表与采购同源，但玩家面对的 AI 弱 4~15 点；
- 关着 → 棋力保住，但平衡报表没有参考价值。

要同时拿到，必须先补上那条注释点名的东西：一套能让贵兵被用出来的战术（集结/承诺）。
这也是"让人手写的九十行脚本打出 87.5%"暴露出来的同一个缺口。
