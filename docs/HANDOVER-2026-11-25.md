1. bump `package.json` 版本号，提交 `release: vX.Y.Z —— 说明`
2. `npm run build:static`（直出 `_publish/`，含 art:index）
3. 用 sites 工具发布 `_publish/` 目录（appId `wbapp_fUY7GgSFcMVuqHwAfJD668`，链接不变）
4. 校验：线上 sha256 与本地逐字节对比 + 关键串 grep + 无 sharecode 应得 403

### 多远端注意

- `origin`（ssh 主库）/ `ip`（https 代理）/ `mirror`；**新分支可能先出现在 `ip`**，检查分支前先 `git fetch --all`
- `merge-all` 分支挂在 worktree 上（`git branch` 里带 `+` 号），别在主工作区直接切过去
- push origin/main 会触发"必须走 PR"的保护，但已配置 bypass，直接推即可
