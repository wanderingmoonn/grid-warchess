## 怎么复盘

把 json 拖进游戏页面（或首页点「复盘」选文件），进度条按步、`←` `→` 步进、空格播放。
点棋子可以看它当时的属性卡。

## 复现命令

```bash
node --experimental-strip-types scripts/rl/export-loss.ts \
     --weights .tmp/mix1/weights-12.json --size 12 --games 48 --seed0 2000
```

同一份权重 + 同一批种子 → 同样这两局（一短一长取的是这批败局里的两端）。
