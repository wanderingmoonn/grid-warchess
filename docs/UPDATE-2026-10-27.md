## 一、打起来能感觉到的

### AI 不再卡在河边、也不再穿墙

以前中后期常看到一支 AI 部队贴着河岸来回磨：它算得出"涉水很贵"，于是宁可停在河边也不绕路，
而真正能过河的地方在两格之外。根子不在搜索，在**代价模型**——所有能走的地方都只标了价，
没有"这里根本过不去"这一档，于是"停在最便宜的地方"永远比"绕远路"划算。

现在距离场分成三张：**旱路**（水面和高山都是墙）、**涉水**（山是墙、水很贵）、**水路**（只走水和桥）。
推进时优先用旱路图；旱路到不了的角落，才用涉水图兜底，并且给兜底值加一个比任何真实旱路都大的底座，
保证它只在"真的没有旱路"时生效。桥的选址也跟着改用涉水图，架桥的位置终于和部队实际能走的路线对上了。

> 实测：`river-h` 地图第 777 号种子跑 45 回合分出胜负，期间双方一共架了 9 座桥。

### 浓雾不再是一次性的黑暗

「浓雾蔽野」原来的行为很绝对：只要视野一走开，连地形都变回一块黑。等于说第二次经过同一个路口，
和第一次来没有任何区别——这不叫迷雾，叫失忆。

现在分三档：

| 状态 | 画成什么 |
|---|---|
| 眼前看得见 | 照实画 |
| 去过、但现在看不见 | 按**上次看到的样子**画：地形压暗一档；城市变成虚线框，牌子上写「旧情报」 |
| 从没去过 | 一片黑 |

两个细节是有意为之：

- **旧情报不画血条**。上次看到的耐久早就不是现在这条了，画出来是假消息；
- **记忆只说当时**。城在雾里升了级、易了手，你看到的还是当时那份——想知道新的，就得再去一次。

基础规则的雾（不勾「浓雾蔽野」）没有任何变化：它只遮单位，地图一直画在屏幕上，所以也不需要记地形。

### 城市挨着好几片水时，水军可以自己挑从哪片下水

以前只能从列表里的第一格下水。想让船从另一侧绕过去，唯一的办法是先把那格水填了。
现在点水军的产兵按钮会先"上膛"：棋盘上把能下水的水面点亮，点哪格就从哪格出；不点就还是老行为（第一格）。

### 对方行动时也能点开单位看数据

以前对方回合、AI 走棋时、指挥官模式里点谁都没反应——不是"看不了"，是那三条路径各自提前 `return` 了。
现在统一到一个入口：任何时候点单位，都能看到它的数值、技能、地形加成。

### 战报只给自己看自己干的事

以前战报是双方共用的，于是「我造了三个长弓手」这种句子对面也读得到——等于免费送视野。
现在战报分两类：

- **私报**：我造了什么、攒了多少钱、往哪走了，只给我自己；
- **公开**：谁倒下了、哪座城破了、谁认输了——棋盘上本来就看得见的事，双方都能读，瞒着只会让人以为界面算错了。

第三方观战位照旧看得到全部。

### 兵种搜索框不再吞字

用中文输入法打「chuan船」，出来的是「chuan船an船」。原因是每敲一个字就把列表整块重绘一次，
浏览器把组字的按键重新投回输入框，字就被插了两遍。现在组字期间只记字、不重绘，列表在整词上屏后再刷。

### 沙盒打完不回顶端

上帝模式里一场几十回合的仗打完，界面会重绘，战报和货架的滚动条一起归零——正顺着往下读的人得重滚一遍。
现在重绘前后会把侧栏和两个内层滚动容器的位置一起记住、再放回去。

## 二、规则与平衡

### 兵营按自己的时代产兵

兵营不再"跟着后方城市换代"。落成那一刻，它的补给时代就钉死了：I 时代的兵营就算旁边的主城升到了 III 时代，
它出的还是 I 时代的兵。面板上也写清了这件事（「落成于 X 时代，后方已到 Y，这座营不跟着换代」），
免得玩家以为界面算错了。想换兵就拆了重盖——这也是兵营便宜的原因。

### 敌方城市里造不了东西

以前可以跑到对面城里插一座箭塔。现在选址时会逐格检查：只要有一格属于敌方城市，就拒绝，并说明理由。

### 史莱姆牢大不再对着空气行动

两个技能（分裂、融合）以前只看冷却和血量，方圆八格内一个敌人都没有也照放。
现在先确认周围有敌人再动——AI 的行动力很宝贵，不该烧在空气上。

## 三、新东西

### 上帝模式能改地形

工具栏多了一组地形笔刷：平原、森林、丘陵、水、山、桥。城格上、站着单位的格子上、以及本来就一样的格子上不给刷
（刷了也没有意义，只会让人以为按钮坏了）。

### 按扩展包筛兵种

兵种越加越多，一屏四十多个。城市产兵、兵营产兵、沙盒货架三处都多了一排包名按钮：只看原版、只看某个扩展包，
或者看全部。只列**这一局真的出现过的包**——列一排点进去全是空的按钮，比不筛更烦人。

### 对局数据：可选、默认关、先摊开再问

一局打完，结算卡上会多一块「这局的数据要不要捐出来」。

- **默认是关的**。勾选框只代表"允许"，点按钮才真的发；
- 发之前把要交的**一条条列出来**：地图种子、棋盘尺寸、行动次数、胜负、扩展组合、AI 难度、双方终局阵容与资源、地形分布；
- 同时写清**不交**什么：玩家名、房间码、每一步的操作记录、自定义兵种的说明文字；
- 传不上去（没开通／凭据过期／断网）不影响任何事：报告随时能「复制」或「下载 .json」，自己发出来一样有用；
- 同一局传过就记在本机，刷新页面再看见结算卡只会说"传过了"，不会悄悄再补一份。

**为什么要做**：哪个兵种偏贵、哪套扩展一开就一边倒，靠自己和朋友打的几十局是看不出来的。
双 AI 观战局也算（那正是最该被收集的一类数据），沙盒和联机观战位不算（一盘是摆出来试兵的，一盘不是你的对局）。

## 四、要收数据的话，需要你做一件事

云端要真的开始收，得在云数据库里执行一次 [`sql/warchess_reports.sql`](../sql/warchess_reports.sql) 建表。
不建也能玩：界面会明说"收集端还没开通"，并把复制／下载留在原地。

这张表**只给匿名写权限、不给读权限**——谁都能交一份，但没人能顺着它把别人交的整锅端走；要做分析请用管理员连接。

## 五、验证方式

```bash
npm run test:rules   # 303 项：寻路、迷雾记忆、军营时代、敌城禁建、水军下水点、报告不含玩家名……
npm run test:ui      # 108 项：浓雾三档、扩展包筛选、滚动保持、战报过滤、输入法组字、结算上传卡……
npm run build        # tsc --noEmit && vite build
npm run manual       # 重新生成规则书（本批改了玩法文案）
```

几条值得单独点出来的用例：

- 寻路：山墙与水各挡一条路，要求 AI 绕开；涉水兜底值必须比任何真实旱路都大（否则"停在河边"又会赢）；
- 浓雾：侦察一次再撤回来，要求那片地形**仍按记忆画**、敌城**变成旧情报**、且城在雾里升级后记忆里的时代不变；
- 报告：把双方玩家名设成中文名字，要求整份 JSON 里**一个都不出现**；
- 界面：打完之后上传卡默认不勾、勾了按钮才活、失败必须落到界面上并给出下一步。
