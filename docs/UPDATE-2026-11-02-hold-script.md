## 二、规则 → 实现对照

| 规则原文 | 实现 | 代码位置 |
|---|---|---|
| ① 开局放弃一座城，永不升级；只有敌军来了才放几个小兵 | 放弃城 = **离敌方城市最近**的那座；按 `seed:座位` 记忆一次，不随后续局面漂移（规则说的是"开局决定"）。敌军进到 4 格内、且它周围我方战斗单位 < 3 时，造 ≤120 金的便宜兵 | `abandonedIdOf()` / 末段"规则 ①" |
| ② 前期持续造经济单位，不造军事单位 | `era < 4` 时只要产兵名额没用完，就在保留城造经济单位（按 `income` 排序）；经济单位还会自己走到能走到的**最赚钱的格子**上 | "规则 ②" / `shuffleEarner()` |
| ③ 每回合判定：现有金 + 3 回合收入 ≥ 升级费 → 停止造农民、转入攒钱、够了就升 | `gold + 3×收入 ≥ upgradeCost(时代最高的那座保留城)`；攒够当回合 `UPGRADE` | "规则 ③" |
| ④ 任一保留城 4 格内出现敌军 → 造当前时代**低移速高战力**单位兑子防守 | `move ≤ 2` 的战斗单位里挑 `punch()` 最大；造不出就退一步造买得起的最强陆军；已有部队缩到城 3 格内 | "规则 ④" / `VISION = 4` |
| ⑤ 进入第 4 代后集中造**高价格**当前时代单位，发起强攻 | `era ≥ 4`：先造"当代、最贵"的陆军；买不起就退一步造买得起的最强陆军（**不回退去种田**）；全军朝血最少的敌城压 | "规则 ⑤" / `PUSH_ERA = 4` |

`punch()` = 攻击 × √血量 × 射程系数——就是"看面板估强弱"，不含任何换子计算。

## 三、对局设置（口径写清楚）

| 项 | 取值 |
|---|---|
| 脚本侧 | `scripts/script-hold.ts`（`--policy hold`），**不含任何评分或搜索** |
| AI 侧 | **当前** `src/core/ai.ts`（`--vs-new`），不是冻结副本 |
| AI 难度 | `高级 advanced`（游戏默认档）与 `中级 tactic`（战术层全开、最强档） |
| 地图 | 20×20，随机图，扩展 = 正式配置（血战 + 先后手补偿） |
| 起始时代 | 火器局 era3（主）/ 青铜局 era1（看"前期攒钱"这段真跑起来是什么样） |
| 局数 | 每格 **30 颗种子 × 2 = 60 局**（同一颗种子两边各执一次先手，抵消先手与地图不对称），三格共 **180 局** |
| 回合上限 | 160 |
| 胜负判定 | 游戏自身的 `checkWinner`：**一方城市全失**，或**一个兵都没有且连最便宜的兵都造不起**判负；两人局只剩一方即结束。160 回合仍未分出 → 记**未决**，按半分计入"计分胜率" |

运行命令（可原样重放）：

```bash
node --experimental-strip-types scripts/ai-duel.ts --era 3 --games 30 \
  --policy hold --level advanced --vs-new
node --experimental-strip-types scripts/ai-duel.ts --era 3 --games 30 \
  --policy hold --level tactic --vs-new
node --experimental-strip-types scripts/ai-duel.ts --era 1 --games 30 \
  --policy hold --level advanced --vs-new
```

## 四、它到底怎么输的

### 火器局：规则 ③ 在第 1 回合就触发，前期直接没了

开局 600 金（`startGoldFor(3) = 120 + 2×240`），火器升蒸汽要 540。
规则 ③ 的判据是"3 回合内买得起"，第 1 回合就成立 → **开局立刻把家底换成一代科技**：

```
t  1 攒钱升城 金713 兵5战+2经   城 3/3
t  3 总攻   金132 兵6战+2经     城 3/4   ← 540 金已经花掉
t  9 总攻   金133 兵8战         敌10
t 11 总攻   金71  兵9战         敌11    城只剩一座（放弃城被推平）
t 31 …      金88  兵5战         敌21
```

也就是说：**"前期铺经济"这一段在默认开局经济下根本不存在**，
实际执行的是"第 3 回合开始用 6 个兵总攻 4 代 AI"。
而 4 代主力（蒸汽重装备）动辄 300~500 金，它连买都买不起——
买到的那个"时代"没有换成任何一个能打的单位。

### 青铜局：前期真跑起来了，但"不造兵"才是致命的

era1 开局 120 金、升代只要 220，规则 ② 有十几个回合的空间：

```
t  1 攒钱升城 金211 兵5战+2经   敌7
t  5 攒钱升城 金136 兵6战       城 1/2   ← 升了第一代
t 11 铺经济   金121 兵8战+2经   敌14
t 13 铺经济   金71  兵6战+3经   敌15
t 17 铺经济   金93  兵8战+3经   敌16    放弃城已丢
t 27 铺经济   金42  兵6战+1经   敌19    经济单位被打光，收入 70→27
```

关键一行是 t11–t13：**我方 8~9 个兵 vs 敌方 14~15 个**。
AI 每回合稳定出 2 个兵，而这套打法在"不生产军事单位"的规则下**整段对局都在攒农民**。
规则 ④ 的防守兵要等敌军进到保留城 4 格内才造——那时候差距已经是 6 个兵，
补两个也追不回来。这是"按规则执行"的必然结果，不是实现写错了。

### 三条根因（按贡献排序）

1. **"前期不造兵"对上"对面每回合造两个"= 让出 10~15 个单位的产能差。**
   这套打法的前提是"对面也慢"。AI 不慢。
2. **升级时机没有"预备队"概念。** 规则 ③ 只说"买得起就升"，没说"升完还剩几个兵"。
   火器局把 540/600 金花在升级上，等于开局自杀——同一笔钱在对面手里是 4 个兵。
3. **放弃城的收益没兑现。** 放弃一座城省下的防守兵力，被"不造兵"这条抵消了；
   丢城带来的收入损失（每城约 40 金/回合）却是实打实的。

## 五、只改三处就能把它救活（都没写进规则里）

这三条不是"更聪明的算法"，是把规则漏掉的常识补上，**任一都可以单独测**：

1. **升级前留一支预备队**：`gold ≥ 升级费 + 两个当兵的价钱` 才升。
   火器局第 1 回合就不会触发（713 < 540+260 左右），前期才能真的存在。
2. **第 5 回合起保持最低产能**：不管在哪个阶段，每回合至少出 1 个战斗单位，
   经济单位只在"兵力 ≥ 对面 80%"时才继续铺。直接堵住根因 1。
3. **总攻要有兵力门槛**：`我方战斗单位 ≥ 对面 × 0.9` 才转进攻，
   否则继续在城下攒——这条正是那条"六条常识脚本"里也没有、而人类一定会做的事。

第 3 条尤其值得测：它等价于问"**同样的打法，只把'什么时候该打'补上，能值多少胜率**"。

## 六、和之前几个数放在一起

| 打法 / 改动 | 结果 |
|---|---|
| 六条常识脚本（`script-ai.ts`）vs 当前 AI | 45.0%（60 局） |
| 五条"改进"（对上一版） | 46.0%（200 局） |
| **弃城发育流（本页）** | **8.3% / 9.2% / 22.5%** |
| 白送一个时代（时代让子） | +27.5 点 |
| 决策层：初级→高级 / 高级→中级 | +19.2 / +0 |

两个极端的对照很有信息量：

- **一条粗糙但"一直在打仗"的脚本能打平**（45%）；
- **一条精细但"前期不打仗"的打法被打崩**（8%）。

差别不在算术，也不在"抢不抢时代"，而在**有没有在打仗**。
这也回过头解释了"白送一个时代 = +27.5"为什么不能直接套用：
让子是**白送**的，本页是**用全副家底买**的——同样一代科技，前者是纯赚，后者是自杀。
**时代的价值取决于你用什么价码换它，以及换完还剩多少兵。**
