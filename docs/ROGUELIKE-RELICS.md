# 肉鸽「藏品」与「增益」系统设计 v0.2

> 目的：给 `ROGUELIKE-STRATEGIES.md` 补一层「局内成长」，同时解决三件事——断档、老兵没感情、每局差异不够。
> v0.2 改动：**取消军饷 → 藏品成为金币主出口**；**加入负面藏品**；**类别扩到 10 类，其中「规则类」是主力**。
> 本文只做设计，不改代码。数据取自 `src/core/ability-registry.ts`（90 条技能）与 `src/core/config.ts`。

---

## 1. 先定分工：方略 / 藏品 / 增益 各管什么

| 系统 | 回答的问题 | 时间尺度 | 数量 | 玩家能否改 |
|---|---|---|---|---|
| **方略** | 我从哪来？（身份） | 整局固定 | 1 | 开局选，之后不改 |
| **藏品** | 这一局发生了什么？（故事） | 整局累积 | 6–10 件 | 靠运气 + 抉择 |
| **增益（词条）** | 这支部队经历了什么？（感情） | 挂在具体单位上 | 每单位 ≤3 条 | 靠战斗奖励 + 事件 |

一句话：**方略决定你的打法，藏品决定你的路线，词条决定你舍不得谁死。**

## 2. 增益（词条）系统

### 2.1 最大的便宜：90 条技能已经写好了

`ability-registry.ts` 里有 **90 条**技能，其中至少 50 条是「挂在单位身上就成立」的通用词条。不需要新写任何效果，只要允许把它们当奖励发出去：

| 档位 | 词条（直接引用现有 ability id） |
|---|---|
| **普通 T1** | 破甲 `armor-pierce`、先手 `first-strike`、盾墙 `shield-wall`、潜行 `stealth`、冲锋 `charge`、淬毒 `poison-hit`、燃焰 `burn-hit`、霜缚 `slow-hit`、击退 `knockback`、穿林 `forest-walk` |
| **稀有 T2** | 吸血 `lifesteal`、再生 `regenerate`、狂暴 `berserk`、分裂 `split`、真元 `qi-true-damage`、剑气环 `artifact-sword-qi`、威吓 `fear`、隐匿 `vanish`、对空 `anti-air`、收割 `kill-rush` |
| **传说 T3** | 重生 `rebirth`、灵体道果 `spirit-ascension`、王命 `royal-decree`、金刚不坏 `body-ward`、强再生 `regenerate-plus` |

> 注意：有一批是舰船/空军专属（`nv-*`、`af-*`），那批不进通用池，只作为对应分支的专属词条出现。

### 2.2 三条规则

1. **每个单位 3 个词条槽**，满了只能替换，不能叠加（避免无限叠「破甲」）。
2. **词条跟随单位跨层、跨升格**（§4.4 会讲为什么这条最关键）。
3. **同名词条不叠**，但可以有「强化版」（普通破甲 → 无视 2 甲，占 1 槽，稀有度升一档）。

### 2.3 词条从哪来

| 来源 | 频率 | 形式 |
|---|---|---|
| 战后三选一 | 每场 | 兵 / 词条 / 补给，三选一 |
| 休整节点 | 每层 1 次 | 三选一，词条权重更高 |
| 事件 | 「增益」类抉择 | 直接给 1–2 条 |
| 藏品 | 少数藏品给「全队 +1 槽」 | 稀有 |

**战后三选一**的结构（这就是 StS 的 card reward，但换成了「人」）：

| 选项 | 内容 | 对应打法 |
|---|---|---|
| 兵 | 本层卡池随机 1 个（按母池权重） | 走「宽」——人多 |
| 词条 | 随机 1 条 T1/T2，挂给任意单位 | 走「深」——精兵 |
| 补给 | 治疗 1 个单位 50% / +1 编制 / 50 金 | 走「稳」——续命 |

### 2.4 为什么词条能让「老兵」有感情

没有词条时，兵是消耗品：死了买新的，数值一样。
有词条后，一个挂了「盾墙 + 淬毒 + 再生」的民兵，你舍不得拿它去堵枪眼——因为**词条是沉没成本**。

## 3. 藏品系统

### 3.1 四条设计原则

1. **藏品要能改规则，不能只是 +10% 数值。** 一件好藏品应该让玩家换一种打法（「空城计」直接让你没有城）。
2. **一局 6–10 件，同类最多 2 件。** 防止经济类滚雪球。
3. **传说全局最多 1 件。** 传说是「这一局的记忆点」，不能变成标配。
4. **负面藏品必须存在，而且要有分量。** 没有代价的选择不是选择——这是收藏品的另一半。

### 3.2 十个类别

前三类是老派的「数值」，中间五类是「改规则」，最后一类是「代价」。

| 类别 | 管什么 | 强度上限 | 例子 |
|---|---|---|---|
| 经济 economy | 金、商店、价格 | 低 | 钱庄、黑市 |
| 编制 roster | 队伍上限、预备队 | 低 | 预备役名册 |
| 战斗 combat | 伤害、恢复、先手 | 低–中 | 战地医院、号角 |
| **时代 era** | 跨时代招募、改装、升格 | **高** | 时代残响、报废图纸 |
| 方略 strategy | 强化方略被动 / 进阶 | 中 | 铁砧之心、残页 |
| 叙事 narrative | 结局、事件可见性 | 中 | 黑匣 |
| **规则 rule** | 招募 / 编制 / 胜负 / 回合的底层规则 | **极高** | 双主、单色、空城计 |
| **地形 terrain** | 地图生成 | 中 | 水乡、隘口、焦土 |
| **敌人 enemy** | 敌方 AI、预算、构成 | 高 | 叛旗、傀儡线 |
| **诅咒 curse** | 纯负面，占格且不可弃 | — | 铁链、血税 |

> 「规则类」是这套系统的重心。**常规对局的平衡在肉鸽里不是第一优先级**——肉鸽的乐趣来自「这一局和上一局规则不一样」。所以规则类藏品应该大胆，宁可事后削弱，也不要一开始就做成 +5% 移速。

| # | 名称 | 效果 | 代价 |
|---|---|---|---|
| 1 | **双主** | 可带 2 个方略，两边被动都生效 | 两条进阶线的成本各 +1 |
| 2 | **单色** | 只能带 1 个分支的兵 | 该分支编制 +2、造价 −40%（是收益也是枷锁） |
| 3 | **空城计** | 你没有城 | 全军 +25% 攻 / +1 移；胜负改为「敌方城全丢」 |
| 4 | **死斗** | 不能撤退 | 每场战斗后必掉 1 件藏品 |
| 5 | **逆流** | 每场战斗敌方先手 | 我方每回合 +1 行动点 |
| 6 | **引力井** | 全场移速 −1（含敌人） | 我方飞行单位免疫 |
| 7 | **借兵** | 每场战斗开始，从敌方池「借」1 个单位 | 战后归还；若它死了，算你的损失 |
| 8 | **无主之地** | 地图上所有中立城开局归你 | 敌方预算 +20% |
| 9 | **时代残响** | 招募池永远含全部 8 个时代 | 超时代单位以「试验型」（−30%）入场；价格 ×1.6 |
| 10 | **同代** | 全场单位强制压到本层时代（含敌人） | 你的高代兵变弱，但敌人也变弱——专治「代差碾压」 |
| 11 | **双倍回合** | 每场战斗回合上限 ×2 | 敌方预算 ×1.3（你能磨，敌人也能磨） |
| 12 | **兵不厌诈** | 战斗开始时可重排敌方 1 个单位的初始位置 | 每场限 1 次；被发现则敌方全体 +10% 攻 |
| 13 | **以战养战** | 击杀获得的金钱 ×2 | 事件与商店的金币收益归零 |
| 14 | **割据** | 每层可跳过 1 个节点 | 跳过的节点奖励归零，且下一层敌方 +10% |
| 15 | **群雄** | 所有会战多 1 个势力（3→4，4→5） | 多出的势力也打别人，但会战奖励 +60% |
| 16 | **短兵相接** | 所有战场缩小 30%，回合上限 −3 | 远程单位射程 −2 |

第 16 条是「反向地形」：它让「齐射」「炮兵」方略当场变弱，但「尖刀」「奔袭」变强。这是肉鸽该有的东西——**一件藏品能让你的方略从强变弱**。

| # | 名称 | 效果 | 代价 |
|---|---|---|---|

### 3.6 负面藏品：三种形态

负面藏品不是「偶尔来一个」，是**抉择的定价工具**。三种形态，用途不同：

| 形态 | 怎么得到 | 能否移除 | 设计用途 |
|---|---|---|---|
| **诅咒（curse）** | 只作为代价被塞给你 | 不可弃；可花 200 金 + 1 个兵「净化」 | 让「强收益」有价格 |
| **契约（pact）** | 事件里主动签 | 完成条件可解除 | 让玩家自己赌 |
| **罚金（debt）** | 事件里「选 A 就必须收下 B」 | 3 层后自动消失 | 让抉择当场疼 |

#### 诅咒（8 件，纯负面 + 一点补偿）

| # | 名称 | 负面 | 补偿 |
|---|---|---|---|
| 28 | **铁链** | 全军移速 −1 | 每场战斗开始获得 1 条免费词条 |
| 29 | **血税** | 每场战后随机 1 个单位 −30% 血 | 藏品掉落率 +50% |
| 30 | **独眼** | 视野 −2 | 敌方对你伤害 −10%（看不见也打不准） |
| 31 | **兵变** | 每层开始 10% 概率 1 个单位叛变 | 全军造价 −20% |
| 32 | **空粮** | 每场战斗超过第 4 回合，全军每回合 −2 血 | 开局金币 +300 |
| 33 | **失语** | 事件里少 1 个选项（永远只剩 1 个可选） | 事件奖励 ×1.5 |
| 34 | **重税** | 商店价格 +50% | 每层结束返还 30% 已花金币 |
| 35 | **孤军** | 会战里没有盟友势力（永远 2 势力对打） | 会战奖励 +40% |

「失语」是最狠的一条：它砍的不是数值，是**玩家的选择权**。适合作为「贪了传说藏品」的代价。

### 3.8 强度预算

| 稀有度 | 大致等价 | 一局期望 | 价格（可购买时） |
|---|---|---|---|
| 普通 | 0.5 条进阶 | 4–5 | 120–180 |
| 稀有 | 1 条进阶 | 2–3 | 260–380 |
| 传说 | 1.5 条进阶 | 0–1 | 不可买（只 Boss/剧情） |
| **诅咒** | −1 条进阶 | 0–2 | **−**（只能被塞） |

合计约 **4–5 条进阶**（方略满级 6 点）。但**规则类藏品不参与这个预算**——「双主」的价值无法用「条进阶」衡量，它换的是整个 build 的形状。所以规则类靠「同类最多 1 件 + 全局最多 3 件规则类」来限，不靠数值预算。

### 3.9 掉落与购买

| 来源 | 掉落 |
|---|---|
| Boss（会战） | 必掉 1 件稀有；L4 掉传说 |
| 精英 | 35% 掉 1 件普通 |
| 事件 | 抉择里可「用 2 个兵换 1 件藏品」 |
| **商店（藏品位）** | **每层 1 件，普通/稀有随机，可买** |
| **商店（消耗位）** | 可重复购买：补给箱 120 / 兵符 180 / 词条卷轴 150 |
| **净化** | 花 200 金 + 1 个兵，移除 1 件诅咒 |

**「部分藏品可以购买」的具体口径**：

- 普通、稀有 → **全部可买**，价格按层 ×1.0 / ×1.3 / ×1.7 / ×2.2。
- 传说 → **不可买**（只能 Boss 或剧情拿），但 L4 商店开 1 个「传说位」，价格 900。
- 诅咒 → **不能买**，但可以**花钱净化**（这是它的出口）。
- 规则类 → **只在商店出现，不进 Boss 掉落**。因为规则类需要玩家「看懂再决定」，塞给玩家会懵。

这条设计直接替代了被取消的军饷：**金币的主要出口是「买一件能改规则的藏品」**，而不是「养一堆不能上场的兵」。

## 4. 藏品/词条怎么解决「断档」

断档的本质是：**你在第 3 层想买本分支的兵，货架上没有。**

### 4.1 硬保底：改装条目进商店
断档层的母池里至少出现 **1 个改装条目**（引用现有单位，改名，保留方略被动），价格 = 新单位造价 × 1.0。不是白送，是「你有钱就能解决」。

### 4.2 主动解：两件藏品
- **报废图纸**（普通）：每层免费改装 1 次。拿到它，断档层完全不慌。
- **时代残响**（传说）：招募池永远含全时代，超时代单位以试验型（−30%）入场。

### 4.3 一次性解：整建制换装
剧情/抉择事件：把全队换成同职能的下一层单位，代价是「失去 30% 金币 + 随机 1 个单位」。

### 4.4 词条与升格的交互（这条最重要）

第 4 层升格时，**词条全部保留**。所以：

- 你在第 1 层给民兵挂的「盾墙」，到第 4 层还在一台 429 血的「塔」身上。
- 这让「早期投资」在后期兑现——肉鸽最爽的时刻之一。

**因此顺序上要先做词条，再做升格。**

## 5. 与方略的接口

| 接口 | 做法 |
|---|---|
| 方略专属藏品 | 10 个方略各 1 件（如「铁砧之心」），只在该方略的掉落池里出现 |
| 藏品改方略 | 「残页」降进阶成本；「门徒」加方略兵；「双主」允许两个方略 |
| 方略改藏品 | 拾荒方略的「图纸」可以提前解锁藏品 |
| 冲突处理 | 方略被动与藏品同名效果时，**取高不叠加** |
| **负面藏与方略** | 「单色」会锁掉通用编制，对「齐射」这类需要前排的方略是硬伤——这是刻意的，让玩家权衡 |

## 6. 数据形状

```ts
interface RelicDef {
  id: string;
  name: string;
  rarity: 'common' | 'rare' | 'legendary' | 'curse';
  category: 'economy' | 'roster' | 'combat' | 'era' | 'strategy'
          | 'narrative' | 'rule' | 'terrain' | 'enemy' | 'curse';
  desc: string;
  hooks: Partial<Record<
    'onLayerStart' | 'onBattleStart' | 'onBattleEnd' | 'onShopStock'
    | 'onRecruitPool' | 'onAscend' | 'onMapGen' | 'onEnemySpawn' | 'onRuleCheck',
    unknown
  >>;
  cost?: number;                 // 商店价；诅咒为 0（不可买）
  removable?: { gold: number; units: number } | false;  // 净化代价
  strategyOnly?: string;
  maxPerRun?: number;
}

interface UnitBuff {
  unitId: string;          // 单位个体 id（不是兵种 id）
  abilityId: string;       // 直接引用 90 条技能里的一条
  tier: 1 | 2 | 3;
  from: 'battle' | 'rest' | 'event' | 'relic';
}

interface UnitInstance {   // 这是新东西：单位个体
  uid: string;
  typeId: string;          // 兵种
  nickname?: string;       // 「民兵 #3」
  buffs: UnitBuff[];       // ≤3（升格协议可到 4）
  kills: number;
  hp: number;              // 跨战斗保留
}
```

**`UnitInstance` 是整个方案的地基**：现在游戏里单位是「兵种 + 坐标」，没有「个体」。肉鸽需要个体——挂词条、跨层带伤、升格保留身份，三件事都要它。
