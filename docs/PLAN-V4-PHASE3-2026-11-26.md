## 0. 一句话

**阶段二修的是"钱往哪投"，阶段三修的是"兵怎么一路一路送上去"。**

主语要换：v4 现在的主语是"**一支要活下来的队伍**"，人的主语是"**一条能反复用的通道**"。
主力部队是消耗品——沿一条线一波一波送上去；一条线受阻就减每波兵力、把钱转产能，
直到产能撑得起两条线。所以本阶段的核心不是"某一处投送不好"，是**v4 心里没有"线"和"波"这两个对象**。

三件已经量出来的事（都在 `S-000 / S-001 / S-002` 上，**S 系列只作参考**）：

| 观察 | 数 | 含义 |
|---|---|---|

| 展开程度 | S-000 到 7/10；S-002 到 **6/25** | **送进去的规模 ≠ 能展开的规模** |
| 交换账 | S-001 赚 720 / **亏 720**；S-002 赚 1000 / **亏 2600** | **送到了也换不到东西** |
| 产能 | `make` 几乎恒为 0 | 现在只维持得起一条线 |

**结论**：主要矛盾**不是**"窄道慢"，是"**派得多、展不开、换不到**"。
这条直接决定了 W2 该先换判据（看交换），而不是先修路况（W4）。

## 3. 阶段三的四步

判据全文在 `DESIGN-LANES-WAVES`，这里只记"做什么、怎么算过、会踩什么"。

### W1 ✅ 影子模式（2026-11-26 10:20 完成）

- **做了什么**：服务层 `laneStats / contacts` 给 `front`（能打到城）/ `engaged`（已接火）/
  `road`（在途）/ `make`（这回合能造几个）；记忆里记**交换账**（按造价、6 手窗口）、
  **波次**（出发 → 首次交战）、**到货**（按人去重，含 `stuck` 连续堵）。
- **验收**：34 题**逐字节零变化**；日志与回放对得上。
- **没做的**：一个判断都没接，`lanes` 还不存在（现在只有"主队"这一条隐式的线）。

### W2 换攻守判据（**下一步**，会翻一批读数）

- **做什么**：`decide.ts` 里"我 > 敌×1.25 才推 / 跌破 1.0 就退"换成**金币交换账**：
  `Σ击杀敌方造价 ≥ Σ我方被击杀造价` → 赚，可以继续/加码；否则亏 → 降预算 / 换线。
  6 手窗口滚动，**允许短期小亏**；窗口里没有交换时**看城血**，一点没掉判「卡住」
  （用户 2026-11-26 确认：卡住 = 此路难通，降预算、准备换线）。
- **验收**：先把 W1 的数据再跑一批（至少 `S-000/001/002/012` + 两道 E/P），
  再换判据；换完**逐题归因**（照 D4b 的格式：哪道题、哪条账、为什么变）。
- **风险**：这是本阶段第一次改行为，几乎肯定会翻红一批 S 题。**不迁就题目**，
  但"大批红 + 归因不清"就停下补数据。
- **前置**：`S-002` 是否要解冻？它现在冻结着，但它是"交换账长期亏"最典型的样本。

### W3 线数与预算（**新行为**，含原 P5）

- **做什么**：决定层输出从"打哪座城"变成"**开几条线、每条多少人**"：
  `lines: [{ targetCityId, men, stance: 'push' | 'hold' | 'build' }]`。
  `men` 由"每波成本 × 产能 × 期限"推出来，**不再是"守军身价 ÷ 我方身价 ×1.5"**。
  一条线受阻（`stuck` / 交换亏）→ `men` 减半、钱转产能；产能恢复到"一波的成本"以上 → 开第二条线。
- **验收**：`P-2-01` 重写成**两波题**（一波打光后有没有第二波上路）；
  底图 `E-2-04`（24×24、`seed 18`、城距 46 步），判据数人次、**不看 `win`**。
- **风险**：这是 v4 最大的一次模型改动（决定层的输出形状变了）。
  `want` 那条"12 手不缩"的记忆要一起改（资产口径 → 波次口径）。

### W4 路况（含原 P4 剩余 + P7）

- **做什么**：人挤人、窄道排队、架桥——把它们当作"**线的通行能力**"来修。
  现有状态：人挤人症状已缓解（落点去重 + 移动力大的先走）但**没有度量**；
  窄道一人一格能过但不知道要几手；`grep BUILD` 为空，架桥完全没有。
- **验收**：以"**单位时间通过量**"为口径（W1 已有这个数：终点到货率 + `stuck`）。
- **风险**：架桥一旦给工兵和钱，考点会滑到"该不该花这笔钱"（E 轨采购）——
  所以 W4 放在最后，且题面要是"有没有比架桥更便宜的路"。

## 4. 验收纪律（本阶段全程）

1. **一次只动一处**。搬位置/加观测：34 题**逐字节**一致（`exam-grade` 的完整 stdout，`diff -rq`），
   不是只看红绿。
2. **换判据必须逐题归因**：哪道题、变了什么、为什么。归因不清就停下，不许靠调窗口凑红绿。
3. **四颗种子同结论**才算立住。
4. **判据必须能数**，不许打分。
5. 全量：`npm run exams:all -- --diff`；单题：
   `node --experimental-strip-types scripts/exam-grade.ts --exam exams/X --me-ai v4 --foe-ai auto`
   （`--foe-ai auto` 不能省）。
6. 每步单独提交。

## 6. 本阶段不做（越界就停）

- **经济**：造经济兵、占岗、收入、发展期投影——全部回阶段二，本阶段只读 `make` 一个数。
- **采购细分**：2d（`E_hard` 破平局）、编成配方——没有混编题，不做。
- **平衡数值**：等内容补齐后统一调。
- **给"线"存路径**：只存通行能力（步数、宽度、能不能被切断），路线每手现算。
- **用推进格数当收益**：会被地形骗（绕路也是推进）；收益只认金币与城血。
