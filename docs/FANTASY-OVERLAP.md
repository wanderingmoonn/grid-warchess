# 奇想兵种：同代同位挤占对照表

> 由 `npm run fantasy:overlap` 生成（`scripts/fantasy-overlap.ts`），数字不手抄。
> 表里有两类数：**数值**来自当前代码（`unit-value.ts` 现算）；**出场 / 战斗**来自
> 400 局双 AI 跑批（`results/bf-modern*`，200 局火药开局 + 200 局信息化开局，20×20）。
>
> **这两类数的时点不同，读的时候要分开**：数值是现算的（含 2026-11-07 那批改动：
> 蝙蝠下放一代、女巫降到二代、超级重骑 +1 甲 +5 血、牛头人 −10 金、修缮 6→10），
> 而建造数和交换比来自 11-02/11-03 那几批跑批，**跑的是改动前的数值**。
> 所以"被挤掉"这一列的判定只对改动前成立；要看改动后的出场，得等新一批跑批。

## 口径

```
战力    = (输出 × 生存)^0.55 × 射程 × 移速 × 视野 × (1 + 能力)，均势姿态（tempo = 0）
性价比新 = 战力 / 价格^0.55          ← 报表 / 审计口径（unit-value.ts）
性价比旧 = 攻×√血×射程 / 价格^0.8     ← **AI 采购默认用的这一把**（ai.ts 的 oldEfficiency）
建造    = 这一兵种在 400 局里被招募/建造的总次数（不含召唤、分裂、孵化）
交换比  = 累计输出伤害 / 累计承受伤害。> 1 说明它换血换得赚
```

**两把尺子要分清**：AI 买不买看的是"性价比旧"，它完全不看移速、视野、能力；
"性价比新"只在报表里出现。表里两列都给，就是为了不让读者拿错那一列去解释出场数。

一个**坑位**的划法：同代 + 同职能 + 价格相差不到一档（≤1.6×）。
同代不同价、或者同价不同职能，都不算互相挤占——那些是"有钱了升级"，不是"二选一"。

## 二、逐组明细

列说明：攻/魔 = 物理攻击 / 魔法攻击；甲/抗 = 护甲 / 魔法抗性；移/射/视 = 移动力 / 射程 / 视野；
建造 = `火药批/信息化批` 的建造次数（两批各 200 局，合计 400），括号里是每局几个；
解锁 = 英雄首次招募的额外解锁费（一次性）。**两批的数字要分开看**：
像皇家骑兵只在火药批出现（62/0，信息化开局直接跳过二代兵），
圣剑勇者只在信息化批出现（23/421，火药开局的局大多打不到信息化）。

## 五、这张表能指认坑位，不能指认病因

先把两把尺子分清，否则下面的数会被读错：

- **性价比（新）** = `unit-value.ts`，管线是兰彻斯特 + 移速/视野/能力。报表、审计用它。
- **性价比（旧）** = `攻×√血×射程 / 价^0.8`，**AI 采购默认用的就是这一把**（`WB_RULER` 未设成 `new`）。
  它完全不看移速、视野、能力，价格指数还更陡（0.8 对 0.55）。

所以"新尺子说它值、它却零出场"不是矛盾——AI 根本没看那一列。

### 旧尺子能解释的

**1. 同价之内，排序就是结论。** G14 是最干净的样本：狼人和吸血鬼都 235 金，
旧尺子 2.33 对 2.66，出场 8 对 648。同价、同代、同职能，比的只剩这一项。

**2. 又贵、旧尺子又低 → 0 次。** G3 的精英骑兵（2.13，全组最低）、
G9 的龙骑兵（2.28，全组最低）都是"最贵 + 分数垫底"，两条同时踩中。
这两个是整张表里最没有疑问的零出场。

### 旧尺子解释不了的（三个反例，别硬套）

| 反例 | 数据 | 为什么解释不了 |
|---|---|---|
| 精灵弓手 | 旧尺子 5.42，**全组最高**；射 5、视 7；400 局只出场 2 次 | 无论哪把尺子它都该被抢，实际几乎没人买。这一条单纯用"值不值"讲不通 |
| 狼骑士 vs 剑士 | 2.44 对 2.96，剑士更高；出场 838 对 89 | 同代、同职能、剑士又更便宜又更高分，却少一个量级 |
| 蜘蛛骑士 vs 剑士 | 2.59 对 2.96，剑士更高也更便宜；出场 167 对 89 | 同上，方向反了 |

三条反例指向同一个缺口：**采购分不是唯一的决定项**。`ai.ts` 里还有兵种搭配、
远程占比、经济节奏、换血（`swapOut`）这些项会改写排序，而它们不在任何一张表里。

**所以：这张表用来找"哪些兵在同一个坑里互相顶"，够用；用来给某次改价找依据，不够。**
真要定位某个兵为什么 0 次，得在"买得起的那一刻"把全候选的分数和 deny 原因打出来，
看它到底输给了谁。在那之前改价，只是把受害者换一个。

### 一件不用等的事

G10 那九个三代远程，互相之间的差异小到没有意义（旧尺子 2.31~5.42 主要差在射程，
而射程在这一档全是 3）。这一档缺的不是第九个射 3，是"射 5 以上"的差异位——
精灵弓手本来是那个位，但它 0~2 次出场，说明这个位现在等于不存在。
