# v0.3.26：开局只有一个门口

一句话：**「新对局」改名为「首页」，点它回门面；开局这件事只剩首页一个入口。**

## 为什么改

上一版把开始页面做出来了，但只做了一半——顶栏还留着「新对局」，一点就直接换一局，
**跳过门面**。于是同一个动作有了两条路：

- 从首页「开始对局」进去：有完整的面板（时代、尺寸、扩展、人数、选卡）；
- 从顶栏「新对局」进去：也弹面板，但它是"打完一局之后顺手再开一局"的心态，
  门面从此再也见不到。

两条路的差别不在功能，在**发现**：新玩家永远学不会"首页是个地方"，只会觉得它是个一次性弹窗。

现在规矩很简单：

- 顶栏那颗按钮叫「首页」，点它**回门面**，不换局；
- 想开新局：首页 → 「开始对局」；
- 想接着打：首页 → 「继续上一局」（原地撤掉这一层，棋盘本来就在下面）。

## 顺手做的三件事

**1. 兵种编辑器、导入对局搬到了首页。**

这两个从来就不是"在对局里做的事"：编辑兵种是先改配置再开局，导入是换一局。
把它们夹在一排对局操作（导出、反馈、规则书）中间，看着像同一类东西。
现在它们在首页的链接行里：`联机对战 · 规则手册 · 兵种编辑器 · 导入对局`。

细节：点「兵种编辑器」**不会撤掉首页**——编辑器是模态框，盖在门面上，改完关掉还站在原地，
可以接着改、也可以直接开局。第一版是先撤层再开编辑器，改完一个数值就落在已经开局的棋盘上，
想再改一次得从头摸回入口。导入则和开始/继续同级，撤层进入那一局。

**2. 回首页会自动暂停 AI。**

棋盘还在下面（「继续上一局」能瞬开全靠这个）。如果这局正轮到 AI，
它会在没人看的时候自己往下走——玩家盯着门面，回来发现丢了两个城。
点「继续上一局」时它会自己重新跑起来。

启动时**不**暂停：开机本来就没有循环在跑，而存档可能正停在 AI 的回合上，
那里暂停等于把一局活棋冻住。

**3. 「继续上一局」只认真的打过的一局。**

启动流程末尾会无条件存一次档（新建的这局当场落盘）。如果「继续」直接看"有没有存档"，
第一次来的人会看到一个亮着的按钮，点下去接着打的是一张谁都没动过的随机棋盘。
现在开机那一刻先量一次（那时自动存档还没发生），之后开一局、导入一局、进房间接手一局才置位。

## 顺带修掉的两处

- **缩放条从首页底下透出来**：右下角「适应 − ＋」是固定定位、层级 60，而首页是 40。
  首页 z-index 提到 80——不能图省事写 999，那会把开局面板（100）和结算卡一起压掉。
- **「最近更新」那一行断在分割点上**：四个入口 + 一句更新说明挤在一行，窄屏换行后行尾
  孤零零留一个「·」。改成更新说明单独一行。

## 怎么验

1. 打开链接 → 首页；第一次来「继续上一局」是灰的。
2. 点「开始对局」→ 配置面板 → 开局。
3. 打两步，点顶栏「首页」→ 回到门面，「继续上一局」此时是亮的；点它，回到刚才那一步。
4. 首页点「兵种编辑器」→ 编辑器盖在门面上；关掉它，首页还在。
5. `?home=1` 可以强制出首页；带 `?room=CODE` 的邀请链接直接进房间，不挡路。

## 用例

界面 172 项全绿。新增两条守门口语义：第一次来「继续」是灰的、打过一局之后它是亮的
（并且点它不会换图）。「选卡退出」那条按新行为改写：退出选卡回首页，想重开再走一遍「开始对局」。
