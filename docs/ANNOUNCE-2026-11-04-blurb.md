# v0.3.29：面板说一句话，细则回规则书

一句话：**开局面板上每条扩展只剩一句短说明**；原来那条一百多字的介绍，回规则书里待着。

## 现象

开局面板「扩展规则」那一栏，每条都是 `<名字> + 一整段`。二十几条挤在一屏里，
其中最长的几条是这样的：

- **时代军备** 274 字，把六代兵种名一口气列完（"青铜的投石兵/战车/攻城槌/旌旗车，
  铁器的瑞士长矛兵/重装军士/战象/弩炮/攻城塔……"）；
- **海军** 248 字，二十条船名；
- **空军** 203 字，十八种飞机；
- **地形高差 / 行动点 / 高机动性** 各一百四十多字，还带着数值公式和例外条款。

玩家在这一屏要做的事只有一件：**勾不勾**。要读完四百字才知道这一条干什么，
等于把"选择"变成了"阅读"。细则本来就该在规则书里——那里每册都有专章，
合册开头还有一张按包的总表。

## 改法

给 `Expansion` 加了一个字段 `blurb`：**给面板的一句话**（一行以内、不列名单、
不带括号补充）。`summary` 原封不动，继续给规则书用（合册总表和单册导语）。

面板改成渲染 `blurb ?? summary`——没写 blurb 的退回 summary，免得将来新加的包在面板上空白。

二十三条现在长这样：

| 包 | 面板上那一行 |
|---|---|
| 战争经济 | 击杀敌人当场拿赏金。 |
| 老兵不死 | 老兵越打越强，回城能补血。 |
| 浓雾蔽野 | 连地图也遮住，走过才记得。 |
| 时代军备 | 每一代都多一批可选兵种。 |
| 奇想 | 魔法、荒兽与英雄，一整套奇幻军备。 |
| 海军 | 从桨帆船到航母，加水雷与海权规则。 |
| 空军 | 从侦察气球到喷气机，能上航母甲板。 |
| 高机动性 | 移动、射程、视野全部 ×1.5。 |

最长的一条 17 个字，全表见 `expansions.ts` 及各 pack 文件里的 `blurb:`。

顺带把同一页里「结束后上传这局的详细数据」那段也压了：原文八行、还混着
Markdown 的 `**`（在网页上会原样显示成星号）。现在三行，只留"记什么、不记什么、
勾一次就记住、发送仍要你点一下"这四件事。

## 守住的

- 规则用例：每个扩展必须有 `blurb`、**≤ 30 字**，且 `summary` 必须比它长
  ——以后想往面板里塞细则，测试会拦下来。
- 界面用例：面板上「海军」那条必须是那句 blurb，且**不许出现 `德罗蒙`**（船名属于规则书）。

## 规则书没动

`summary` 依然是规则书合册总表里那一列，四册的导语也照旧。这次只是把"给谁看"
这件事分开：**面板给判断，规则书给细节**。
