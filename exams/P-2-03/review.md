# P-2-03 评审（2026-11-26）· 自己架桥

> **这是一道诊断题**，不是能力题：它要复现的问题是"**桥能铺出来，但部队不过桥**"。
> 红不代表 v4 不会架桥；它代表架完桥之后那一步断了。

## 一、题是什么

- 18×18，一条 **3 格宽**的河横断全图，**一格桥都没有**（就是 `P-4-01` 把桥拆掉）；
- 我方：6 戟兵 + 6 火枪 + **2 个劳工**（能修木桥，45 金/格）、**900 金**；无收入；
- 敌方：一座 3 代城 + 两座箭塔，**摆在角落 (17,0) / (17,17)**——打不到桥、不压上岸点，
  只用来避免对手"无兵出局"；
- 判据：40 手内把敌城打掉 ≥60 血 + 老家不丢。

和 `P-4-01` 的唯一差别：**那道题有现成的一格桥，这道要自己修**。

## 二、编号

`字母-数字-数字` = **类型-复杂度-序号**。架桥只有两件事（铺出来 + 过去），复杂度 **2**；
序号顺延取奇数（`P-2-01` 是主，`P-2-02` 留给它的"一换"），所以是 **`P-2-03`**。

## 四、v4 回放里能看到什么（塔挪到角落这一版）

回放在 `exams/P-2-03/replay.json`（314 个动作、80 手、40 条编队记录）。

**桥修出来了，而且一直完好**——3 次 `BUILD`，正好是渡口三格：

```
BUILD  bridge @ 8,7
BUILD  bridge @ 9,7
BUILD  bridge @ 10,7
```

到第 40 手，三格桥**全部满血 40/40**（塔在角落，没人打它）。

**但一次都没打**——动作分布：

```
MOVE 224 · END_TURN 80 · BUILD 3 · RECRUIT 7 · ATTACK 0 · SIEGE 0
```

**14 个人 40 手全在 x ≤ 7（西岸）**：戟兵在 (4,4)~(7,8)，火枪在 (4,7)~(7,5)，
工兵停在 (5,8)/(6,7)。东岸一个人都没有。

所以结论是干净的：**桥通着、没被打、钱也够过桥，队伍就是不上去**。
上一版（塔压桥头）还能怪"桥被打塌"，这一版把这理由排掉了。

## 五、怎么复现

```bash
# 跑一局看判据
node --experimental-strip-types scripts/exam-grade.ts --exam exams/P-2-03 --me-ai v4 --foe-ai auto

# 看逐手兵线/编队（工兵那一行是 [build]）
V4_LANE_LOG=1 node --experimental-strip-types scripts/exam-grade.ts --exam exams/P-2-03 --me-ai v4 --foe-ai auto 2>&1 | grep -E '^\[lane\]|^\[band\]|^\[build\]'

# 重新导出回放
node --experimental-strip-types scripts/make-replay.ts --exam P-2-03 --me-ai v4 --window 40 --out exams/P-2-03/replay.json
```

看回放建议抓 **T10~T20（桥刚通那几手）**。这一版没有"桥被打塌 → 重修"的循环，
整个 40 手都是同一个现象，随便看哪一段都一样。
