# D-1-02 评审（2026-11-25）· 守 · 1 一件事

**结论：立住了，而且是守轨第一道「探路题」——只有 v1 / v3 绿，v4 红。**

## 这题是什么

D-1-01 的一换：**只把敌人从东边挪到北边**，其余（3 代城 81 血、4 打 4、无收入、窗口 6、
判据）全部不变。

我方 4 个长枪兵在城北一行；敌方 4 个长枪兵贴在城北的产兵格上，和我方隔一行——
每一对都正好在射程内，是一盘纯粹的兑子。

## 实测（四颗种子）

| 答题者 | 第 6 手城血 | 打死几个 | 结论 |
|---|---|---|---|
| 空壳 | 4（没人挡，被磨到只剩 4） | 0 | ❌ |
| v1 | 25 | 2 | ✅ |
| v3 | 25 | 2 | ✅ |
| **v4** | **4** | **0** | ❌ |

种子 51 / 1 / 2 / 3 完全一致（v1 / v3 / v4 各验三颗）。

## v4 红在哪（这是这道题最有价值的地方）

它不是没打——**每一手四个兵都在攻击**，只是四个敌人被**平均削**：

```
T1 敌兵 30/30/30/30
T3 敌兵 20/20/20/20
T5 敌兵 10/10/10/10      ← 一个都没死
```

v1 / v3 同样的局面，同样 4 打 4，6 手内打死 2 个。

**差别只在"打谁"**：v4 的选靶是「射程内血最少的那个」，四个人站的位置不同，
各自眼里"最少的"不是同一个 → 伤害摊平。兑子里摊平等于没打。

## 更正（2026-11-25 13:50，量了可达目标数之后）

上面那句"差别只在打谁"**站不住**。第 1 手实测（`attackableTargets` + 走一步后的可达目标）：

| 我的兵 | 现在能打几个 | 走一步后能打几个 |
|---|---|---|
| u1 (0,8) | **1 个**（u8） | **0 个** |
| u2 (1,8) | **1 个**（u5） | **0 个** |
| u3 (2,8) | **1 个**（u6） | **0 个** |
| u4 (3,8) | **1 个**（u7） | 1 个（还是 u7） |

也就是说：**这张局面里，第 1 手的集火在物理上不可能**——四个兵各对着一个敌人，
每人只有一个目标，四个敌人被平均削是**几何决定的**，不是选靶选错。
"30/30/30/30 → 20/20/20/20" 是四个 1v1 各掉一发，不是"该集火却摊平"。

那 v1/v3 的 2 杀是怎么来的？**后面几手靠移动**。回放（v1）：

```
T3 u4 走到 (3,9)，和 u3 一起打 u6   ← u7 往南撤了，u4 跟上去换了个目标，两人打同一个
T5 u3 走到 (2,9)（u6 死后的空位）再打 u5
```

所以这题真正区分的是**"敌人挪了之后，我这一手能不能跟着挪到能打的位置"**，
不是"我盯着谁打"。v4 的走位是"照着计划走一格 / 回城"，没有"走一步能多打到谁"这个概念。

**对出题的影响**：要考集火，局面必须满足"至少两个单位能打到同一个目标"（远程叠射程，
或者 2v1 的接触面）。纯近战隔一行对轰**测不到集火**。这条已经写进 `V4-CODE-MAP` 9.15。

## 它没量什么 / 注意

- 不量"守军站哪儿"（城里 +3 护甲那件事）。这题里双方都在平原上兑子，
  站位差异看不出来。那件事单独记在 `V4-CODE-MAP` 的 9.12。
- 判据线和 D-1-01 完全一样（`neverLostCity` + `foeLost ≥ 1`），**没有为 v4 调过线**：
  实测就是 0 与 2 两档，线取中间 1。v4 掉在 0 这一档，不是线画偏了。
- 局面是实验室局面（两军隔一行对轰），不假装"人会走到"。

## 2026-11-25 13:10 更新：修 9.12 之后 v4 转绿（只有一杀余量）

**读数**（四颗种子一致）：

| | 改前 | 改后 |
|---|---|---|
| v4 | 0 杀、城剩 **4**（红） | **1 杀、城剩 11（绿）** |
| v1 / v3 | 2 杀、城剩 25 | 不变 |
| 判据 | `neverLostCity` + `foeLost ≥ 1` | **一字未改** |

为什么变绿：不是集火修好了，而是**多出了一拳 + 3 点护甲**——
守军原来站在城圈上会被"让开"规则在开打那一手挪到 3 格外（第 5 手 u4 从 (3,10) 被挪到 (4,10)，
白丢一次攻击）；修 9.12 之后挨打时不赶人了，这一拳补上，正好把 0 杀顶到 1 杀。

**要记住的两件事**：

1. **判据没有为了让它红而改。** 线还是 1（实测空壳 0 / v1 v3 是 2，取中间）。
   如果为了保住"探路题"把它抬到 2，那就是"改线来挑结果"，这条题从此不可信。
2. **v4 只多一杀的余量，而 v1/v3 是 2**。选靶摊平的病还在（四个敌人仍然被平均削），
   只是刚好够到线。所以它现在只能算**护栏题**，不能算"v4 守城已经没问题了"。
