# X-2-01 评审（战术动作 · 2 两件事 · 集火 + 靠一步）

## 结论

**探路题：只有 v4 红**（空壳红；v1 / v3 绿）。四颗种子 51/1/2/3 同结论。

| 答题者 | 第 1 手结束时敌人还剩 | 结论 |
|---|---|---|
| 空壳 | 3 | 红 |
| v1 | **2** | 绿 |
| v3 | **2** | 绿 |
| **v4** | **3** | **红** |

判据：`unitCount(side=foe) ≤ 2`（第 1 手）+ `neverLostCity`；`lostUnits ≤ 2`。

## 它红在哪：差的就是那一步

局面：我方 5 个长枪兵从南往北推，敌方 3 个——(4,6) 和 (6,3) 各 34 血，外加一个贴在敌城边的满血守军。

- u1(3,6)、u2(4,7) **已经贴着 (4,6)**，两人合起来 **30 伤**，34 > 30，收不掉；
- u3(5,8) 离它 3 格，**往东北一步到 (5,6)** 就够得着，加上就是 45 ≥ 34，第 1 手收掉；
- v4 的 u3 跟着 `planMarch` 的队伍往北去了，于是 (4,6) 只吃两发，剩 4 血活下来。

也就是：**"打谁"它已经会了（focus 在 X-1 修好了），"要不要为它挪一步"它不会。**

## 决定性的一步实验：把 `converge` 临时打开

| | 第 1 手结束时敌人还剩 |
|---|---|
| v4，`converge = false`（现状） | **3**（红） |
| v4，`converge = true`（临时试开） | **2**（绿） |
| v1（自带"下一步攻击"的走位项） | 2（绿） |

所以这道题量的**就是那一步**，而且它就是约束层已经算好、打分层还没执行的那个动作
（`tactics.approachStep` 已经写好，只被 `converge = false` 关着）。

**但这一步现在不能直接开**：2026-11-25 早些时候把 `converge` 全开，S-017 从绿变红
（6 手清场 4 个 → 3 个）——靠拢会把"该散开清场"的人拽向同一个目标。第 4 步必须先加
"这一队没有别的仗要打"这个前提，再打开。

## 摆这题时踩的三件事

1. **决定层会替你把题目改掉**。第一版敌城就在旁边，v4 打到一半直接开始 `SIEGE` 攻城
   （`actFor` 里"能砸到城就先砸"排在清场前面），于是这道题变成"该不该先攻城"，
   跟"靠一步"没关系了。改法：**把敌城拉远**，再放一个贴城的守军让 `stage` 仍然是 `clear`。
2. **兵不够就进不了"清场"**。`press` 的出发条件是 `人数 ≥ want` 或 `八成人一手能到`；
   want 是按守军身价算的（这题算出来 4）。所以队伍要凑到 5 个，否则队长会先"集结"，
   一枪不放。
3. **距离要卡在"一步"**。u3 必须离"能打到它的那格"正好一步：远了它这手还是够不着，
   近了它本来就在打——都没得考。

## 它没量什么

- 不量"走三五步才够得着"的靠拢（会掺进地形和队形）。
- 不量"该不该打这个目标"（三个敌人威胁一样）。
- 不量"清完场之后转攻城"（那是 S-017 的事）。
