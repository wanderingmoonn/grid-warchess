# X-2-01 评审（战术动作 · 2 两件事 · 集火 + 靠一步）

## 结论

**立住（护栏）**：空壳红，v1 / v3 / v4 绿。四颗种子 51/1/2/3 同结论。

修之前它是探路题（只有 v4 红）；约束层把"靠一步"的条件算出来之后转绿。

| 答题者 | 第 1 手结束时敌人还剩 | 结论 |
|---|---|---|
| 空壳 | 3 | 红 |
| v1 | **2** | 绿 |
| v3 | **2** | 绿 |
| **v4** | **2** | **绿**（`converge` 打开之前是 3、红） |

判据：`unitCount(side=foe) ≤ 2`（第 1 手）+ `neverLostCity`；`lostUnits ≤ 2`。

## 它修之前红在哪：差的就是那一步

局面：我方 5 个长枪兵从南往北推，敌方 3 个——(4,6) 和 (6,3) 各 **28 血**，外加一个贴在敌城边的满血守军。

- u1(3,6)、u2(4,7) **已经贴着 (4,6)**，两人合起来 **20 伤**（一发 **10**：15 攻扣 5 护甲），28 > 20，收不掉；
- 第三个兵往西一格到 (4,5)、或往东一格到 (5,6)，就够得着，加上就是 30 ≥ 28，第 1 手收掉；
- 修之前，第三个兵跟着 `planMarch` 的队伍往北去了，于是 (4,6) 只吃两发，剩 8 血活下来。

也就是：**"打谁"它已经会了（focus 在 X-1 修好了），"要不要为它挪一步"修之前不会。**

## 现在的判据（约束层算，打分层只执行）

```
converge = 这一队能移动
        && 0 < 原地伤害 < 它的血          // 已经在打它了，但这一手打不死
        && 原地伤害 + 一个闲人那一发 ≥ 它的血   // 再补一个人就收
```

"闲人"= **这一手本来没有任何可打目标**的兵。两个条件缺一不可：

- 只写第一条时（只要"补一刀就收"），S-017 从绿变红（6 手清场 4 → 3）——
  那一局第 1 手是"没人够得着、七个闲人合计够"，于是全军被拽过去，清场慢一手；
- 加上"原地伤害 > 0"（已经在打）和"只算**一个**闲人的量"之后，它只在真正的
  "补一刀"场景里开，S-017 回到绿。

实测：v4 第 1 手 `converge = true`（原地 20 + 一个闲人 10 ≥ 28），第三个兵走进来、
第 1 手收掉一个 → 转绿；S-017 仍是绿。

## 摆这题时踩的三件事

1. **伤害要用 `previewAttack` 量**。第一版按"长枪 15 攻"算，得出"两发 30、三发 45"，
   于是把敌人设成 34 血——实际一发只有 **10**（15 攻扣 5 护甲），两发 20、三发 30，
   34 血要四拳才倒。数值错了，判据就跟着错。
2. **决定层会替你把题目改掉**。第一版敌城就在旁边，v4 打到一半直接开始 `SIEGE` 攻城
   （`actFor` 里"能砸到城就先砸"排在清场前面），于是这道题变成"该不该先攻城"，
   跟"靠一步"没关系了。改法：**把敌城拉远**，再放一个贴城的守军让 `stage` 仍然是 `clear`。
3. **兵不够就进不了"清场"**。`press` 的出发条件是 `人数 ≥ want` 或 `八成人一手能到`；
   want 是按守军身价算的（这题算出来 4）。所以队伍要凑到 5 个，否则队长会先"集结"，
   一枪不放。
4. **距离要卡在"一步"**。u3 必须离"能打到它的那格"正好一步：远了它这手还是够不着，
   近了它本来就在打——都没得考。

## 它没量什么

- 不量"走三五步才够得着"的靠拢（会掺进地形和队形）。
- 不量"该不该打这个目标"（三个敌人威胁一样）。
- 不量"清完场之后转攻城"（那是 S-017 的事）。
