# T-1-02 评审（2026-11-25）· 接管 · 1 一件事

**结论：立住了，也是"护栏题"（v1 / v3 / v4 全绿）。**

## 这题是什么

T-1-01 的一换：**只加了一座更远的废墟**，其余同形（我方 1 城、金 200、3 个长枪兵、无威胁、无收入）。

- 近的废墟 (6,9)，离最前面的兵 1~3 格；
- 远的废墟 (10,1)，离它 14 格 ≈ 7 次行动；
- 窗口 3 手 = 2 次行动，所以只有近的那座够得着。

问题：3 手内让废墟变成我的——判据只认**近的那座**。

## 实测（四颗种子）

| 答题者 | 近的那座（第 3 手） | 结论 |
|---|---|---|
| 空壳 | B | ❌ |
| v1 | A | ✅ |
| v3 | A | ✅ |
| **v4** | A | ✅ |

种子 51 / 1 / 2 / 3 同结论；v1 / v3 各另验一颗。

顺带一个不算成绩的观察：v4 这道题**没有接着造兵**（第 3 手仍是 3 个战斗兵），
v1 / v3 都造到了 4 个。差别不在判据里，但和"接管成功后决定翻成打"的时机有关，值得记着。

## 这一对证出了什么

| | T-1-01 | T-1-02 |
|---|---|---|
| 变化 | 一座废墟，就在旁边 | 多一座远的 |
| 结论 | 空壳红 / v1 v3 v4 绿 | 同左 |

两道一起说明："接管 · 1"这一格 v4 站得住，而且不是靠"只有一座没得选"。
**但两道都没红**——所以"接管"这条轨目前没有问题可修，它的作用是把地基钉住，
让 T-2（钱不够、先攒）和 T-3（废墟旁有敌人、先清场）红了能归因。

## 它没量什么

- 不指向 v4 的缺点（三个 AI 都能过）。
- 不考"该不该花这笔钱"。两座废墟都要得，只是先后；真正的取舍在 T-2。
- 局面是实验室局面。

## 和 T-1-01 共用的一个坑（写两遍，免得漏看）

这道题也必须 **3 个兵**。只有 1 个时，守家兵规则（`role === 'home'` 无条件留 2 个）
会把唯一的兵扣走，`captureId` 为空，接管根本发不出去——那不是"选错了废墟"，
是"没人去"。详见 `exams/T-1-01/review.md`，也是待办 9.7 的新证据。
