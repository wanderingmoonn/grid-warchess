# P-4-03 评审（2026-11-26）· 自己架桥

> **这是一道诊断题**，不是能力题：它要复现的问题是"**桥能铺出来，但部队不过河**"。
> 红不代表 v4 不会架桥；它代表架完桥之后那一步断了。

## 一、题是什么

- 18×18，一条 **3 格宽**的河横断全图，**一格桥都没有**（就是 `P-4-01` 把桥拆掉）；
- 我方：6 戟兵 + 6 火枪 + **2 个劳工**（能修木桥，45 金/格）、**900 金**；无收入；
- 敌方：一座 3 代城 + 两座箭塔（不会动，但让对手不成"无兵出局"）；
- 判据：40 手内把敌城打掉 ≥60 血 + 老家不丢。

和 `P-4-01` 的唯一差别：**那道题桥是现成的，这道要自己修**。

## 三、v4 的回放里能看到什么

回放在 `exams/P-4-03/replay.json`（702 个动作、81 回合、40 条编队记录）。

**桥确实修出来了**——3 次 `BUILD`，位置正好是渡口的三格：

```
BUILD  bridge @ 8,7
BUILD  bridge @ 9,7
BUILD  bridge @ 10,7
```

**但一次都没打**——动作分布：

```
MOVE 611 · END_TURN 80 · BUILD 3 · RECRUIT 8 · ATTACK 0 · SIEGE 0
```

也就是说：**路修好了，兵没过去**。8 次造兵把钱花光（900 → 0），桥被对岸箭塔打掉一格之后也没钱修。

## 五、已知局限

- **四版全红，没有人手答案**。按项目规矩（判据要"人手能绿"才算立住），
  这道题暂时只能当**诊断题**用，**不进 `ACTIVE`**；等它修绿、并补一份人手答案，再考虑收进跑批。
- 桥是建筑（木桥 40 血），会被对岸箭塔打掉——这是题目设定的一部分，不是 bug。
  但它会干扰"部队过河"这个主问题：看回放时先看 **T15 前后（桥刚通的那几手）**，
  那几手才反映"过不过桥"，后面是"修桥—被打掉"的循环。
