# 2026-11-07

## 产品线：新手教程收尾 → 上帝模式 UI 瘦身 → 战报卡

用户已放弃继续修 AI（"我不修 AI 了"），转做产品。今天三件事，全部已上线。

### 1. 教程扩到十步（0.3.46，commit 9eff5f3）
`goal → select → move → terrain → attack → endturn → upgrade → recruit → siege → done`。
每步用**状态谓词**（`done?: (c: Ctx, s: Snap) => boolean`）判定"真的做到了"，不是"点了下一步"。
踩过的坑：
- 红框必须在 `renderBoard` 的渲染参数里给（`tutorialTiles / tutorialCityId`），
  不能渲染完再往 DOM 上贴 class——棋盘每帧重建，首帧在 rAF，贴上去就没了。
- 逐格 outline 会在交界处出现细线/中央十字 → 改成整块 `.city-block` 上框。
- 第三步要限位：`allowedDestinations()` 只放行"走完贴脸"的落点 +
  `dispatch` 首部 `tutorialBlocking()` 拦掉讲解页的一切改局动作。

### 2. 上帝模式工具栏瘦身（0.3.46，commit 51b54ef）
删掉「操控」整组、`GodUi.selected`、两段自解释文案、多余的棋子状态；
轮次行合成一行；结束回合按钮统一成同行样式（偏高是 `.chip` 的 line-height 造成的）。

### 3. 战报卡（0.3.47，commit f86ed78）
一局打完出一张 720×560 的卡：破城回合 / MVP 兵种 / 关键三步，出口是
存图片（本地生成）、系统分享（有 `navigator.share` 才出现）、复制文字。

实现口径（下次改这块要守住）：
- **数据全从 `GameState` 算，不依赖录制器**——关掉"详细记录"的局也要能出卡。
- 破城回合读 `city.capturedTurn` 并按 **`owner === 赢家`** 找。
  第一版从"owner !== 我"找，破城那一刻城已归我 → 永远 null。
- 敌方席位必须走 `seatsOf(s)`。`state.players` **恒有 A/B/C/D 四个键**，
  直接 `Object.keys` 会在两人局多出两个 0 兵 0 城的幽灵席位（`4 !== 2` 就是这么来的）。
- 入口条件**不复用结算卡**：结算卡在上帝模式里是不给的（沙盒），
  而那正是自家玩得最多的地方。战报卡只排"复盘"一种情况。
- 终局一次性提示放在 `render()` 里（`settledNotified`）：分出胜负有八条路
  （攻城/认输/城被打光/联机提交/AI 走完/指挥官收尾…），各处各写一句一定漏。

排版验证的办法（**这个可以复用**）：本机没有 puppeteer/playwright，但有 Edge。
`msedge --headless=new --screenshot=... file:///...` 能出图，前提是
1) 脚本必须**内联**进 HTML（file:// 外部脚本报 "Script error." 拿不到真消息）；
2) esbuild 打 CSS 会产出独立 `.css`，得手动内联进 `<style>`，否则整页没样式。
另外加了一条用例：假 ctx（CJK 1em / 半角 0.55em）记录每一笔的边界，
断言没有字块画到卡外——排版错误变成红灯，比肉眼看一遍稳。
