
## 规则书加了「十二只诡异关系图」

试玩反馈没人搞得清 12 只谁变谁。做法：`Expansion.manualDiagram`（新字段，内联 SVG），
印在该包「特殊规则」的最前面。画成四条横链（影/血/骨/零散），箭头=变成，跨系用虚线框。

**没有渲染器时的验证办法**：本机没 rsvg-convert / cairosvg，qlmanage 被沙箱挡。
改用几何自检——解析生成的 SVG，按"中文 1em / ASCII 0.55em"估包围盒，和所有 rect 求交。
第一轮抓到"骨系副标题压进骸骨框"，缩短后 0 问题（45 文字 / 13 框）。

## 试玩后三处调整

- 黑蝗：血 20→14、甲 4→2；走位加"远离黑茧"（权重 0.9、封顶 6 格）。
- 诡异：新词条「暗影呼吸」每回合 +6 血（`TURN_START.self`，不看地形、不要求站住）；
  AI 血 ≤ 一半 → **放弃攻击**、往暗影最深处退，`pull` 随伤势 150→230。
- 两条合起来是它的性格：打不死，除非追进暗影一次打死（追进去视野/射程减半）。

探针 probe:odd 加 4 条（回血 / 满血不涨 / 低血无攻击候选且撤退 / 黑蝗避茧）。

## 仆从：青铜卫 + 断传承 / 痴愚

**核心改动（很小）**：`AbilityHooks` 加 `canCaptureCity` / `onCityCaptured`，
接在 `doMove` 里那处**唯一的城市易手点**。核心只问能力、不认兵种——不污染引擎。
`canCaptureCity` 必须问在**移动之前**（否则留下"站在废墟上但没占下来"的中间态）。

**两条词条**：
- 断传承（青铜卫）：占城后 `city.era -= 1`（最低 1）。
- 痴愚（**全部 12 只诡异**）：`canCaptureCity` 返回"痴愚：它不明白一座城是什么"。

**青铜卫** `bronze-guard`：era 2、血80/甲6/攻12/射1/移3、自主分 **0**（听指挥）、无暗影半径。
满潮里放了两只 (20,10)/(20,22)——**玩家现在真的会丢城了**（之前 C 全是诡异，永远占不了）。

探针 `npm run probe:servant`（18 条）。坑：诡异是 B 的兵，探针里忘了设 `current='B'`
会报"这不是你的单位"。

## 卫系三只 + 断传承改破城

**断传承**从 `onCityCaptured`（占领）改到新钩子 `onCityRazed`（破城），
`destroyCity(s, city, owner, byUnit?)` 多了一个可选单位参数，攻城路径传攻击者。
**没有单位的破城（剑气/陨石走 abilityApi）不触发**——得有"砸的人"。

**仆从 vs 诡异**：仆从能占城（无痴愚）、自主分 0.45（听指挥+一点自主）、有「留食」；
诡异全凭本能、痴愚不能占城。

**新核心钩子** `canAttackTarget`（和 canCaptureCity 同一套路）：核心只问，"为什么不打"由能力说。

**卫系**：青铜卫（140/12/视9/移2 钉子）、暗影卫（70/14/2段/飞/暗影4 追人）、
号卫（110/8/射6/溅射2 削弱）。共有「暗影驱动」：死留傀儡残躯，残躯 3 格内吸暗影→半血复活。
拆成两条词条：shadow-drive（怎么死）+ wreck-revive（怎么活）。

**虚弱**状态：移动/攻击 ×0.7，号卫「衰鸣」命中贴 2 回合。

探针 probe:servant（40 条）。满潮加了暗影卫+号卫（敌 31 兵）。

## 仆系三只（傀儡师 / 勾魂使 / 血医）

共同纪律：**不往人堆里扎**（同处 2 格内 ≥3 敌就退），但有人摸到仙帝/裔系 3 格内就作废。
裔系用 id 前缀 `heir-` 预留。

- **傀儡师**「傀儡制造」：每 3 回合按 青铜卫→暗影卫→号卫 造，每种 ≤2，满了跳过。
- **勾魂使**「暗影潜行」（只在暗影里藏、出手现形）+「勾魂」（6 格内任何单位回合末没动过就被拽向暗影深处，**不分敌我**）。
- **血医**「增生光环」：治疗 3 格内不分敌我（一半缺失、上限 12），等量积「影蚀之血」，
  超过最大生命 30% → 死亡化成 1 血肉 + 1 暗影；**挨打按伤害冲淡**（所以"先打再治"才是救人）。

**实现要点**：
- 勾魂在扩展层做（`pullSouls`），因为要影响别的单位；为此给扩展 `TurnEndCtx` 补了 `api`。
- 探针坑：`beginTurnOf` 结束的是对面回合，勾魂属于"回合末"，必须用 `endTurnOf`。

探针 `npm run probe:court`（34 条）。满潮补三只（C 起手 20 兵）。

## 裔系三只（眷属 / 后裔 / 子嗣）

- **避城**（共有）：视野内敌方城 era ≤3 → 10 回合撤离期（沉眠地 > 暗影最深处 > 远离那座城）。
  判断写进 `custom.retreatUntil`，走位用 220 分压住——是纪律不是偏好。
  **给玩家的反向活路**：把城打残能换十回合安宁（配合断传承）。
- **不据城**（共有）：`canCaptureCity` 直接拒。
- **归附**（眷属）：待够就变仆从，等待 = **2 + 场上仆从数**，变场上最少的那种。
- **传裔**（后裔）：3 回合一个眷属，上限 2。**衍嗣**（子嗣）：2 回合一个后裔，上限 2。
- 三只都有暗影跳跃 + 暗影 1。

**真元**：修真包里真元挂在修士 rank 上（`maxManaOf`），子嗣不是修士，
所以用 `magicAtk`（魔法段，同样无视护甲）表达，不动境界系统。

**探针坑**：场地里必须给**双方**各一座城，否则没城的那方在第二回合就被判出局
（"对局已结束"）；废墟要逐格挂 `tile.cityId`，不然后走进去不触发入驻。

探针 `npm run probe:heir`（33 条）。满潮补三只（C 起手 23 兵）。

## 两处纠正（作者指出）

1. **眷属「归附」只认仆系三种**（傀儡师/勾魂使/血医），卫系不算。
   原来 `SERVANT_TYPES` 把卫系 3 只也算进去了 → 等待时间被虚高、而且会变成"青铜卫"那种机关（等于降级）。
   现在计数与目标都只用 `COURT_TYPES`。
2. **子嗣的"真元"不用魔法段**：魔法段是奇想包污染核心的产物，这个包不借。
   改成**并进暗蚀**（子嗣暗蚀 20，全包最高），`magicAtk` 删掉。
   **判据**：扩展之间可以共享机制，但不该共享"象征物"。

探针补了"卫系不算仆从"和"子嗣暗蚀 20、眷属/后裔为 0"。
