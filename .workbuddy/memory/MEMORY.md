## 架构与坑

- **移动是瞬移结算**（无路径记录）：按"路过"判定得给 `reachableTiles` 补父指针；
  现有规则一律按**落点**算。
- **`s.cities = []` 会让引擎判该席位出局**（已踩三次）。脚本对局要留城，只挪战场。
- `placeUnit` 是纯函数。
- **跑批**：单次 60 局会被系统杀 → 20 局一批串行（约 7 分钟/批）。两进程 24s/局，
  四并发反而 2 分钟/局。
- `node_modules` 是符号链接，`.gitignore` 写 `node_modules`（不带斜杠）。
- **`setup.ts` 的 config 逐项白名单抄**：新开关不抄 = 开了跟没开一样（踩两次）。
- 用开关包逻辑时**关着必须等于老行为**：别给 `if` 整体加条件（会整段跳过），
  要保留这段、只换里面的判据。
