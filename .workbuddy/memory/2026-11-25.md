## 10:05 修订：八级阶梯作废 → **四轨 × 三档**（用户指出"按复杂度排没按内容排"）

用户质疑两件事：① 阶梯只按复杂度排，人类的打仗能力是多方面的（经济/升代/侦查/编成/时机/关口/兵种），
塞不进去；② 第 1 级"一个兵走到指定格"不知道怎么摆局面。两条都成立。

**核心发现一：三项能力在 v4 里没有主人**（逐个 grep 过，记进 V4-CODE-MAP 9.10）
- **升级时代**：`src/core/v4/` 里没有"升级"这个词，三层都不决定升。
- **侦查敌情**：只有 `playerView` 读雾，没有"去看"这个动作。
- **识别关口**：地形只被当"形状"读（窄道排队/分路），没被当"价值"读。
- 第四项**守**有位置但缺数：城角色只看"离敌**城**几格"，敌军离多近不参与判断 → 守轨写不出题。
→ 结论："升级时代放第几层"没有答案，因为它哪一层都不在。这类进"架构欠账"，不进题库。

**核心发现二：题面"一个兵走到指定格"和架构对不上**
决定层只输出四个意图（发展/打/接管/守），没有"把某单位挪到某格"。走动是意图分解后的执行细节。
所以第 1 档不能写"走到某格"，要写"只剩一个意图能成立"。四个开关（按 decide.ts 顺序）：
① 用第 1 手（没有上次决定）② 守要"对面身价 > 我 0.9 倍"→ 让我强或对面 0 兵
③ 场上不留废墟（否则必接管）④ 打要"我身价 > 对面 1.25 倍"→ 我方 0 战斗兵
陷阱：**对手必须有城**（否则判出局），所以"无敌人"= 空城；空城 + 我有战斗兵 = 必打。
→ **纯发展局面必须一个战斗单位都没有**（S-015 正是"我 0 兵"）。
→ 另一条：**经济岗与意图无关**（约束层无条件算），所以发展轨的题测不到决定层。

**新结构**：行 = 四轨（发展/打/接管/守），列 = 三档（一件事/两件事/在对抗下）。
- "会挪一格"降级成**单元测试**（`npm test`，不进题库）；"不做无用功"降级成**判据第二段**；"整局"归跑批。
- 13 道分布：发展1 = S-006/009/015；打1 = S-005/016；打2 = S-000/017；打3 = S-002/011/012；
  接管2 = S-001；守2 = S-013；守3 = S-004。**6 个格子空着**，其中守轨 3 格写不出来。
- 接管轨和打轨天生带阶段（入驻→攒钱→清场 / 空城→有守军→有火力），三档各一道，天然成立。
