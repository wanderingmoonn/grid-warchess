方格战棋 · 规则书

回合制 · 1v1 · 五个时代 · 本文件由 npm run manual 从配置自动生成，数值与代码一致。

01目标

干掉对方的抵抗能力。判定条件是两条，满足任意一条就输：

① 城市全部易主 → 立刻判负
② 单位全灭 且 金币不够造最便宜的兵 → 判负

城就是根。没有城市，你就产不了兵、升不了级、也断了一切收入来源——手上有多少兵都只是拖延， 所以"丢光所有城市"直接判负，不再看你还剩几个兵。反过来，兵打光了但城还在、钱还够，你就还能再造。

这一条让"绕过去偷家"变成了真正的战术：只要把对方两座城都端掉，他前线那支满编部队立刻作废。

注意时代差距。伤害允许为 0，所以低两个以上时代的部队打高级装甲就是打不动。落后方唯一的翻盘路径是赶紧升级自己的城市，而不是堆兵。

02回合流程

  1. 对方回合结束时，你的建筑自动开火一次（打射程内最近、血最少的敌人）。
  2. 你的回合开始，结算收入：基础 20 + 每座城按自己的时代贡献 + 每个经济单位按所在地形产出。
  3. 你的单位恢复行动力（移动一次、攻击一次）。
  4. 你行动：移动、攻击、攻城、建造、在城市生产、升级城市。
  5. 点「结束行动」，把回合交给对方。

热座模式下会弹出交接遮罩；人机模式下 B 由 AI 自动接管，每步停留约 0.16 秒让你看清它在干什么。

水、桥与船

水和桥不是装饰，它们决定"能不能过去"：

  • 水域陆军进不去，但能养活一支舰队。水军在水上一格一步，机动性其实比陆军好；它的短板是上不了岸、也进不了城。
  • 桥是修在水面上的建筑：建好之后那一格变成桥面，双向通行——你的兵能过，对方的兵也能过。桥不是"自家专属的浮桥"，它是一条路。
  • 桥上能穿过、不能停留：桥本身占着那一格（和任何建筑一样）。所以一格宽的桥，恰好等于"移动力 1 的一道门"。
  • 桥不挡水路：船从桥底下过，和走在河上一样。想把一条河彻底封死，得靠岸上的兵，不能靠桥。
  • 桥有耐久（40），被打掉之后地形立刻退回水面。想断掉这条路，只能把桥打塌——这是真实的防守手段，也是真实的进攻目标。但拆桥必须贴到桥头：远程单位隔着河放箭打不塌（详见下一节）。
  • 桥只能架在至少一侧是陆地的水面上——一片汪洋上架不了桥。

渡船：让人过水

  • 渡船是水军里的运输船：攻击力 0，唯一的用处是把陆军运过水面。
  • 装载：选中渡船 → 点「装载」→ 点一个贴着船的己方陆军。上船的单位从棋盘上消失，占掉它这一回合。
  • 卸载：选中渡船 → 点「卸载」→ 点船边一格空地。下船的单位这一回合不能再动也不能再打——不然运输船就成了隔河空投。
  • 一次装卸会花掉渡船的 acted，所以每回合只能装卸一次；但它装完仍然可以开走。
  • 船沉了，舱里的人一起没。载着人往炮口上冲是最贵的失误。
  • 和桥的分工：桥是永久的、双向的、便宜的；渡船是机动的、一次只送两三个，而且会被击沉。桥断了以后，渡船就是唯一的办法。
桥之所以是"谁都能过"，是因为它站在一条公开的规则上：地形可通行 = 谁都能走。 上一版把桥做成"只有本方部队能过"，本质上是给一方开了一条专属通道——战场上没有这种东西。 现在桥只是一块能走的地，唯一的门槛是它被自己的建筑占着，所以只能穿、不能停。

地貌长什么样打起来是什么感觉

城市的摆法单独抽签，和河的走向无关：

  • 对峙：双方各占同一条边的两角——隔着河对峙，正面冲突。
  • 对角：双方各占一对对角——河的两岸都有敌我。你的北城和对方的北城可能在同侧，河不再是"敌我分界线"，而是穿过双方领土的水系。
上一版是"横河就南北分家、纵河就东西分家"，于是纵河不过是把横河转了 90 度，四张图其实是两张图。 现在布局和河各抽各的，四种组合都会出现——同样是纵河，也可能打着打着从"抢渡口"变成"守自己的河岸"。

水域已经不再零散：河道 2~3 格宽起步并带拐弯，中段会鼓成 2~7 格宽的湖面；每座城边还有较高概率自带一小片水（那是港口，水军要靠它下水）。代价是有的图水占了近四成——那种图上，桥和船的价值会立刻凸显。

城市间距也是随机的。横向和纵向的"中间地带"各自抽签：小图上可能抽出两军隔 4 格贴脸的快棋，大图上可能抽出隔 14 格的长征局。间距直接决定第几回合接火——这比任何数值都更能改变一局的手感。

无渡口的河：必须架桥才能过

约四成的横河/纵河图会是一处渡口都没有的河：从地图这头连着那头，中间没有任何浅滩。

  • 这种河只在"对峙"布局里出现——也就是双方各占同一条边的两角、河真的横在两军中间。如果河只是穿过双方的领土（对角布局），它逼不出桥，也就没有意义。
  • 为了让桥铺得起，这种图的河宽被固定在 2 格，也不会有"汪洋"：一条 7 格宽的河要铺七座桥，那就不是障碍，是笑话。
  • 开局的战报会直接告诉你"这一局的河没有渡口"。这件事必须提前知道——你要为它准备的是十个回合的工程队和金币。
  • 一座桥 45 金，一次建一座，占掉工程队一整个回合。横渡 = 两座桥 = 90 金 + 两个回合；桥被打断就得重来。
  • 桥能接着往外递：建造距离是 2 格，但沿着同一条直线上已经铺好的桥面，可以再往外接两节。工程队站在岸上就能把桥修到河心——不然三格以上的水面永远铺不通，人站不到第二段桥旁边。
  • 桥是双向的，所以你先架好的桥对方也能用。架桥之前先想清楚：这个桥头堡守不守得住。
  • 拆桥要贴到桥头：只有站在桥那一端（相邻一格）的单位才能拆，长弓隔着河放箭打不塌。 否则谁先架桥谁吃亏——两边各架七八座、桥头来回换，河就成了永久屏障。
这才是"桥"真正变成主角的地方：在有渡口的图上桥是捷径，在无渡口的图上桥是唯一的通路， 而破坏一座桥就等于断掉对方整条补给线。反过来，桥头也是最容易被守方集火的位置—— 桥一格宽，你在桥头挤不下第二个人。

对称方式决定两侧地形是否一样：

  • 地势各异（默认）：两侧的森林、丘陵、高山数量相同，但位置不同。你熟悉的地形在对面可能是另一副样子。
  • 完全镜像：严格点对称，最公平，也最可预测。适合认真分胜负。
生成器有一条硬保证：四座城之间一定连得通。算法会从一座城出发算代价最高的路径，遇到绕不过去的河就架渡口、遇到山就开隘口——所以不会出现"打不起来"的废图。

想自己看一眼生成结果：npm run map 会把若干张图打成 ASCII。

04单位总览

全表分四类。完整数值见 第 15 节。

战斗单位
打仗的。每回合能移动一次、攻击一次。
经济单位
站在合适地形上产出金币（农民在平原、伐木工在森林）。很脆，需要保护。
建造单位
自己不产金，但能盖建筑。建造会占掉整个回合。
建筑
移动力 0，不可移动。军事建筑每回合自动开火，经济建筑按地形产金，桥把水面变成可通行的桥面，军营则是能推到前线的产兵点。
水军
只能在水面上行动（一格一步），从临水城市或临水军营边上的空水面下水。上不了岸，也进不了城；桥底下能过。
运输船
渡船不打架，但它能把贴身的陆军装进货舱（容量 2）运过水面。这是没有桥的时候唯一的过河方式，也是所有运输单位的通例：船沉了，舱里的人一起没。
开局部队只给时代 1 的战斗单位，外加两个经济单位（摆在城外）。高级兵、建造者、建筑都要自己想办法弄出来。

05移动

  • 只能走上下左右四方向，斜向不行。这样地形和走位才有意义。
  • 每格消耗由地形决定（见第 3 节），累计不能超过单位的移动力。
  • 敌军挡路：既不能进入，也不能穿过。
  • 友军可以穿过，但不能停在上面。
  • 建筑例外：站在上面是允许的。桥、箭塔、军营、磨坊这类设施占着一格却永远空着， 只会让布阵时莫名其妙地缺一个洞——所以它们可以站人：塔上有梯子、军营有营门、桥面本来就是路。 墙、栅栏、拒马、铁丝网不行：它们的全部作用就是让这一格不存在，能站等于把它删了。
  • 敌方的设施不能站（桥除外，桥是双向的）：那一格还被它占着，得先打掉。
  • 敌方城市格不可通行，必须先把耐久打空。
  • 己方城市格可以进驻，驻军享受城市的 +3 护甲。

选中单位后，棋盘上有四层提示：

  • 蓝色：可移动范围
  • 淡红斜纹：移动之后能打到的范围（还没移动时才显示）
  • 实红框：现在就能打的目标
  • 橙色：建造选址（建造模式下）
移动过的单位只剩原地开火那一圈，不会再画一大片。威胁范围会随状态变化，看红区之前先看这个单位还有没有移动力。

机动与视野的整体下调

所有单位的移动力和视野各削了一档（视野最低 2 格）：

  • 移动力 5 → 4（斥候、骠骑兵、装甲车、炮艇），4 → 3（骑士、坦克、牧民、舢板），3 → 2（民兵、弓手、农民、劳工……）。
  • 移动力 2 的单位不再下调。这不是手软：森林和丘陵的进入消耗是 2，再削一档就是"永远进不了林子"，整套地形系统会当场失效。
  • 视野全部 −1，下限 2。斥候仍是眼睛最好的单位，但"一眼看穿对面半场"结束了。
  • 射程没有跟着削，反而要盯住"射程 − 移速"这个差值：移速降了，远程本来就该占更多便宜。 现在的刻度分两档：移速 1~2 的单位，射程必须 ≥ 移速 + 1（弓手 2 移 3 射、长弓 2 移 4 射、机枪 1 移 3 射）； 移速 3 以上的重甲单位，射程至少 3 格才算远程（坦克 3 移 3 射、装甲车 4 移 3 射）。 另外还有一档射程 2 的"长兵器"（戟兵、长枪兵那一路）：比近战多一格，但不要求压过移速。 这两条线都有测试盯着，防止以后调数值时又把它缩回去。

后果是全图有效宽度变大：以前三个回合能从家门口顶到对面城下，现在要走五六个回合，而且中间大概率隔着一道非过不可的水。

06战斗

伤害 = 攻击 + 攻击方光环 − （护甲 + 防守方光环 + 地形加成）
然后过一遍扩展钩子，最低 0，取整

纯减法，没有随机、没有暴击。玩家能当场心算出来。

修正项

  • 破甲：防守方护甲（含地形和光环）先砍半再参与计算。
  • 盾墙：防守方本回合没移动过时，最终伤害 −2。
  • 光环：相邻友军提供 +2 攻击（指挥）或 +2 护甲（守护）。只加不乘，不递归。

反击

反击伤害 = 伤害 × 0.5
条件：目标存活 且 攻击者在其射程内 且 攻击方没有「先手」能力

所以远程站在射程外输出可以完全不吃反击；近战互殴时双方都掉血。

溅射与连击

两种"一次攻击打好几下"的机制，方向和代价完全相反：

  • 溅射（splash）：主目标周围 N 格内（曼哈顿距离，不含斜角）的敌人各吃 50% 伤害。 半径按兵种不同：臼炮 / 炮台是 1 格（主目标上下左右四格），火炮是 2 格。战报里会写"溅射了谁"。 只打敌人，不打自己人——打的是阵型，不是一个人。
  • 连击（burst）：一次攻击结算 N 段，每段单独减一次护甲。段数也不是固定的： 装甲车 2 段、机枪队 3 段、重机枪组 4 段。段数越多，对重甲越吃亏——所以每段攻击力也越低。
  • 表格里攻击列写成 18×3 就表示"每段 18 点，打 3 段"。特性列会另外标出「溅射 N 格」「连击 N 段」。
  • 破城（攻城伤害 ×1.5）现在给到了整条炮线：臼炮、火炮、坦克、铁甲舰。高时代的城又厚又能回血， 没有破城的攻城单位在城墙下只是刮痧。
  • 两者都不吃反击加成：反击仍然只结算一次（前提是目标活下来了）。
这两个机制是"护甲是减法"的直接后果：连击把一次减法拆成 N 次，所以对高护甲天然吃亏； 溅射则是"多打几个人"而不是"打得更深"。想针对它们，就堆护甲（对付机枪）或者散开阵型（对付臼炮）。

为什么允许 0 伤害

攻击力低于护甲时就是 0。这是刻意的：差四个时代的民兵打坦克，本来就该打不动。战报会写「穿不透护甲」。

调数值时的铁律：护甲每 +1 不是"+1 防御"，而是直接砍掉一点伤害。基数是 8~14 的伤害，护甲 +3 就减了 30%。所以跨时代成长主要放在攻击和血量上，护甲要克制地涨。

07攻城

攻城伤害 = 攻击 − 城市护甲 （有「破城」能力则 ×1.5）
城市不会反击。最低 0。
  • 城市初始耐久 30，随时代提升（见第 11 节）。
  • 耐久归零 → 城市变成废墟：不再产出、不产兵、不回血，但还不算易主——它仍挂在原主名下，所以不会因为"丢了一座城"立刻判负。
  • 派兵走进去才接管：入驻时支付一笔重建费（= 城市耐久上限 × 2.5），付不起就进不去。接管后耐久恢复到上限的 30%，时代等级一起接收。
  • 这条把"砸开城墙"和"拿到城市"拆成了两件事：攻方必须留一支部队去占，否则只是把对面打残，没拿到产能。
  • 刚接管的城当回合产不了兵，要等下一回合恢复。否则打下一座城就等于顺手补了一支部队，攻城反而成了补员。
  • 城内来不及撤走的守军随城陷落，建筑也一起损失。
  • 攻陷后时代等级会一起接收——抢下一座时代 III 的城，你立刻就有它的产能。

城市 2×2 共四格，所以"驻军还是修工事"是个真实的取舍：城里站满就放不下建筑。

驻军休整：守城是有回报的

回血 = 3 + (驻军数 − 1) × 1，上限 6 / 回合
条件：城内有驻军，而且城墙外一圈没有敌方单位
  • 回血在自己回合开始时结算，和收入一起。
  • 没有驻军就不回血。刚打下来的城如果一个人都不留，它就一直是残血——这才是"占领"该有的样子。
  • 被围城就不回血。敌方单位贴在城墙外一圈（含斜角），城就没法休整。想拆掉一座城，先把它围起来；反过来，想守住一座城，就得把贴脸的散兵清掉。
  • 上限 6：城可以守住，但不会变成打不动的铁王八。
这条规则是冲着"刚被攻陷的城太脆"去的：攻陷时耐久只恢复到上限的 30%， 如果不再回血，对面留一个小队就能第二轮摘回去，等于白打。 现在只要派驻军、清掉贴脸的敌人，它每回合自己往回爬。

08经济

每回合收入 = 20（基础）
  + Σ 每座城市按自己的时代贡献
  + Σ 每个经济单位 / 经济建筑按所在地形产出
  + 相邻水域的额外 3 金
再过一个扩展钩子，最后取整

经济单位的产出看它站在哪儿：农民在平原最赚、牧民在丘陵最赚、伐木工在森林最赚、厂长在城里最赚。城里对农民几乎是零产出，所以人必须撒到野外去。

「临水 +3」是一条通用规则，适用于所有经济单位和经济建筑——这是水利、灌溉、运输的抽象。所以河边的平原是整个地图上最值钱的地。

经济单位很脆（护甲 1~4，血 16~30）。它创造了一个新玩法：你的后方开始有必须保护的东西，推进时得留人看家。

时代升级为什么这么贵

升级费用：中世 220 · 火药 360 · 工业 540 · 现代 780
开局 120 金起步，先结一次收入后手上有两百出头

升级一次性给你三样东西：更好的兵、更硬的城市、更高的城市收入。三样叠在一起就是滚雪球—— 先手方只要能在第一回合升级，第二回合就能用长弓和骑士去打民兵，经济差还会自己越滚越大。

  • 所以第一道闸是开局差一点买不起：开局先结一次第一回合收入，手上有两百出头， 离 220 金刚好差一点——逼你先走一两个回合的积累，而不是第一回合就把科技点上去。
  • 第二道闸是升级会掏空你的兵：升级那一回合你几乎造不出任何东西，等于把一整个回合押在"以后"。
  • 第三道闸是收益不再指数增长：城市收入从 30 → 56，涨得比造价慢得多。所以越到后面，升级越像"解锁更强的兵"，而不是"印钞"。
想调整节奏就看两个数：ERAS[].upgradeCost（越贵越慢）和 ERAS[].cityIncome（越低越穷）。 改这个表之后记得同步 CONFIG.startGold——"开局买不起"是刻意的设计，不是巧合。

09生产

  • 只能在自己的城市格里产兵，而且那一格必须是空的。
  • 城市只能造当前时代和上一个时代的兵种。换句话说：比城市低两个时代（含更老）的战斗单位一律不能生产——已经淘汰的装备不会再开产线，否则到了现代还要在面板里翻十个早就没用的兵。
  • 这条对所有兵种一视同仁：原版兵和扩展包带来的兵都按同一把尺子卡（def.era < 城市时代 − 1 直接拒绝，面板里也不会列出来）。军营按"最近一座己方城市"的时代算。
  • 建筑不在城市生产列表里，得由建造单位去盖（见第 10 节）。
  • 新兵当回合不能行动，否则等于凭空多一次攻击。
  • 水军要临水：城市旁边必须有一格空水面，船就下在那儿。内陆城市造不了船。
  • 军营是第二个产兵点：兵从营门四邻的空地出来，规则和城市完全一样，唯一的区别是它自己没有时代——时代取离它最近的己方城市。军营不用升级，所以前线的兵种水平跟着后方那座城走。
  • 军营必须扎在水边：脚下要是平地或丘陵，四邻还要有一格水面（桥面也算，桥下就是河）。粮秣、饮水、船运都得靠水，这条同时给了水军存在的理由——补给点必然在水上，也就必然会被船盯上。
  • 军营分五档，跟着建造单位的时代解锁：军营（古典）→ 寨垒（中世）→ 堡寨（火药）→ 兵站（工业）→ 前进基地（现代）。越高档耐久越高、哨兵火力越强，产兵规则完全一样（时代取最近的城市）。所以"把补给点往前推"这件事，是可以跟着时代一起升级的。
  • 双方作战单位数上限 24，防止滚雪球。建筑不占编制——建筑是工地不是部队，否则前线盖几座军营、后方几座磨坊，产线就被自己的工地堵死了。

10建造

建筑不是凭空出现的：得有一个建造单位走过去，花钱，把这一回合搭进去。

  1. 选中建造单位，面板底部会出现「可建造」列表。
  2. 点其中一项，棋盘上高亮出它周围 2 格内的空地。
  3. 点一块地，开工。
  • 建造消耗该单位整个回合（移动和攻击都没了）。
  • 建造者本身攻击力只有 4~5、血 20~30，派到前线修工事是真的有风险。
  • 军事建筑在敌方回合开始时自动开火，打射程内最近且血最少的敌人。有攻击力也有射程，所以被单位攻击时会正常反击。军营同样有哨兵，贴到营门口会被敲一下。
  • 军营只能扎在平原或丘陵上（地形要求写在兵种数据里，不写死在代码里）。它是最便宜的"把补给点往前推"的办法：省掉新兵从后方跑到前线的那几个回合。
  • 建在自家城里要留出兵位：如果这一格是这座城最后一个空位，界面会拒绝开工并说明原因。 这一条是踩出来的——在只剩一格空地的城里盖座塔，城市的产兵格就变成 0，从此一兵不出， 而界面上只有一句"没有可造的兵"。宁可不让建，也不让人莫名其妙地卡死自己。
  • 拆除：选中自己的建筑或单位，面板底部有「拆除（回收 X 金）」，回收造价的 40%。 不是全额退：全额退款等于"造一个侦察兵看一眼、原地拆掉回本"，一条零成本的开图路线。 也不给退钱以外的补偿——拆掉就是拆掉。

缩放

棋盘右下角有 −／适应／＋ 三档：1× 是"整张图塞进屏幕"，最多能放到 3×。 放大之后按住地图直接拖就能平移（鼠标和手指都行），也保留滚动条；拖动本身不算点击， 松手不会顺带走一步棋。 放大是把每个格子真的画大（不是把整块画布拉糊），所以字和血条一起变清楚； 超出的部分用滚动看，缩放时会自动把视口挪到地图中间。

为什么要它：32×32 的图"适应屏幕"之后一格约 20 像素，认得出棋子、看不清位置。 这也正是大地图不能只靠"图更大"来做多线的原因——看得见全图和在某一处看得清，是两件事。

开局时可以选起始时代（1~5）。越高，一局越短：

  • 古典开局：完整五级链条，适合打整晚
  • 火药开局：跳过冷兵器，直接进入排队枪毙
  • 现代开局：纯装甲对抗，二十分钟一局

12战争迷雾

  • 地形始终可见，只有敌方单位受迷雾影响。
  • 视野来源：己方单位的视野半径、己方城市周围 1 格。
  • 离开视野的敌人会留下半透明幽灵，标在最后已知位置。移动过或已阵亡你都无从确认——这正是它的乐趣。
  • 玩家视角恒等于当前行动方。人机对战时 AI 也只吃同一份过滤后的视图，不作弊。

浓雾蔽野（扩展）

上面那套雾只遮单位：地形、河流、敌城的位置永远是公开的，等于一张免费的地图。 开「浓雾蔽野」之后这一层也没了：

  • 视野外的格子连地形都不画，只剩一片暗面；
  • 敌方城市要侦察到（四格里有任意一格可见）才会出现在图上；
  • 顶栏的迷雾开关锁定为开，不能关——能一键关掉的话，这个扩展就只是个大号的显示选项。
幽灵标记是「迷雾」和「长回合异步」交叉出来的刚需：你隔一天回到游戏，战场上你只记得"上次他在河边"，这个记忆必须被画出来。

14扩展规则

开局时在设置面板里勾选，效果叠加。规则以 id 的形式记进对局存档（不存代码），所以存档可以序列化、可以回放，换台机器打开结果也一致。

「血战」默认开着。不特别说明的话，新对局就是"血战 + 你另外勾选的那些"。 它是给后半场踩刹车的：第 50 回合起城市不再回血、升级恢复原价、全军移动与视野各 +1。 实测（各 120 局、同种子配对）开与不开：古典未决率 5.8% → 0.8%、平均少打 19 回合；中世 17.5% → 10.0%、少打 15 回合； 先后手胜率没有可分辨的变化。想体验老节奏就在面板里把它取消勾选。

四条新规则

  • 魔法攻击 / 魔法抗性：魔攻是独立结算的第二段伤害，不吃护甲、地形、破甲，只被魔抗平减。 所以法师打重甲划算、打在魔抗单位身上像挠痒。数值都压在 20 以内——它是"另一条路"，不是"更大的数字"。
  • 属性伤害：火 / 水 / 土 / 风 / 光 / 暗 / 自然 / 奥术。目标可以写「怕X」（倍乘）和「抗X」（平减）， 作用在整段伤害上——怕火不是"怕魔法火"，被火把砸一下也疼。
  • 飞行：分两层。飞行能掠水（但不能停在水上）、森林丘陵按 1 步；掠空再进一步，还能和地面单位同格—— 地面那格站着人，天上那格照样能停，天上那格的人也只能打天上的。
  • 状态：中毒（每回合 6% 上限血）、点燃（8%，怕火的翻倍）、减速（移动 −1，最低 1）、诅咒（护甲 −2，最多两层）。 都按兵种血量百分比算，这样一支巨魔中同样的毒，掉的血和它的体型相称。
机制都写成"有前提、有解法"的形式：飞行怕射程、魔法怕魔抗、狂暴怕风筝、召唤怕清场。 纯加成的兵最后只会变成"贵一点的那个步兵"——这条在写这个包的时候被反复验证过。

16引擎与兼容

确定性

规则内核是纯函数 (state, action) → state，不碰 DOM、不发网络、不读系统时间、不用 Math.random。所有随机都从 state.seed 派生。所以：

  • 存档就是一个 JSON，每步自动落盘
  • 回放 = 把 action 列表重放一遍
  • 同一个种子永远生成同一张地图

存档自包含

对局的兵种表（state.unitTypes）完整存在存档里，所以你把对局发给别人，对方不需要装你的自定义兵种也能接着玩。

自定义兵种

内置兵种只读（那是平衡基准）。想改手感就复制一份，自定义的带 c_ 前缀存在本机，不会污染内置表。可以导出 JSON 发给别人。

17AI 托管与观战

AI 和玩家吃同一份迷雾视图（不作弊），决策不碰 Math.random，随机性从种子派生。几条它自己会算的事：

  • 手长单位不往前顶：射程里已经有人时，弓手会停在射程边缘开火，而不是往前挪到近战怀里。只有"挪过去能多打几个目标"才会继续前进。
  • 过不了河就架桥：算得出"纯走旱路摸不到对方城市"时，全军往最窄的渡口集结，工程队优先去铺桥。 已经铺出去的桥会接着往外递，而不是下回合换个地方重来——同一条河段上桥铺到四座就算够了。
  • 会往前线扎军营：军营是唯一能把钱直接变成"前线产兵点"的东西。选位讲究"不近不远"—— 离敌人 6~9 格最值，贴着敌人在下回合就被推平，缩在后方等于没造。每城一座、最多四座。
  • 不砌塔：军事建筑每座城最多一座，否则钱会全变成城墙。
  • 集中打一座城：主攻方向的权重压得比其它敌城低一截（0.32 : 0.85）， 全军朝同一座城收，而不是四路各挠一下。这条是专门为大地图加的： 32×32 上原来两军在中场互相绕圈，40 个回合一座城都推不动； 现在同样 40 回合，攻城次数翻倍、城市掉血从 97 涨到 249。 主攻方向取"血最少的那座，同血取最近的"。
  • 水军看地图造：水域占比不到 8%（开阔、山岭图）就干脆不造船—— 一个池塘里转圈的舢板只是四十五金的靶子；河图上才正经下水。
  • 高时代会换装：工业/现代单位在打分里有额外权重，造价惩罚也放宽—— 否则它算下来永远觉得"三个火枪兵比一辆坦克划算"，一辈子不换代。
  • 会收废墟：城被打空之后只是废墟（不产兵、不产出、不回血）， 得派兵走进去、付重建费才易主。AI 现在会朝最近的、付得起重建费的废墟开拔， 站上去完成接管；钱不够就不去（规则会拒绝这一步，白走一趟只会卡住它自己）。 自己的城被砸成废墟时更急——那是产线断了。
  • 会围攻：每回合挑血最少的那座敌方城市作为主攻方向，全军往那边收； 已经贴着城的友军越多，继续往上压的分越高（一座城每回合回血 3~6，一个人打是永远打不下来的）； 城一旦掉过半血，补刀优先级再抬一档。因为"丢光所有城市就输"，收敛攻城 = 直接赢。

AI 是一个"一步前瞻 + 启发式打分"的贪心对手：把所有能做的动作列出来各打一个分，挑最高的做，然后重新评估。它只吃迷雾过滤后的视图，跟你看到的东西一样多，所以它不会作弊——你用 AI 测出来的平衡是可信的。

两档难度

新对局面板里选完「人机对战」或「双 AI 观战」之后，会多出一行 初级 AI / 高级 AI。 两档跑的是同一套代码、同一套地形与架桥逻辑，差别只在「打分算得多细」。

行为初级 AI高级 AI
威胁图只看「有没有人能打到我」，一个和五个一样怕数得清有几只：周围每多一个敌人就多扣分，越贵的单位、越残的单位扣得越狠
换子判断按掉血比例算划不划算按身价算：拿坦克换民兵这种亏本买卖会主动避开
兵种搭配纯按单价估看现有部队的远程占比，缺远程补远程，缺肉盾补肉盾
经济兵走位哪块地赚得多就站哪先看这块地会不会被抢，被围了宁可不种也要撤
随机幅度大：同等分数里挑得比较随便小：出手更集中，不会因为噪声造一个明显不合适的兵

注意：「不会把自己憋死」这类修正两档都有。地形困死的兵种不招、远程不往近战怀里挪、建造者会躲、攻城有主攻方向—— 这些是补漏洞，不是难度；把漏洞留在初级里只会让人误以为这游戏的 AI 就是傻的。

三种用法

用法怎么开适合干什么
人机对战新对局面板选「人机对战」自己练手，或验证某个兵种好不好用
双 AI 观战新对局面板选「双 AI 观战」把两边都交出去，看它自己打完整局——调平衡最快的手段
中途托管顶栏「交给 AI」／「收回操作权」这一回合懒得走，或者想看看"换成它会怎么打"
  • 托管是按当前行动方切换的，随时可以收回来接着自己走。
  • 观战时顶栏出现「暂停」「速度」：慢 / 快 / 极快（极快是一帧算完一个回合，中间不重绘）。
  • 双 AI 观战给的是全图视角——这时候没有"我方"，迷雾没有意义。
  • AI 不碰 Math.random：它的随机性是从 (seed, 回合, 已走步数) 派生的，所以同一局面永远同一个决策，"它为什么走这一步"仍然可复现。
  • 但每回合的值都不一样：评分咬得很紧的几个动作里它会随机挑一个，所以同一种局面它会左翼一次、右翼一次。
  • 每局还有自己的性格（从种子长出来）：推进欲望 0.85~1.2 决定它多敢往前顶，另有两个偏爱兵种，所以每局的部队组成都不一样。
托管开关记在对局里（state.aiControl），不是只记在界面状态里。所以存档带上它，刷新之后这一方仍然是托管的。

让人旁观：观战位

想看别人打，不用抢座位。联机面板里输房间码点 「只看」，或者直接把邀请链接发过去—— 如果两个座位都有人了，链接会自动以观战身份打开，而不是弹一句"席位满了"。

  • 观战不占座：座位是互斥的（两个人不能同时执 A），观战不是。几个人同时看同一局都行，也不会互相挤掉。
  • 观战是全图视角：双方的伏兵、金币、正在造的兵全都看得见。适合看完局、复盘、开黑时说"你这步不对"。
  • 也正因如此，别在两个人还在打的时候开着麦念棋盘——那是替对面开图。
  • 观战只能看：走子、产兵、提交、认输全部锁住，点单位只会弹出属性卡。
  • 观战同样是"每次提交才同步"：对方点完「结束回合」，你这边下一次轮询就会看到新局面。
观战位刻意没有在数据库里加一列。加列意味着给已经在跑的房间做迁移， 而观战本来就不需要互斥——它只是本机的一个视角标记：不 claimSeat、提交被 myTurn 挡住、渲染给全图。 代价写在上面那条：看得见一切。

18指挥官模式

只当指挥官，不当连长：你决定接下来几回合各造什么兵， 其余的——建造建筑、升级城市、走位、攻击、上下船——全部交给 AI。

开局时在「你的角色」里选「指挥官模式」。之后一批只做一次决定：

  1. 顶栏下面那条「参谋部」横带里有 5 格生产序列，第一格标着「本回合」。
  2. 每格选一个兵种、选「升级时代」，或者留「不指定」。
  3. 每格下面写着「≈ N 金」——那是那一回合手上大概有多少钱： 现有金币 ＋ 中间几次收入 − 前面几格的花费。预算不够时数字变红。
  4. 点一次「执行 5 回合」，AI 把这 5 个回合（连同对手的 5 个回合）一起打完；中途可以按「中断」。
  5. 打完之后序列原样留着：不改就直接再点一次执行，排一次能用很多批。

手机上这条横带默认折成一行（只留「参谋部 + 排计划」），点开才铺出 5 格。 顶栏本来就吃掉一截屏幕，再让 5 个下拉常驻，棋盘就只剩一条缝了。

几条硬规则

  • 每回合最多产 1 个兵。序列就是「一回合一个」——允许多造，计划里的顺序就失去意义了。
  • 造不出来也照样消耗那一格。钱不够、城市时代不够、编制满了，这一格就是空的。 这是这个模式的核心取舍：得算着钱排计划，不是把想要的写上去等它实现。
  • 点名的兵不会被顶替。排了坦克但造不起，AI 不会「体贴地」换个民兵顶上，它这回合就不产兵。
  • 中间可以留空：排「弓手 → 空 → 民兵」就是第二回合故意不造、第三回合造民兵。
  • 棋盘只看不碰。选中、移动、攻击都不响应，这一方的走位归 AI。
  • 升级时代也归你。排了「升级时代」，这一回合就专注升级、不产兵；没排，AI 就不会自作主张升。 什么时候换代和造什么兵是同一层的决定，交出去一半就没得算了。
  • 建筑不能进序列——建筑是建造单位走过去盖的，序列里只能排会被「造出来」的单位。

序列存在对局状态里、跟着存档走，刷新页面不会丢；它同样是可复现的： 同一个种子、同一条序列、同样的对手，跑出来是同一局。

拿它当尺子

指挥官模式对 AI 同样生效：在它下面选「双 AI 观战」，两边都只剩「一回合一个兵」的产能。 这正是量「这套限制下 AI 还能打成什么样」的场景——如果限制下 AI 依旧能推得动， 说明每回合两个兵本来就是过剩产能；如果立刻打成一团浆糊，说明节奏是靠堆兵撑起来的。

AI 也排序列。它不是一回合一个兵地临时决定造什么——那样它只会做局部最优 （谁便宜造谁），永远不会为下一级兵攒三个回合的钱，这个模式对它就等于只剩下"少造"。 它每次排满 5 格，并且排的时候会把前面几格的产出算进去（先排了两个农民， 第三格就不会再排农民），所以它也会做"先铺经济、后转兵"这种跨回合的取舍。 一格升级最多排一次：占掉一格就是五个回合少一个兵。

也就是说，人机对局里双方受同一套约束、也都在算同一笔账——观战看到的不是 "这条限制的下界"，而是两个都会排计划的指挥官在互相博弈。

19联机与云存档

这是给"一回合半小时、各走一段再交接"准备的。点顶栏「联机」把当前这局挂到云上，拿到一个 6 位房间码；对方在任意设备上输入代码，或者直接点邀请链接，就坐进这一局。

规则

  • 结束回合＝提交。你不点「结束回合」，云端的存档不会变——所以对方永远看不到你正在怎么摆兵。
  • 提交之前关页面、断网、换设备都不影响：草稿存在本机浏览器里，回来接着走。
  • 云端记着"第几回合、轮到谁"，所以对面一看就知道你是不是已经走完了。
  • 你回到这个页面、或者切回这个标签时，会主动问一次云端：轮到我了吗。
  • 两边同时提交会撞车：后提交的那次会被挡下来（提交时不覆盖别人的回合），提示你先同步。

席位

一局两个席位（A / B）。打开邀请链接时优先回到你原来的席位（本机存着席位令牌），没有记录就坐空着的那个。 两个席位都有人时自动转成观战视角（见第 17 节）：不占座、只看、全图。

边界

迷雾在联机里是界面层面的约定，不是加密：整局状态是存在云上的，服务端不参与规则计算。也就是说，会开控制台的人理论上能读到对方的位置。真要防作弊，得把视图过滤（playerView）挪到服务端去算——架构上已经准备好了，但目前没做。

存哪儿

房间表在云数据库 warchess_rooms：一行一局，state 是整局 JSON 快照，turn / current 冗余出来给轮询用，两个 seat_* 列存席位令牌。房间码就是通行证，谁拿到谁能进这一局。

20认输 · 撤回 · 拆除 · 提示音

认输

侧栏底部「认输」，点一下问一句，确认就直接判负、整局结束。

  • 为什么要这个按钮：这游戏的判定是"城全丢才输"，残局里两边都没了进攻能力、 靠回合上限耗完，剩下的几十分钟谁也不享受。认输是给这种局面的一条出路。
  • 不可撤销，所以要确认一次。联机里认输同样会被提交上去。

撤回一步

侧栏「撤回一步」，回到上一步操作之前。范围是刻意收窄的：

  • 只在本机对局里有效（联机局提交过的回合收不回来——那等于改历史，两边会直接对不上）；
  • 只在本回合内有效（点过「结束回合」，这一回合的账就结了）；
  • 最多留 30 步；指挥官模式（走位归 AI）和 AI 托管时不给撤。

存的是旧状态的引用而不是克隆：applyAction 内部本来就深拷贝过，旧对象不会再被改，留着引用是安全的，也省掉每步一次深拷贝。

拆除

选中自己的任意建筑或单位，面板底部有「拆除（回收 X 金）」，回收造价的 40%。

  • 典型用途是"这堵墙把自家出兵位堵了""这条船搁在浅滩上没用了"。
  • 不给全额退：全额退款等于"造个侦察兵看一眼、原地拆掉回本"，一条零成本开图路线。
  • 拆除不消耗回合——它是"收拾自己留下的残局"，不是一次行动。

回合提示音

侧栏「铃声」按钮循环切换音量：静音 / 25% / 50% / 75% / 100%，存在本机，点一下当场试听。

  • 响的时机是"行动方换人了"——对面点完「结束回合」，你这边屏幕上"叮"一声，人就能从桌边走回来。
  • AI 对 AI 不响（会变成每秒一声），观战不响，分出胜负之后也不响。
  • 声音是 WebAudio 现场合成的（两个正弦音，660 → 880 Hz，间隔 0.14 秒），不带音频文件： 一声提示音不值得为它多一个几 KB 的下载和一条加载失败的分支。
