01这个包是什么

在基础包（太空时代）之上加一层「轨道」：地球和月球成为星图上的两个节点，中间连着航道；发射井除了送兵，还能把核心舱送上轨道，展开成一座可扩建的空间站。站上的建设不需要工程队、不需要运输——花资源就长。

  • 空间站：发射井可以直接发射「核心舱」——不用加注、不用装载，只花资源，点火就入轨。核心舱决定站的规模（5×5 / 7×7 / 9×9），到轨道时只有正中间一格甲板，其余全是虚空。点核心舱的「扩建甲板」选一格挨着已有甲板的虚空，花资源铺出来；铺好之后可以在上面造「生产舱」（每回合产金币）。站上的建设不需要工程队、不需要运输，钱到位就长。
  • 太空建设折扣：地球上每多一座发射井，站上建设就更便宜一点——但收益递减：没有井时比额定贵 50%，一座井时贵 30%，两座贵 14%，三座基本平价，之后才开始便宜，永远到不了半价。所以"多盖井"和"多建站"是同一条投资曲线上的两段。
  • 舱段与能量：空间站有一条自己的能量账（不是地球上的电网）：核心舱自带 10 电，每块「太阳能舱」+12，每台「推进器舱」耗 15，每座「生产舱」耗 4。电不够就造不出来（按钮会写明还差多少）；万一被打到过载，整站停摆——推进器不提速、生产舱不产金。
  • 功能舱段：遥感模块、微重力研究室、材料研究室、通讯模块——它们必须有一名航天员贴着（上下左右相邻）才会工作，没人值守就是一个箱子：不加成、技能也放不出来。航天员自己免疫外空环境，所以"派个人上去值班"是这些舱段的前置条件。
  • 遥感模块：技能「星球表面观测」——从轨道上对脚下这颗星球做一次观测，选一格，点亮它和上下左右共 5 格，本方从此看得见那片地方（情报永久有效，同一座模块再观测会替换上一次）。每回合 1 次，用掉之后要点技能按钮会提示"回一发"。
  • 微重力研究室：每座让本方总金币收入 +5%，多座叠加，上限 +20%。
  • 材料研究室：每座让本方所有单位护甲 +1，上限 +5。这条加成落在"外空 ÷5"之后——站内单位本来都被环境折过一遍，如果先加再除，等于白造。
  • 通讯模块：每座让本方所有单位视野 +1，上限 +3。
  • 维生仓：造好之后，半径 3 格内的单位不再吃「恶劣外空环境」（护甲不再 ÷5、移动不再减半）。航天员本来就免疫，不用罩。覆盖是按格算的：站要长大就得多造几座，围着它布置才划算。维生仓自己也是密封模块，所以它自己同样不受影响——攻打一座站时，它往往是最难拆的那一块。
  • 推进器舱：必须造在核心舱的下半区（不是正下方，整条下缘都行）。每台让这座站的航速 +1。装了推进器，空间站就是飞船：点核心舱出现「启航 → 目的地」，沿航道开到别的星球轨道，站内坐标一格不动，变的只是它挂在哪颗星球上。航程 = 航道距离 ÷ 航速（向上取整、至少 1 回合），地月距离 6，所以 1 台推进器 3 回合、2 台 2 回合、3 台 2 回合、5 台 1 回合。推进器不影响火箭：直飞月球的火箭弹道固定，1 回合到。
  • 星图：左上角面板里点「查看星图」。星图把每颗星球画成一格，连线就是航道；点星球能看到轨道上停着哪些站、有没有东西正在飞来，还能直接「前往」那张图或那座站。点连线能看到航程与路上的东西。只有一张图的局面没有星图可看。

03机制词条

表里带虚线下划线的词，鼠标停上去会浮一句说明；点一下停在这里。

不可移动
移动力 0：能开火、能产出，但永远不换位置。
扩建甲板
把一格虚空铺成甲板。一次一格，可以连着铺；价格按太空建设折扣算。 冷却 0 回合；不占移动与攻击。
建造生产舱
在空的甲板上造一座生产舱，每回合产 6 金（耗电 4）。价格按太空建设折扣算。 冷却 0 回合；不占移动与攻击。
建造太阳能舱
在空的甲板上造一块太阳能舱，发电 12。它自己不用电，所以电力再紧也能造。 冷却 0 回合；不占移动与攻击。
建造维生仓
在空的甲板上造一座维生仓（耗电 8），让周围 3 格内的单位不再吃「恶劣外空环境」：护甲不再 ÷5、移动不再减半。 冷却 0 回合；不占移动与攻击。
建造推进器舱
在核心舱下半区的空甲板上造一台推进器，耗电 15。每台让本方航道速度 +1（航程 = 距离 ÷ 速度）。 冷却 0 回合；不占移动与攻击。
建造遥感模块
在空的甲板上造一座遥感模块（耗电 10）。它有「星球表面观测」技能：从轨道上点亮地表一小片。需要航天员相邻才工作。 冷却 0 回合；不占移动与攻击。
建造微重力研究室
在空的甲板上造一座微重力研究室（耗电 12）：每座让本方总金币收入 +5%，多座叠加、上限 +20%。需要航天员相邻才工作。 冷却 0 回合；不占移动与攻击。
建造材料研究室
在空的甲板上造一座材料研究室（耗电 12）：每座让本方所有单位护甲 +1，上限 +5。需要航天员相邻才工作。 冷却 0 回合；不占移动与攻击。
建造通讯模块
在空的甲板上造一座通讯模块（耗电 8）：每座让本方所有单位视野 +1，上限 +3。需要航天员相邻才工作。 冷却 0 回合；不占移动与攻击。
星球表面观测
对脚下这颗星球的表面做一次观测：选一格，点亮它和上下左右共 5 格。情报永久有效（同一座模块再观测会替换上一次）。每回合 1 次。 冷却 0 回合；不占移动与攻击。
